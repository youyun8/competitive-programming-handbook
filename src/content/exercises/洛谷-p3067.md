statement: 給定 n 頭互異奶牛（產奶量可相同），計算有多少個非空子集能劃分成兩組，使兩組產奶量總和相同。
constraints:
  - 1 <= n <= 20
  - 1 <= a_i <= 100000000
input_format: 第一行 n；接著 n 行各一個產奶量。
output_format: 輸出平衡非空子集數量；同一奶牛集合無論有幾種劃分都只計一次。
samples:
  - input: |
      4
      1
      2
      3
      4
    output: '3'
    explanation: 平衡子集為 {1,2,3}、{1,3,4} 與 {1,2,3,4}。
core_knowledge: [三態枚舉, 折半搜尋, 子集遮罩去重]
judgment: 每頭牛有不選、放左組、放右組三種角色；答案計算聯集子集而不是劃分方式。
hints:
  - 用差值 `sum(left)-sum(right)` 表示一個劃分是否平衡，目標差值為零。
  - 把奶牛分兩半，各自枚舉三種角色並依差值分組。
  - 合併互為相反數的差值；用完整 n 位遮罩標記聯集，避免同一子集因多種劃分重複計數。
solution_outline: 對兩半做三進位 DFS，記錄每個差值可形成的選中遮罩集合；枚舉左右差值相反的遮罩對，標記其聯集，最後扣除空集合。
proof_or_invariant: 任一平衡子集及其一種劃分在兩半各對應唯一三態指派，兩半差值互為相反數，故一定被合併。反之被合併的指派總差為零，聯集是平衡子集。布林遮罩只把同一聯集計一次。
complexity:
  time: O(3^(n/2) + C)，C 為相反差值組的去重遮罩配對數
  space: O(3^(n/2) + 2^n)
common_errors: [把左右交換視為不同答案, 忘記扣除空集合, 用 32 位整數儲存差值總和]

  using namespace std;
  int main(){ios::sync_with_stdio(false);cin.tie(nullptr);int n;cin>>n;vector<long long>a(n);for(auto&x:a)cin>>x;int middle=n/2;using Groups=unordered_map<long long,unordered_set<int>>;const auto build=[&](int begin,int end){Groups groups;const auto dfs=[&](const auto&self,int index,long long difference,int mask)->void{if(index==end){groups[difference].insert(mask);return;}self(self,index+1,difference,mask);self(self,index+1,difference+a[index],mask|(1<<index));self(self,index+1,difference-a[index],mask|(1<<index));};dfs(dfs,begin,0,0);return groups;};Groups left=build(0,middle),right=build(middle,n);vector<bool>balanced(1<<n,false);for(const auto&[difference,left_masks]:left){auto it=right.find(-difference);if(it==right.end())continue;for(int first:left_masks)for(int second:it->second)balanced[first|second]=true;}int answer=0;for(bool value:balanced)if(value)++answer;cout<<answer-1<<'\n';}
