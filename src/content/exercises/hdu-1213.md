statement: >-
  宴會有 n 位客人。已知若干對互相認識的客人，而且「認識」可沿關係傳遞：
  同一個朋友群中的人都能坐在同桌，不同朋友群的人不願同桌。對每筆測試資料，
  求讓所有客人入座所需的最少桌數。

  - 1 <= n, m <= 1000
  - 客人編號為 1 到 n；每條關係的兩個編號不同
  - 官方時限為 1000 ms（非 Java），記憶體限制為 32768 KB（非 Java）

  第一行為測試資料筆數 T。每筆資料先給 n、m，接著 m 行各給 a、b，
  表示客人 a 與 b 認識；測試資料之間可能有空白行，格式化讀取會自動略過。
output_format: 每筆測試資料輸出一行整數，表示至少需要幾張桌子，不加額外空白。
samples:
  - input: |
      2

      2 3

    explanation: >-
      第一筆中 1、2、3 形成一群，4、5 形成另一群，所以需要兩桌。
      第二筆只有 2 與 5 相連，其餘三人各自成群，共四桌。
core_knowledge:
  - 無向圖的連通分量恰好對應可同桌的朋友群
  - 並查集以代表元維護目前的分組
  - 按大小合併與路徑壓縮可使操作攤銷近乎常數
judgment: 每組只輸出連通分量數；重複關係不應再次減少答案。
hints:
  - 把每位客人看成節點、每對認識關係看成無向邊；答案等同哪個基本圖論量？
  - 一開始每人各成一組。每讀一條關係，只需要知道兩人的代表元是否不同。
  - 令 groups 初值為 n；只有 unite(a,b) 真正合併兩個不同集合時才將 groups 減一。
solution_outline: >-
  為每位客人建立並查集，並令集合數 groups=n。逐條讀入認識關係，找到兩端代表元；
  若不同，按集合大小合併並把 groups 減一。全部關係處理完後，groups 就是朋友群數，
  也就是最少桌數。
proof_or_invariant: >-
  不變量是：處理完前 k 條關係後，並查集中的每個集合恰為由這 k 條邊形成之圖的一個
  連通分量。初始無邊時每個點各自成分量，命題成立。加入一條邊時，若兩端原本同分量，
  分量不變；若分屬兩個分量，該邊恰把它們合成一個，unite 也做完全相同的合併。
  因此處理完所有邊後，集合數就是朋友群數。每桌不能混合兩個朋友群，而每個朋友群
  可以共桌，所以此數量既是下界也可達成。
common_errors:
  - 每讀到一條關係都減一，沒有排除兩端本來已在同一集合的重複連接
  - 只統計直接朋友，沒有利用關係的傳遞性
  - 跨測試資料重用上一筆的 parent、size 或 groups
complexity:
  time: O((n + m) alpha(n)) 每筆測試資料
  space: O(n)

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  class DisjointSet {
  public:
      explicit DisjointSet(int n)
          : parent_(static_cast<size_t>(n + 1)),
            size_(static_cast<size_t>(n + 1), 1) {
          iota(parent_.begin(), parent_.end(), 0);
      }

      int find_root(int node) {
          if (parent_[static_cast<size_t>(node)] != node) {
              parent_[static_cast<size_t>(node)] =
                  find_root(parent_[static_cast<size_t>(node)]);
          }
          return parent_[static_cast<size_t>(node)];
      }

      bool unite(int first, int second) {
          int first_root = find_root(first);
          int second_root = find_root(second);
          if (first_root == second_root) {
              return false;
          }
          if (size_[static_cast<size_t>(first_root)] <
              size_[static_cast<size_t>(second_root)]) {
              swap(first_root, second_root);
          }
          parent_[static_cast<size_t>(second_root)] = first_root;
          size_[static_cast<size_t>(first_root)] +=
              size_[static_cast<size_t>(second_root)];
          return true;
      }

  private:
      vector<int> parent_;
      vector<int> size_;
  };

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      int test_count;
      cin >> test_count;
      while (test_count-- > 0) {
          int n, m;
          cin >> n >> m;
          DisjointSet dsu(n);
          int groups = n;
          for (int edge = 0; edge < m; ++edge) {
              int first, second;
              cin >> first >> second;
              if (dsu.unite(first, second)) {
                  --groups;
              }
          }
          cout << groups << '\n';
      }
  }
