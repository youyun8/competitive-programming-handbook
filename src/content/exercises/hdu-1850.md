statement: >-
  桌上有 m 堆牌。兩人輪流從任一堆取走至少一張、至多整堆，取走最後一張者勝。
  假設之後雙方都採最佳策略，求先手第一步有多少種選擇能保證獲勝。
constraints:
  - 1 < m <= 100
  - 1 <= n_i <= 1000000
  - 輸入含多組資料，m=0 結束
input_format: 每組先輸入堆數 m，下一行有 m 個堆大小；單獨的 0 結束輸入。
output_format: 每組輸出必勝第一步的數量；若先手必敗則輸出 0。
samples:
  - input: |
      3
      5 7 9
      0
    output: '1'
    explanation: 總異或為 11，只有把大小 9 的堆減為 9 xor 11=2 能把局面交給對手時變成零異或。
core_knowledge:
  - Nim 局面必敗恰若所有堆大小的 xor 為 0
  - 對固定一堆，能把總 xor 變成 0 的新大小唯一
judgment: 同一堆取不同張數視為不同選擇；但每一堆至多只有一個必勝取法。
hints:
  - 設所有堆的 xor 為 nim_sum；若它是 0，先手無法一步留下一個零異或局面。
  - 若修改第 i 堆為 target，修改後總 xor 是 nim_sum xor piles[i] xor target。
  - 令它為 0 可得 target=piles[i] xor nim_sum；只有 target<piles[i] 時才是合法取牌。
solution_outline: 先求 nim_sum，再逐堆計算 piles[i] xor nim_sum；若結果嚴格小於原堆大小，就將答案加一。
proof_or_invariant: >-
  Nim 定理指出零異或是且僅是 P 局面。對第 i 堆，要求移動後異或為零會唯一決定
  target=piles[i] xor nim_sum；它小於原值時恰對應一次合法非空取牌。若 nim_sum=0，
  每個 target 都大於等於原值，因此計數自然為零；反之逐堆測試會列出全部且僅有的必勝第一步。
common_errors:
  - 計算可取張數時拿 piles[i] xor nim_sum 當成取走量；它其實是剩餘量
  - 使用 <= 判斷，誤把取零張算成合法操作
  - 只判斷先手勝負而未計算所有可行第一步
complexity:
  time: 每組 O(m)
  space: O(m)

cpp_solution: |
  #include <iostream>
  #include <vector>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int pile_count;
      while (cin >> pile_count && pile_count != 0) {
          vector<int> piles(static_cast<size_t>(pile_count));
          int nim_sum = 0;
          for (int& pile : piles) {
              cin >> pile;
              nim_sum ^= pile;
          }
          int answer = 0;
          for (int pile : piles) {
              if ((pile ^ nim_sum) < pile) { ++answer; }
          }
          cout << answer << '\n';
      }
      return 0;
  }
