statement: 十字形棋盤有 24 格，數字 1、2、3 各八個。A 到 H 八種操作各把一條七格直線循環移動一格；求讓中央八格同值的最短操作字串，最短方案多個時輸出字典序最小者。

output_format: 第一行輸出操作字串；初態已完成則輸出 `No moves needed`。第二行輸出中央八格最後的數字。

core_knowledge: [固定轉移表, IDA*, 中央色數下界]
judgment: 最短深度相同時須按 A 到 H 枚舉，第一個解才是字典序最小方案。
hints:
  - 用八條長度七的索引表精確表示 A..H；E/F/G/H 分別是 B/A/D/C 的逆操作。
  - 中央八格若最多有 k 格同色，至少還要 `8-k` 步，因一次操作只會換入一個中央格。
  - 從此下界開始逐層 IDDFS，且避免緊接著走上一操作的逆操作。
solution_outline: 對深度上限做迭代加深；DFS 以 `depth+h<=limit` 剪枝，按 A..H 套用循環轉移並回復，找到第一個完成狀態即輸出路徑。
proof_or_invariant: 每次操作只更換中央八格中的一格，所以 `8−最多同色數` 不會高估。IDA* 依上限遞增完整枚舉所有未被可採納下界排除的序列，首個有解上限即最短；同層按字母序 DFS，首解亦為字典序最小。

  #include <bits/stdc++.h>
  using namespace std;
  const int line_index[8][7]={{0,2,6,11,15,20,22},{1,3,8,12,17,21,23},{10,9,8,7,6,5,4},{19,18,17,16,15,14,13},{23,21,17,12,8,3,1},{22,20,15,11,6,2,0},{13,14,15,16,17,18,19},{4,5,6,7,8,9,10}};
  const int center[8]={6,7,8,11,12,15,16,17},inverse_move[8]={5,4,7,6,1,0,3,2};int board[24],limit;string path;
  int heuristic(){int count[4]={};for(int p:center)++count[board[p]];return 8-max({count[1],count[2],count[3]});}
  void rotate_line(int move){int first=board[line_index[move][0]];for(int i=0;i<6;++i)board[line_index[move][i]]=board[line_index[move][i+1]];board[line_index[move][6]]=first;}
  bool search(int depth,int previous){int h=heuristic();if(h==0)return true;if(depth+h>limit)return false;for(int move=0;move<8;++move){if(previous>=0&&move==inverse_move[previous])continue;rotate_line(move);path.push_back(static_cast<char>('A'+move));if(search(depth+1,move))return true;path.pop_back();rotate_line(inverse_move[move]);}return false;}
  int main(){ios::sync_with_stdio(false);cin.tie(nullptr);while(cin>>board[0]&&board[0]){for(int i=1;i<24;++i)cin>>board[i];path.clear();for(limit=heuristic();!search(0,-1);++limit)path.clear();if(path.empty())cout<<"No moves needed\n";else cout<<path<<'\n';cout<<board[center[0]]<<'\n';}}
