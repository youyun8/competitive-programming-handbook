statement: >-
  給無向加權圖。旅行者可任選一座城市免費作為起點，須造訪全部 n 座城市，且每座城市最多造訪
  兩次；終點不限。求道路總費用最小值，無可行路線則輸出 -1。
constraints:
  - 輸入含多組資料，讀到 EOF
  - 1 <= n <= 10
  - 每條道路給兩端點與非負費用；平行道路取較小費用即可
input_format: 每組第一行 n、m；接著 m 行各為 a、b、c，表示城市 a、b 間費用 c。
output_format: 每組輸出一行最小費用；不存在符合條件的旅行路線時輸出 -1。
samples:
  - input: |-
      2 1
      1 2 100
      3 2
      1 2 40
      2 3 50
      3 3
      1 2 3
      1 3 4
      2 3 10
    output: |-
      100
      90
      7
    explanation: 三組最佳路線成本依序為 100、40+50=90，以及 1→2→1→3 的 3+4=7。
core_knowledge: [三進位狀態壓縮, 以末端城市為狀態的最短路徑 DP, 多起點初始化]
judgment: 起點可任選且不收費、終點不限；每座城市必須造訪至少一次且至多兩次，重複經過即算再次造訪；道路為無向，若同一對城市有多條道路只需保留最低費用。
hints:
  - 每城造訪次數只有 0、1、2 三種，將整體狀態寫成 n 位三進位數。
  - dp[state][last] 表示目前造訪次數為 state、停在 last 的最小費用；每個單城起點成本皆為零。
  - 只可沿道路把某個三進位位數小於 2 的相鄰城市加一；答案只取所有位數皆非零的狀態。
solution_outline: 預算三的冪，以三進位狀態壓縮每城造訪次數，依遞增狀態做最短路徑式 DP。
proof_or_invariant: >-
  狀態與末城完整描述後續可走選項。任一合法路線的最後一步必由某相鄰城市走到 last，並使 last
  的造訪次數加一，故轉移涵蓋它；反之每個轉移沿真實道路且不讓任一位超過二，因此構造出的路線
  全部合法。所有可能起點均初始化後，歸納可得每個狀態的最小費用；在每城位數至少一的狀態取小
  即完成全部城市的最優解。
common_errors: [用二進位而無法表示第二次造訪, 只初始化固定起點, 接受仍有某位為零的終態]
complexity:
  time: O(3^n * n^2)
  space: O(3^n * n)

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <limits>
  #include <vector>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false); cin.tie(nullptr);
      int n = 0, m = 0;
      while (cin >> n >> m) {
          const long long inf = numeric_limits<long long>::max() / 4;
          vector<vector<long long>> edge(static_cast<size_t>(n),
              vector<long long>(static_cast<size_t>(n), inf));
          for (int i = 0; i < m; ++i) {
              int a = 0, b = 0; long long cost = 0;
              cin >> a >> b >> cost; --a; --b;
              edge[static_cast<size_t>(a)][static_cast<size_t>(b)] =
                  min(edge[static_cast<size_t>(a)][static_cast<size_t>(b)], cost);
              edge[static_cast<size_t>(b)][static_cast<size_t>(a)] =
                  min(edge[static_cast<size_t>(b)][static_cast<size_t>(a)], cost);
          }
          vector<int> power(static_cast<size_t>(n + 1), 1);
          for (int i = 1; i <= n; ++i)
              power[static_cast<size_t>(i)] = power[static_cast<size_t>(i - 1)] * 3;
          vector<vector<long long>> dp(static_cast<size_t>(power[static_cast<size_t>(n)]),
              vector<long long>(static_cast<size_t>(n), inf));
          for (int city = 0; city < n; ++city)
              dp[static_cast<size_t>(power[static_cast<size_t>(city)])][static_cast<size_t>(city)] = 0;
          long long answer = inf;
          for (int state = 0; state < power[static_cast<size_t>(n)]; ++state) {
              bool complete = true;
              for (int city = 0; city < n; ++city)
                  if (state / power[static_cast<size_t>(city)] % 3 == 0) complete = false;
              for (int last = 0; last < n; ++last) {
                  const long long current = dp[static_cast<size_t>(state)][static_cast<size_t>(last)];
                  if (current == inf) continue;
                  if (complete) answer = min(answer, current);
                  for (int next = 0; next < n; ++next) {
                      if (state / power[static_cast<size_t>(next)] % 3 == 2 ||
                          edge[static_cast<size_t>(last)][static_cast<size_t>(next)] == inf) continue;
                      const int next_state = state + power[static_cast<size_t>(next)];
                      dp[static_cast<size_t>(next_state)][static_cast<size_t>(next)] =
                          min(dp[static_cast<size_t>(next_state)][static_cast<size_t>(next)],
                              current + edge[static_cast<size_t>(last)][static_cast<size_t>(next)]);
                  }
              }
          }
          cout << (answer == inf ? -1 : answer) << '\n';
      }
  }
