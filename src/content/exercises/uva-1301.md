statement: 一個邊長為 1 的正方形框，每條邊各有 n 個依位置遞增的釘子。第 i 條縱向線連接下邊的 (a_i,0) 與上邊的 (b_i,1)，第 i 條橫向線連接左邊的 (0,c_i) 與右邊的 (1,d_i)。連同正方形邊界，這些線把框分成 (n+1)² 個四邊形網格；求其中面積最大者。
constraints:
  - '0 < n <= 30'
  - '0 < a_1 < ... < a_n < 1，b、c、d 四組亦各自嚴格遞增'
  - 各位置以小數點後 7 位表示
  - 單獨一行 0 結束輸入
input_format: 多組資料。每組先給 n，接著四行依序給 a_1..a_n、b_1..b_n、c_1..c_n、d_1..d_n；0 表示結束。
output_format: 每組輸出最大網格面積，固定小數點後 6 位；容許誤差不超過 1e-6。
samples:
  - input: |
      1
      0.4000000
      0.6000000
      0.3000000
      0.5000000
      0
    output: |
      0.348958
    explanation: 兩條內部線把正方形分成四格；逐格由四個線交點套用鞋帶公式，最大一格面積為 0.348958。
core_knowledge:
  - 同一族連線因兩端順序一致，在正方形內不互相交叉
  - 每個網格四角是相鄰兩條縱線與相鄰兩條橫線的四個交點
  - 四邊形面積可用鞋帶公式穩定計算
judgment: n 最多 30，直接枚舉 (n+1)² 個網格即可。把左右、上下框邊也當成兩族直線的首尾元素，計算每格四個交點及面積。
hints:
  - 把 x=0、x=1 視為縱線族的第 0、n+1 條，把 y=0、y=1 視為橫線族的第 0、n+1 條。
  - 第 (i,j) 格只由縱線 i、i+1 與橫線 j、j+1 決定，不必建立完整平面圖。
  - 依「左下、右下、右上、左上」收集四個交點，再以相鄰點叉積總和的一半求面積。
solution_outline: 將每條線記為一點及方向向量，補入四條框邊。雙層枚舉相鄰縱線與相鄰橫線，利用叉積公式求四個交點，套用鞋帶公式並更新最大值。
proof_or_invariant: 兩組釘子都按邊界位置嚴格遞增，因此同族連線在框內不交叉；每條橫線與每條縱線恰交一次。故相鄰兩條縱線和相鄰兩條橫線圍成且只圍成一個網格，所有 (n+1)² 個網格也恰由雙層枚舉各一次。交點依邊界順序組成該格四邊形，鞋帶公式給出其精確面積，取最大值即為答案。
complexity:
  time: O(n²)
  space: O(n)
common_errors:
  - 忘記把正方形四條邊加入兩族直線
  - 四個交點次序交錯而使鞋帶公式互相抵消
  - 以線段斜率計算，遇到垂直線時除以零
  - 輸出位數不是固定 6 位

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  struct Point { long double x; long double y; };
  struct Line { Point point; Point direction; };

  static Point operator+(const Point& a, const Point& b) {
      return {a.x + b.x, a.y + b.y};
  }
  static Point operator-(const Point& a, const Point& b) {
      return {a.x - b.x, a.y - b.y};
  }
  static Point operator*(const Point& point, long double scale) {
      return {point.x * scale, point.y * scale};
  }
  static long double cross(const Point& a, const Point& b) {
      return a.x * b.y - a.y * b.x;
  }
  static Point intersection(const Line& first, const Line& second) {
      const long double ratio =
          cross(second.point - first.point, second.direction) /
          cross(first.direction, second.direction);
      return first.point + first.direction * ratio;
  }
  static long double quadrilateral_area(const array<Point, 4>& polygon) {
      long double twice_area = 0.0L;
      for (size_t i = 0; i < polygon.size(); ++i) {
          twice_area += cross(polygon[i], polygon[(i + 1U) % polygon.size()]);
      }
      return fabsl(twice_area) * 0.5L;
  }

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      cout << fixed << setprecision(6);
      int n;
      while (cin >> n && n != 0) {
          vector<long double> bottom(static_cast<size_t>(n));
          vector<long double> top(static_cast<size_t>(n));
          vector<long double> left(static_cast<size_t>(n));
          vector<long double> right(static_cast<size_t>(n));
          for (long double& value : bottom) { cin >> value; }
          for (long double& value : top) { cin >> value; }
          for (long double& value : left) { cin >> value; }
          for (long double& value : right) { cin >> value; }

          vector<Line> vertical;
          vector<Line> horizontal;
          vertical.push_back({{0.0L, 0.0L}, {0.0L, 1.0L}});
          horizontal.push_back({{0.0L, 0.0L}, {1.0L, 0.0L}});
          for (int i = 0; i < n; ++i) {
              const size_t index = static_cast<size_t>(i);
              vertical.push_back(
                  {{bottom[index], 0.0L}, {top[index] - bottom[index], 1.0L}});
              horizontal.push_back(
                  {{0.0L, left[index]}, {1.0L, right[index] - left[index]}});
          }
          vertical.push_back({{1.0L, 0.0L}, {0.0L, 1.0L}});
          horizontal.push_back({{0.0L, 1.0L}, {1.0L, 0.0L}});

          long double answer = 0.0L;
          for (size_t i = 0; i + 1U < vertical.size(); ++i) {
              for (size_t j = 0; j + 1U < horizontal.size(); ++j) {
                  const array<Point, 4> cell{
                      intersection(vertical[i], horizontal[j]),
                      intersection(vertical[i + 1U], horizontal[j]),
                      intersection(vertical[i + 1U], horizontal[j + 1U]),
                      intersection(vertical[i], horizontal[j + 1U])};
                  answer = max(answer, quadrilateral_area(cell));
              }
          }
          cout << answer << '\n';
      }
      return 0;
  }
