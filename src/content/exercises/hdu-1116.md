statement: >-
  給定若干小寫英文單字，每個單字必須恰使用一次。若前一字的尾字母等於下一字的首字母，
  兩字便可相接。判斷是否能把全部單字排成一條接龍。
constraints: [1 <= 測試組數 <= 20, 1 <= 單字數 <= 1000, 每字僅含小寫英文字母, 每個單字至少一字元]
input_format: 第一行為測試組數；每組先給單字數 n，再給 n 個單字。
output_format: 可接成完整序列輸出 Ordering is possible.，否則輸出 The door cannot be opened.。
samples:
  - input: "3\n3\nabc\ncde\nefg\n3\nabc\ncde\nxyz\n2\nabc\ncde\n"
    output: "Ordering is possible.\nThe door cannot be opened.\nOrdering is possible."
    explanation: 第一、三組可依所列順序相接；第二組的 xyz 與另外兩字不連通。
core_knowledge: [字母作頂點且單字作有向邊, 有向歐拉跡度數條件, 忽略方向的弱連通]
judgment: 不需輸出排列；重複單字仍是不同邊且都必須使用。
hints:
  - 單字首字母到尾字母建立一條有向邊。
  - 除起終點外入度應等於出度；起點可多一條出邊，終點可多一條入邊。
  - 所有出現過的字母在忽略方向後還必須位於同一連通塊。
solution_outline: 統計 26 個字母的入出度，並以 DSU 合併每個單字兩端；檢查弱連通及歐拉路/迴路度數條件。
proof_or_invariant: >-
  使用每個單字一次等價於使用每條有向邊一次。歐拉跡定理指出，非空有向圖存在涵蓋全部邊
  的跡，恰需所有有邊頂點弱連通，且度差全零，或恰一點 out-in=1、恰一點 in-out=1。
  程式逐項檢查這些充要條件。
common_errors: [只檢查度數而忽略不同連通塊, 要求所有 26 字母連通, 把首尾方向顛倒, 將歐拉迴路情況誤判為失敗]
complexity: { time: O(總字元數 + n*alpha(26)), space: O(26) }

cpp_solution: |
  #include <iostream>
  #include <string>
  #include <vector>
  using namespace std;
  struct Dsu{vector<int> p;explicit Dsu(int n):p(static_cast<size_t>(n)){for(int i=0;i<n;++i)p[static_cast<size_t>(i)]=i;}int find(int x){return p[static_cast<size_t>(x)]==x?x:p[static_cast<size_t>(x)]=find(p[static_cast<size_t>(x)]);}void unite(int a,int b){p[static_cast<size_t>(find(a))]=find(b);}};
  int main(){
      ios::sync_with_stdio(false);cin.tie(nullptr);int cases=0;cin>>cases;
      while(cases--){int n=0;cin>>n;vector<int> in(26,0),out(26,0);Dsu dsu(26);
          for(int i=0;i<n;++i){string word;cin>>word;int a=word.front()-'a',b=word.back()-'a';++out[static_cast<size_t>(a)];++in[static_cast<size_t>(b)];dsu.unite(a,b);}
          bool ok=true;int root=-1,start=0,finish=0;
          for(int v=0;v<26;++v)if(in[static_cast<size_t>(v)]+out[static_cast<size_t>(v)]>0){if(root==-1)root=dsu.find(v);else if(root!=dsu.find(v))ok=false;int diff=out[static_cast<size_t>(v)]-in[static_cast<size_t>(v)];if(diff==1)++start;else if(diff==-1)++finish;else if(diff!=0)ok=false;}
          if(!((start==0&&finish==0)||(start==1&&finish==1)))ok=false;
          cout<<(ok?"Ordering is possible.\n":"The door cannot be opened.\n");
      }
  }
