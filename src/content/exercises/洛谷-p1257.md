core_knowledge:

  - 中線窄帶的常數鄰點性質
judgment: 兩兩枚舉需 O(n²)。依 x 分半後，只須檢查離中線小於目前答案的點；窄帶依 y 排序時，每點只可能與後面常數個候選形成更近點對。
hints:
  - 先按 x 排序並二分；答案只可能來自左半、右半或跨越分界線的點對。
  - 遞迴回傳兩半較小距離 d，同時把目前區間按 y 合併；跨界候選只需保留 |x-mid_x|<d 的點。
  - 窄帶按 y 遞增後，對每點向後掃到 y 差不小於 d 即停；d×d 方格的裝箱性質保證總比較次數為線性。
solution_outline: 先依 x、y 排序。遞迴處理左右半區並取得 d，把區間穩定合併為 y 序；建立中線寬 2d 的窄帶，按 y 次序比較仍可能小於 d 的點對。
proof_or_invariant: 遞迴返回時，best 是區間內左右半點對的最短距離，且該區間已按 y 排序。任何尚未考慮且可能更短的點對必跨越中線，因此兩點都在寬 2best 的窄帶。窄帶按 y 排序後，若 y 差已不小於 best，距離不可能改善；其餘候選被逐一比較。故三類點對皆涵蓋，歸納得到全域最短距離。
complexity:
  time: O(n log n)
  space: O(n)
common_errors:
  - 直接枚舉所有點對而超時
  - 每層重新排序窄帶，將複雜度升為 O(n log² n)
  - 只比較窄帶相鄰一點，漏掉其他 y 距離小於 d 的候選
  - 最後輸出平方距離或小數位數錯誤

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  struct Point {
      long long x;
      long long y;
  };

  static long double distance_between(const Point& a, const Point& b) {
      return hypotl(static_cast<long double>(a.x - b.x),
                    static_cast<long double>(a.y - b.y));
  }

  static long double closest_pair(vector<Point>& points, vector<Point>& buffer,
                                  size_t left, size_t right) {
      const size_t length = right - left;
      if (length <= 3) {
          long double best = numeric_limits<long double>::infinity();
          for (size_t i = left; i < right; ++i) {
              for (size_t j = i + 1; j < right; ++j) {
                  best = min(best, distance_between(points[i], points[j]));
              }
          }
          sort(points.begin() + static_cast<ptrdiff_t>(left),
               points.begin() + static_cast<ptrdiff_t>(right),
               [](const Point& a, const Point& b) { return a.y < b.y; });
          return best;
      }

      const size_t middle = left + length / 2;
      const long long middle_x = points[middle].x;
      long double best = min(closest_pair(points, buffer, left, middle),
                             closest_pair(points, buffer, middle, right));
      merge(points.begin() + static_cast<ptrdiff_t>(left),
            points.begin() + static_cast<ptrdiff_t>(middle),
            points.begin() + static_cast<ptrdiff_t>(middle),
            points.begin() + static_cast<ptrdiff_t>(right),
            buffer.begin() + static_cast<ptrdiff_t>(left),
            [](const Point& a, const Point& b) { return a.y < b.y; });
      copy(buffer.begin() + static_cast<ptrdiff_t>(left),
           buffer.begin() + static_cast<ptrdiff_t>(right),
           points.begin() + static_cast<ptrdiff_t>(left));

      vector<Point> strip;
      strip.reserve(length);
      for (size_t i = left; i < right; ++i) {
          if (fabsl(static_cast<long double>(points[i].x - middle_x)) < best) {
              strip.push_back(points[i]);
          }
      }
      for (size_t i = 0; i < strip.size(); ++i) {
          for (size_t j = i + 1; j < strip.size(); ++j) {
              if (static_cast<long double>(strip[j].y - strip[i].y) >= best) { break; }
              best = min(best, distance_between(strip[i], strip[j]));
          }
      }
      return best;
  }

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n;
      cin >> n;
      vector<Point> points(static_cast<size_t>(n));
      for (Point& point : points) { cin >> point.x >> point.y; }
      sort(points.begin(), points.end(), [](const Point& a, const Point& b) {
          return a.x != b.x ? a.x < b.x : a.y < b.y;
      });
      vector<Point> buffer(points.size());
      cout << fixed << setprecision(4)
           << closest_pair(points, buffer, 0, points.size()) << '\n';
  }
