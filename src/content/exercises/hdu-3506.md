statement: >-
  n 堆物品環形排列，每次合併相鄰兩堆，代價為兩堆物品總數；求合成一堆的最小總代價。輸入含多組資料直到 EOF。
constraints:
  - 1 <= n <= 1000
  - 每堆數量為非負整數
  - 答案需 64 位
input_format: 每組第一行 n，第二行 n 堆數量。
output_format: 每組輸出最小總代價。
samples:
  - input: |-
      3
      1 2 3
    output: |-
      9
    explanation: 先合併 1、2 付 3，再與 3 合併付 6，總代價 9。
core_knowledge: ['環形區間 DP', '石子合併', '決策單調性']
judgment: 複製環成長度 2n 的鏈，答案是所有長度 n 區間的最小合併成本；區間和滿足 Knuth 優化條件。
hints:
  - 令 dp[l][r] 為線性區間合成一堆的最小代價，轉移加 sum(l,r)。
  - 環上任一最後保留的切邊對應加倍陣列的一個長度 n 區間。
  - 最佳切點單調：只枚舉 opt[l][r-1]..opt[l+1][r]，把 O(n^3) 降為 O(n^2)。
solution_outline: >-
  加倍輸入並建前綴和；按長度計算至 n 的區間 DP 與最佳切點，最後枚舉 n 個起點取 dp 最小值。
proof_or_invariant: >-
  每個區間方案最後一步唯一分成兩個連續子區間，得標準合併轉移。區間權為元素和，滿足四邊形不等式與包含單調性，Knuth 定理給出決策單調界。環形方案切開一條未跨越的邊後成為某個長度 n 線性方案，反之亦然。
common_errors: ['只計固定輸入切點', '切點範圍包含 r 造成自我依賴', 'opt 邊界未限制在 l..r-1']
