statement: |-
  有若干行文字，其中每個單字的字元順序都被顛倒了。請分別反轉每個由空白分隔的單字，但保留單字之間的順序以及原有空白位置。
constraints:
  - 每行至多 1000 個字元
  - 第一行的 T 表示待處理文字行數
input_format: 第一行為整數 T；接著 T 行，每行是一筆要處理的文字。
output_format: 對每筆文字輸出一行，逐字反轉其中每個單字，空白與單字順序維持不變。
samples:
  - input: |
      3
      olleh !dlrow
      m'I morf .udh
      I ekil .mca
    output: |
      hello world!
      I'm from hdu.
      I like acm.
    explanation: 第一行的 `olleh` 與 `!dlrow` 各自反轉為 `hello` 與 `world!`；空白仍留在兩個單字之間。其餘兩行以相同方式逐字處理。
core_knowledge:
  - 堆疊的後進先出順序可反轉一段連續字元
  - getline 讀取含空白的整行文字
  - 分隔符應原樣輸出，不能把整行一起反轉
judgment: 看到一般字元就入堆疊；遇到空白或行尾時清空堆疊，再輸出該分隔符。每個字元恰好進出堆疊一次。
hints:
  - 第一階段：先想想單一單字 `olleh` 要如何利用後進先出恢復成 `hello`。
  - 第二階段：逐字掃描整行；普通字元先暫存，遇到空白時才輸出目前單字。
  - 第三階段：用 `stack<char>` 暫存字元；遇到空白或掃描到行尾，就依序彈出全部字元，再原樣輸出空白。
solution_outline: 對每一行建立字元堆疊。掃到非空白字元便推入；掃到空白時先彈出並輸出整個堆疊，再輸出空白。掃描完成後再清空一次堆疊，以處理最後一個單字。
proof_or_invariant: 掃描至任一位置時，堆疊由底至頂恰為「目前尚未輸出的單字前綴」之正序。遇到分隔點時從頂端依序彈出，便得到該單字的反序；已輸出的所有先前單字及空白均與目標結果一致。行尾清空後整行皆正確。
complexity:
  time: 'O(L)，L 為全部文字的總長度'
  space: 'O(W)，W 為最長單字長度'
common_errors:
  - 讀完 T 後沒有吃掉換行，導致第一筆 getline 讀到空字串
  - 把整行反轉，連單字順序也一起顛倒
  - 漏掉行尾最後一個沒有空白結尾的單字
  - 以字串切割後重組，意外改變連續空白的數量

cpp_solution: |
  #include <iostream>
  #include <stack>
  #include <string>

  using namespace std;

  string restore_line(const string& line) {
      stack<char> characters;
      string answer;

      auto flush_word = [&]() {
          while (!characters.empty()) {
              answer.push_back(characters.top());
              characters.pop();
          }
      };

      for (char character : line) {
          if (character == ' ') {
              flush_word();
              answer.push_back(character);
          } else {
              characters.push(character);
          }
      }
      flush_word();
      return answer;
  }

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      int test_count;
      if (!(cin >> test_count)) {
          return 0;
      }
      string line;
      getline(cin, line);
      while (test_count-- > 0) {
          getline(cin, line);
          cout << restore_line(line) << '\n';
      }
      return 0;
  }
