statement: 給定目標 t 與一列已按非遞增排列的正整數，列出使用原列元素（每個位置至多一次）所得、總和為 t 的所有互異表示。
constraints: [0 < t < 1000, 1 <= n <= 12, 0 < x_i < 100, 輸入序列非遞增且可重複]
input_format: 每組一行 t、n、接著 n 個數；n=0 結束。
output_format: 先輸出 `Sums of t:`；依數列字典序遞減輸出、項間以 `+` 相連；無解輸出 `NONE`。
samples:
  - input: |
      4 6 4 3 2 2 1 1
      5 3 2 1 1
      0 0
    output: |
      Sums of 4:
      4
      3+1
      2+2
      2+1+1
      Sums of 5:
      NONE
    explanation: 重複值可按出現次數使用，但相同數值序列只能輸出一次。
core_knowledge: [依索引回溯, 同層重複值剪枝, 輸出順序]
judgment: 同值的不同位置不構成不同答案；單一數字也可是一組表示。
hints:
  - 由左至右枚舉下一位置，原序列已遞減，DFS 葉的順序自然符合要求。
  - 同一遞迴層若候選值等於前一個已嘗試值，就略過它。
  - 已選總和加候選超過 t 時不能選；達到 t 後立即輸出，不再向下。
solution_outline: 對每組資料從索引零 DFS；保存目前和與路徑，依序選後方元素，同層跳過相同值。
proof_or_invariant: 路徑索引嚴格增加，故每個位置至多使用一次且數值非遞增。每個值在同層只採最早位置；較早位置具有較完整的後綴，因此不漏任何值序列。依原序列順序展開使輸出符合遞減字典序。
complexity: { time: 'O(2^n * n)', space: 'O(n)' }
common_errors: [把相同值的不同位置重複輸出, 允許同一位置重複使用, 遺漏標頭冒號或 NONE]

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;
  int main(){ios::sync_with_stdio(false);cin.tie(nullptr);int target,n;while(cin>>target>>n&&n){vector<int>a(n),path;for(int&x:a)cin>>x;cout<<"Sums of "<<target<<":\n";bool found=false;const auto dfs=[&](const auto&self,int start,int sum)->void{if(sum==target){found=true;for(size_t i=0;i<path.size();++i)cout<<(i?"+":"")<<path[i];cout<<'\n';return;}for(int i=start;i<n;++i){if(i>start&&a[i]==a[i-1])continue;if(sum+a[i]>target)continue;path.push_back(a[i]);self(self,i+1,sum+a[i]);path.pop_back();}};dfs(dfs,0,0);if(!found)cout<<"NONE\n";}}
