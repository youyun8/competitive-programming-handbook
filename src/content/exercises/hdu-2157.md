  - 矩陣快速冪
statement: 給定 0 到 n-1 的有向圖，多次詢問從 A 到 B 恰走 k 條邊的路徑數，允許重複走邊，答案模 1000。
constraints:
  - 1 <= n <= 20
  - m <= 100
  - 1 <= T <= 100
  - 0 <= k < 20
  - n=m=0 結束
input_format: 每組先給 n、m 與 m 條有向邊，再給詢問數 T 與 T 行 A、B、k。
output_format: 每個詢問輸出一行方案數模 1000。
samples:
  - input: |
      4 4
      0 1
      0 2
      1 3
      2 3
      2
      0 3 2
      0 3 3
      0 0
    output: |
      2
      0
    explanation: 恰走兩邊有 0→1→3、0→2→3；圖中沒有恰走三邊到 3 的路徑。
core_knowledge:
  - 鄰接矩陣乘法
  - 恰定邊數計數
judgment: 鄰接矩陣的 k 次方直接給出所有恰走 k 邊的路徑數。
hints:
  - 先理解 A²[i][j] 中間索引的求和正是在枚舉中繼點。
  - 一般地 A^k[i][j] 計數恰走 k 條邊，重複點與邊自然包含。
  - k=0 時使用單位矩陣，只有 A=B 有一條空路徑。
solution_outline: 建鄰接矩陣；每個詢問快速計算 k 次方並輸出對應元素。
proof_or_invariant: 由路徑最後的銜接點分割，矩陣乘法把長 x、y 的路徑合成長 x+y；歸納可得 A^k 的語意。
complexity:
  time: 每詢問 O(n^3 log k)
  space: O(n^2)
common_errors:
  - 把 k 解讀為中間點數而多一次邊
  - 把有向邊建成雙向
  - k=0 未用單位矩陣
