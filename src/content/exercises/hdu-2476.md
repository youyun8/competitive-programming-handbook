statement: 給等長小寫字串 A、B。一次可把 A 的任意連續區間全部改成同一字元，且可覆蓋先前結果；求把 A 變成 B 的最少操作數。
constraints:
  - 輸入含多組資料，讀到 EOF
  - 兩字串等長且長度不超過 100
  - 字串只含小寫英文字母
input_format: 每組兩行，依序為 A、B。
output_format: 每組輸出一行最少操作數。
samples:
  - input: |-
      zzzzzfzzzzz
      abcdefedcba
      abababababab
      cdcdcdcdcdcd
    output: |-
      6
      7
    explanation: 第一組可由外向內依序塗成 a、b、c、d、e，中央保留 f，共六次；第二組最少七次。
core_knowledge: [空白到目標的區間 DP, 利用來源相同位置]
judgment: 每次區間可任意選字元，後來操作可覆蓋；兩組輸入彼此獨立。
hints:
  - 先求 paint[l][r]：不利用 A 現況，從空白塗成 B[l..r] 的最少次數。
  - B 中相同字元可共用一次較早的塗色，得到 strange-printer 區間轉移。
  - 再做前綴 dp；若 A[i]=B[i] 可保留該位，否則枚舉最後一段由 j..i 完成。
solution_outline: 先以 O(n^3) 區間 DP 求任意 B 子串的純塗色成本，再用一維前綴 DP 合併 A 已正確位置。
proof_or_invariant: >-
  paint 精確表示忽略初始字串時完成目標區間的最低成本：末端可單獨塗，或與區間內相同目標字元
  共用一次操作，枚舉即涵蓋所有最後操作。前綴 dp[i] 的最優方案若保留 A[i]=B[i]，由 dp[i-1]
  取得；否則存在最後一個獨立完成的後綴 [j,i]，成本為 dp[j-1]+paint[j][i]。兩類完備，
  歸納後 dp[n] 正確。
common_errors: [直接對 A 做 strange-printer 而忽略原本正確字元, 相同目標字元的區間轉移下標錯誤, 只讀一組資料]
complexity:
  time: O(n^3) 每組
  space: O(n^2)

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <string>
  #include <vector>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false); cin.tie(nullptr);
      string source, target;
      while (cin >> source >> target) {
          const int n = static_cast<int>(source.size());
          vector<vector<int>> paint(static_cast<size_t>(n), vector<int>(static_cast<size_t>(n), 0));
          for (int left = n - 1; left >= 0; --left) {
              paint[static_cast<size_t>(left)][static_cast<size_t>(left)] = 1;
              for (int right = left + 1; right < n; ++right) {
                  int best = paint[static_cast<size_t>(left)][static_cast<size_t>(right - 1)] + 1;
                  for (int middle = left; middle < right; ++middle)
                      if (target[static_cast<size_t>(middle)] == target[static_cast<size_t>(right)]) {
                          const int before = middle == left ? 0 :
                              paint[static_cast<size_t>(left)][static_cast<size_t>(middle - 1)];
                          best = min(best, before +
                              paint[static_cast<size_t>(middle)][static_cast<size_t>(right - 1)]);
                      }
                  paint[static_cast<size_t>(left)][static_cast<size_t>(right)] = best;
              }
          }
          vector<int> dp(static_cast<size_t>(n + 1), 0);
          for (int length = 1; length <= n; ++length) {
              dp[static_cast<size_t>(length)] = paint[0][static_cast<size_t>(length - 1)];
              if (source[static_cast<size_t>(length - 1)] == target[static_cast<size_t>(length - 1)])
                  dp[static_cast<size_t>(length)] = min(dp[static_cast<size_t>(length)],
                                                        dp[static_cast<size_t>(length - 1)]);
              for (int left = 1; left < length; ++left)
                  dp[static_cast<size_t>(length)] =
                      min(dp[static_cast<size_t>(length)],
                          dp[static_cast<size_t>(left)] +
                          paint[static_cast<size_t>(left)][static_cast<size_t>(length - 1)]);
          }
          cout << dp[static_cast<size_t>(n)] << '\n';
      }
  }
