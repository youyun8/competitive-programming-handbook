statement: >-
  n 個人要依若干 a→b 限制撤離，表示 a 必須先於 b。希望編號 1 儘量早撤離；在此前提下
  編號 2 儘量早，依此類推。求符合這個逐編號優先目標的順序。
constraints: [1 <= 測試組數 <= 10, 1 <= n <= 30000, 0 <= m <= 100000, 輸入限制保證存在合法順序]
input_format: 第一行為測試組數；每組先給 n m，接著 m 行 a b。
output_format: 每組輸出一行 n 個撤離者編號，以空格分隔。
samples:
  - input: "1\n5 4\n5 4\n5 3\n4 2\n3 2\n"
    output: '1 5 3 4 2'
    explanation: 1 沒有限制可先離開；要讓 2 儘早，必須先完成 5、3、4，且 3 應比 4 更早。
core_knowledge: [反圖拓撲排序, 最大堆, 從序列尾端貪心]
judgment: 目標不是普通字典序最小拓撲序；較小者若有前置限制，必須先安排其必要前驅。
hints:
  - 從最後一個位置往前決定，候選是原圖目前的出度零點。
  - 最後位置應放候選中編號最大者，為小編號保留更前的位置。
  - 把邊反向、以最大堆拓撲排序，最後反轉結果。
solution_outline: 對 a→b 建反邊 b→a，原圖出度作反圖入度；最大堆完成反向拓撲序，再整體反轉輸出。
proof_or_invariant: >-
  決定目前最右位置時只能選原圖匯點。若可選 a<b 卻把 a 放最右，改放 b 不影響限制並為
  較小 a 保留更早位置，目標不劣；故每步最大候選具有交換論證。反向 Kahn 正好維護所有
  當前匯點，反轉後滿足原邊方向且逐編號最優。
common_errors: [用正圖最小堆求一般字典序, 建反邊後忘記反轉, 把原圖入度當成反圖入度, 每組輸出末尾多空格]
complexity: { time: O((n + m) log n), space: O(n + m) }

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <queue>
  #include <vector>
  using namespace std;
  int main(){
      ios::sync_with_stdio(false);cin.tie(nullptr);int cases=0;cin>>cases;
      while(cases--){int n=0,m=0;cin>>n>>m;vector<vector<int>> reverse_graph(static_cast<size_t>(n+1));vector<int> degree(static_cast<size_t>(n+1),0);
          for(int i=0;i<m;++i){int a=0,b=0;cin>>a>>b;reverse_graph[static_cast<size_t>(b)].push_back(a);++degree[static_cast<size_t>(a)];}
          priority_queue<int> ready;for(int v=1;v<=n;++v)if(degree[static_cast<size_t>(v)]==0)ready.push(v);vector<int> order;order.reserve(static_cast<size_t>(n));
          while(!ready.empty()){int u=ready.top();ready.pop();order.push_back(u);for(int v:reverse_graph[static_cast<size_t>(u)])if(--degree[static_cast<size_t>(v)]==0)ready.push(v);}reverse(order.begin(),order.end());
          for(int i=0;i<n;++i)cout<<order[static_cast<size_t>(i)]<<(i+1==n?'\n':' ');
      }
  }

逐編號優先不是「每次選最小零入度」；從尾端用最大匯點，才不會過早犧牲小編號的位置。
