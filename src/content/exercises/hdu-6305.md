statement: 定義 RMQ(A,l,r) 為區間最大值最左側位置。若兩個等長序列在每個區間的 RMQ 位置都相同，就稱為 RMQ Similar。已知整數序列 A；隨機序列 B 的各元素獨立且均勻取自 [0,1]。若 A、B 相似，B 的權重為元素總和，否則為 0；求權重期望對 1000000007 取模。

  - 答案分母保證不被 1000000007 整除

output_format: 每組輸出期望值所代表的模 1000000007 整數。

core_knowledge: [RMQ 與笛卡爾樹同構, 左側最大值 tie-breaking, 子樹大小乘積, 期望線性]
judgment: 所有區間最大值最左位置完全決定最大笛卡爾樹形狀；隨機連續序列幾乎必然沒有相等值，因此只需計算隨機排列形成指定樹形的機率。
hints:
  - 用最大笛卡爾樹表示每個區間的最左最大值；為保留最左側 tie-breaking，單調棧只彈出嚴格較小值。
  - 若節點 u 的笛卡爾子樹大小為 size_u，隨機排列在該區間讓 u 成為最大值的條件機率是 1/size_u。
  - 相似機率為所有 1/size_u 的乘積；相似條件下元素總和期望仍為 n/2，最後乘上 2 與各 size_u 的模逆元。
solution_outline: 以嚴格小於比較的單調棧 O(n) 建最大笛卡爾樹；迭代後序求每個子樹大小，將 n/2 乘上所有子樹大小的模逆元。
proof_or_invariant: 兩序列 RMQ Similar 當且僅當其最左最大笛卡爾樹同構。對任一子樹，其根在對應隨機排列中成為區間最大值的條件機率為 1/size；遞迴相乘得到指定樹形機率。連續獨立樣本的排序排列與排序後數值獨立，所以在指定樹形條件下總和期望仍是 n/2，兩者相乘即答案。
complexity:
  time: 每組 O(n)
  space: O(n)
common_errors:
  - 相等時也從棧中彈出，改成最右最大值而違反 RMQ 的最小索引規則
  - 把期望誤寫成所有 1/(2×size_u) 的乘積；因子 1/2 只來自總和期望 n/2
  - 以遞迴 DFS 處理百萬節點鏈而造成呼叫棧溢位

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  constexpr long long mod_value = 1000000007LL;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      int test_count;
      cin >> test_count;
      vector<long long>inverse{0, 1};

      while (test_count-- > 0) {
          int n;
          cin >> n;
          vector<int>sequence(static_cast<size_t>(n));
          for (int& value : sequence) cin >> value;

          size_t required_inverse = static_cast<size_t>(max(n, 2));
          while (inverse.size() <= required_inverse) {
              long long value = static_cast<long long>(inverse.size());
              inverse.push_back(
                  mod_value -
                  mod_value / value * inverse[static_cast<size_t>(mod_value % value)] % mod_value
              );
          }

          vector<int>left_child(static_cast<size_t>(n), -1);
          vector<int>right_child(static_cast<size_t>(n), -1);
          vector<int>monotonic_stack;
          monotonic_stack.reserve(static_cast<size_t>(n));

          for (int index = 0; index < n; ++index) {
              int last_smaller = -1;
              while (
                  !monotonic_stack.empty() &&
                  sequence[static_cast<size_t>(monotonic_stack.back())] <
                      sequence[static_cast<size_t>(index)]
              ) {
                  last_smaller = monotonic_stack.back();
                  monotonic_stack.pop_back();
              }
              if (!monotonic_stack.empty()) {
                  right_child[static_cast<size_t>(monotonic_stack.back())] = index;
              }
              left_child[static_cast<size_t>(index)] = last_smaller;
              monotonic_stack.push_back(index);
          }

          int root = monotonic_stack.front();
          vector<int>order{root};
          order.reserve(static_cast<size_t>(n));
          for (size_t index = 0; index < order.size(); ++index) {
              int node = order[index];
              int left = left_child[static_cast<size_t>(node)];
              int right = right_child[static_cast<size_t>(node)];
              if (left >= 0) order.push_back(left);
              if (right >= 0) order.push_back(right);
          }

          vector<int>subtree_size(static_cast<size_t>(n), 1);
          for (auto iterator = order.rbegin(); iterator != order.rend(); ++iterator) {
              int node = *iterator;
              int left = left_child[static_cast<size_t>(node)];
              int right = right_child[static_cast<size_t>(node)];
              if (left >= 0) {
                  subtree_size[static_cast<size_t>(node)] +=
                      subtree_size[static_cast<size_t>(left)];
              }
              if (right >= 0) {
                  subtree_size[static_cast<size_t>(node)] +=
                      subtree_size[static_cast<size_t>(right)];
              }
          }

          long long answer = static_cast<long long>(n) * inverse[2] % mod_value;
          for (int size : subtree_size) {
              answer = answer * inverse[static_cast<size_t>(size)] % mod_value;
          }
          cout << answer << '\n';
      }
  }
