statement: 一個 n 列數字三角形中，從頂端開始，每步走到下一列相鄰的左下或右下格；求抵達底列的最大路徑和。
constraints:
  - 1 <= n <= 350
  - 0 <= value <= 99
input_format: 第一行為 n，後續第 i 列給 i 個整數。
output_format: 輸出最大路徑和。
samples:
  - input: |-
      5
      7
      3 8
      8 1 0
      2 7 4 4
      4 5 2 6 5
    output: '30'
    explanation: 選擇 7→3→8→7→5 可得 30；每格保留的最佳前綴證明沒有更大路徑。
core_knowledge: [數字三角形 DP, 最優路徑]
judgment: 路徑必須從唯一頂點開始並抵達底列，每步只能走向兩個相鄰子格。
hints:
  - 到達某格的最後一步只能來自它的兩個父格。
  - 用 dp[j] 保存上一列到第 j 格的最大和，邊界不存在的父格視為不可達。
  - 先讀一列，再從右往左更新，最後取底列所有狀態的最大值。
solution_outline: 逐列從右向左更新一維 DP，每格取兩個父狀態最大值加本格數字。
proof_or_invariant: >-
  第 i 列處理後，dp[j] 是頂端到 (i,j) 的最大路徑和。所有到該格的路徑必由兩父格之一延伸，
  因而轉移取兩者最大值既不漏解也不產生非法路徑。頂點基底正確，歸納至底列後取最大即為答案。
common_errors: [由左往右原地更新而覆寫父狀態, 邊界錯讀不存在的父格, 忘記在底列取最大]
complexity:
  time: O(n^2)
  space: O(n)

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <limits>
  #include <vector>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false); cin.tie(nullptr);
      int n = 0; cin >> n;
      const int negative = numeric_limits<int>::min() / 4;
      vector<int> dp(static_cast<size_t>(n), negative);
      for (int row = 0; row < n; ++row) {
          vector<int> values(static_cast<size_t>(row + 1));
          for (int& value : values) cin >> value;
          for (int column = row; column >= 0; --column) {
              if (row == 0) { dp[0] = values[0]; continue; }
              const int left = column > 0 ? dp[static_cast<size_t>(column - 1)] : negative;
              const int right = column < row ? dp[static_cast<size_t>(column)] : negative;
              dp[static_cast<size_t>(column)] =
                  max(left, right) + values[static_cast<size_t>(column)];
          }
      }
      cout << *max_element(dp.begin(), dp.end()) << '\n';
  }
