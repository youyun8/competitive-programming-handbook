statement: >-
  給定一個長度為 n 的字串。對每個長度 i > 1 的前綴，判斷它能否由某個更短的字串連續重複至少兩次組成；
  若可以，輸出 i 與可重複的最大次數。輸入含多組資料。

  - 2 <= n <= 1000000
  - 官方總時間限制 3000 ms，記憶體限制 65536 kB
  - 每組字串的實際長度等於 n
  - 單獨一行 0 是輸入終止標記，不是一組測資

  每組資料有兩行：第一行是字串長度 n，第二行是字串 s。最後以一行 0 結束。
output_format: >-
  第 t 組先輸出 `Test case #t`。接著按 i 遞增輸出所有具有週期的前綴，每行為 `i k`，
  其中 k 是該前綴可由最短循環節重複的次數。每組資料後輸出一個空行。

    explanation: >-
      `aaa` 的長度 2、3 前綴分別是 `a` 的 2、3 次重複。第二組中，長度 6、9、12
      的前綴分別是 `aab` 的 2、3、4 次重複；長度 2 的前綴 `aa` 則是 `a` 的兩次重複。
core_knowledge:
  - KMP 前綴函數 pi[i] 表示前綴 s[0..i] 的最長真前綴兼後綴長度
  - 長度 length 的前綴候選最短週期為 length - pi[length - 1]
  - 候選週期整除 length 時，重複次數才是 length / period
judgment: >-
  必須逐組輸出指定標題、所有符合條件的前綴長度與最大重複次數，順序遞增；標題大小寫、井號與組間空行都要一致。
hints:
  - 先想每個前綴與自身最長的「真前綴兼後綴」之間，差了多少字元。
  - 用 KMP 前綴函數一次求出每個前綴的最長邊界；長度 length 的候選循環節長度是 length - pi[length - 1]。
  - 只有 length 能被候選長度整除時才形成完整重複，且 length / period > 1；此商就是題目要求的最大次數。
solution_outline: >-
  線性計算整個字串的 KMP 前綴函數。依序枚舉 length=2..n，令 period=length-pi[length-1]；
  若 length 可被 period 整除且商大於 1，就輸出 length 與商。前綴函數給出的最長邊界使 period
  最小，因此商最大。
proof_or_invariant: >-
  前綴函數的不變量是 pi[i] 恰為 s[0..i] 的最長真前綴兼後綴長度。若長度 length 的字串由長度 p
  的區塊重複，則它有長度 length-p 的邊界，所以最長邊界導出的 p0=length-pi[length-1] 不大於 p。
  字串週期引理又保證：當 length 可被 p0 整除時，p0 確為完整循環節；反之若不能整除，就無法把整個
  前綴切成相同的 p0 區塊。任何完整循環節都不短於 p0，因此 length/p0 是最大重複次數。
common_errors:
  - 忘記檢查 length % period == 0，僅有前綴兼後綴不代表可完整重複
  - 把 pi 的索引與前綴長度混用，誤寫成 length - pi[length]
  - 漏掉每組答案後的空行，或把終止標記 0 當成測資
complexity:
  time: O(n)，每組字串的每個位置至多被失配指標總計回退線性次
  space: O(n)，儲存前綴函數

cpp_solution: |
  #include <iostream>
  #include <string>
  #include <vector>
  using namespace std;

  static vector<int> build_prefix_function(const string& text) {
      vector<int> prefix(text.size(), 0);
      for (size_t i = 1; i < text.size(); ++i) {
          int matched = prefix[i - 1];
          while (matched > 0 && text[i] != text[static_cast<size_t>(matched)]) {
              matched = prefix[static_cast<size_t>(matched - 1)];
          }
          if (text[i] == text[static_cast<size_t>(matched)]) {
              ++matched;
          }
          prefix[i] = matched;
      }
      return prefix;
  }

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      int n = 0;
      int case_number = 0;
      while (cin >> n && n != 0) {
          string text;
          cin >> text;
          const vector<int> prefix = build_prefix_function(text);
          cout << "Test case #" << ++case_number << '\n';
          for (int length = 2; length <= n; ++length) {
              const int period = length - prefix[static_cast<size_t>(length - 1)];
              if (length % period == 0 && length / period > 1) {
                  cout << length << ' ' << length / period << '\n';
              }
          }
          cout << '\n';
      }
      return 0;
  }

最長邊界提供最短的候選週期；整除條件則負責排除只在首尾重疊、卻不能鋪滿整個前綴的情形。
