statement: >-
  有 n 座城堡，每座有價值且至多依賴一座父城堡；只有先攻下父城堡才能攻子城堡。恰攻 m 座，求最大價值。
constraints:
  - 1 <= n <= 200
  - 1 <= m <= n
  - 以 0 0 結束
input_format: 每組 n、m；其後 n 行給城堡 i 的父編號（0 表示無父）與價值。
output_format: 每組輸出最大價值。
samples:
  - input: |-
      3 2
      0 1
      1 2
      1 4
      0 0
    output: |-
      5
    explanation: 先選根城堡 1，再選價值 4 的城堡 3，總值 5。
core_knowledge: ['依賴揹包', '虛擬根', '樹形 DP']
judgment: 選取集合對祖先封閉；加入不計數的虛擬根後成為標準含根連通子樹揹包。
hints:
  - 把所有父編號 0 的城堡接到虛擬節點 0。
  - dp[u][j] 表示含 u、選 j 個真城堡的最大價值；虛擬根不占名額。
  - 合併兒子時可從該兒子取 0 個，否則其方案必含兒子根。
solution_outline: >-
  建立依賴森林並接虛擬根，後序逐兒子做分組揹包，真節點以選自己一個初始化，最後輸出 dp[0][m]。
proof_or_invariant: >-
  祖先封閉集合與包含虛擬根的連通選點集合一一對應。每個兒子子樹的選擇互不相交，轉移枚舉名額分配；歸納得固定名額最大值。
common_errors: ['把虛擬根算入 m', '允許選兒子卻不選父親', '正序容量使兒子重複合併']

  int main(){ios::sync_with_stdio(false);cin.tie(nullptr);int n,m;while(cin>>n>>m&&(n||m)){vector<vector<int>>ch(n+1);vector<int>w(n+1);for(int i=1,p;i<=n;i++){cin>>p>>w[i];ch[p].push_back(i);}vector<vector<int>>dp(n+1,vector<int>(m+1,-1000000000));auto dfs=[&](auto&&s,int u)->void{dp[u][u?1:0]=w[u];for(int v:ch[u]){s(s,v);auto nd=dp[u];for(int i=0;i<=m;i++)if(dp[u][i]>-1000000000)for(int j=1;i+j<=m;j++)nd[i+j]=max(nd[i+j],dp[u][i]+dp[v][j]);dp[u].swap(nd);}};dfs(dfs,0);cout<<dp[0][m]<<'\n';}}
