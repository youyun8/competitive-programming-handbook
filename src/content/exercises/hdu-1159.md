statement: >-
  給兩個字串。子序列可由原字串刪除任意字元後取得，保留下來的字元相對順序不可改變。
  求兩字串共同子序列的最大可能長度。

  - 輸入含多組資料，讀到檔案結尾
  - 每組是兩個以空白分隔的非空字串
  - 官方題面保證輸入資料合法，但未另列字串長度上限
input_format: 每組輸入兩個以任意空白分隔的字串，直到 EOF。
output_format: 每組輸出一行最長共同子序列的長度。
samples:
  - input: 'abcfbc abfcab'
    output: '4'
    explanation: abfb 是長度 4 的共同子序列；動態規劃也證明不存在更長者。
core_knowledge:
  - 最長共同子序列的前綴 DP
  - 只依賴上一列與本列左側，可用滾動陣列
judgment: 求的是子序列而非連續子字串，答案只需長度，不需輸出序列。
hints:
  - 用兩個前綴長度描述狀態，思考最後一個字元是否被配對。
  - 若兩個末字元相同，可把它接在更短前綴的共同子序列後；否則至少捨去其中一個末字元。
  - 令 dp[j] 表示目前第一字串前綴與第二字串前 j 個字元的答案，另存更新前的左上角值。
solution_outline: >-
  逐字元掃描第一字串。更新第二字串的每個前綴時，若兩末字元相同，以更新前的左上角加一；
  否則取上一列同欄與本列左欄的較大值。保留一列即可。
proof_or_invariant: >-
  完成第一字串前 i 個字元與第二字串前 j 個字元的更新後，dp[j] 是兩前綴的 LCS 長度。
  末字元相同時，存在最佳解配對兩末字元，答案為左上前綴答案加一；末字元不同時，任一共同
  子序列不可能同時以這兩個不同字元結尾，必捨去至少一者，答案即上方與左方狀態的最大值。
  初始空前綴答案為零，故歸納得到完整字串答案。
common_errors:
  - 把共同子序列誤作必須連續的共同子字串
  - 一維更新時沒有保存舊 dp[j-1]，使左上角值被覆寫
  - 只讀一組資料，忽略輸入直到 EOF

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <string>
  #include <vector>
  using namespace std;

  static int lcs_length(const string& first, const string& second) {
      vector<int> dp(second.size() + 1U, 0);
      for (char left_char : first) {
          int diagonal = 0;
          for (size_t j = 1; j <= second.size(); ++j) {
              const int old_above = dp[j];
              if (left_char == second[j - 1U]) {
                  dp[j] = diagonal + 1;
              } else {
                  dp[j] = max(dp[j], dp[j - 1U]);
              }
              diagonal = old_above;
          }
      }
      return dp.back();
  }

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      string first;
      string second;
      while (cin >> first >> second) {
          cout << lcs_length(first, second) << '\n';
      }
  }
