statement: >-
  一列 n 張牌各寫一個正整數。每次只能取走非首尾牌，得分為該牌與當時左右相鄰牌三者的乘積；
  最後留下首尾兩張。安排取牌順序，使總得分最小。
constraints:
  - 3 <= n <= 100
  - 1 <= card_i <= 100
input_format: 第一行為牌數 n，第二行為依序排列的 n 個整數。
output_format: 輸出最小總得分。
samples:
  - input: |-
      6
      10 1 50 50 20 5
    output: '3650'
    explanation: 區間 DP 枚舉每段最後取走的牌，所得全列最小成本為 3650。
core_knowledge: [區間最後決策, 矩陣鏈式 DP]
judgment: 原本的第一張與最後一張牌永遠不能取走；相鄰關係會隨取牌改變。
hints:
  - 固定一段仍保留的左右端點，思考其內部最後被取走的是哪張牌。
  - 若 k 最後取走，當時相鄰牌必是區間端點 l、r，新增成本為 card_l*card_k*card_r。
  - 依區間長度遞增，令 dp[l][r] 為清空開區間 (l,r) 的最小成本。
solution_outline: 枚舉長度、左右端點與最後取走位置 k，以 dp[l][k]+dp[k][r]+a[l]a[k]a[r] 更新。
proof_or_invariant: >-
  固定任一區間最優取法及其最後取走的內部牌 k。在此之前，k 兩側牌必已各自清空，且兩側操作互不影響，
  因而成本至少是兩個子區間最優值加最後一步乘積。反之依任一 k 執行兩側最優方案再取 k 必可行。
  枚舉所有 k 即精確涵蓋最優解；由短區間到長區間歸納成立。
common_errors: [把 k 當第一張取而非最後一張取, 允許取走原始首尾牌, 乘積未在相鄰關係更新後計算]

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <limits>
  #include <vector>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false); cin.tie(nullptr);
      int n = 0; cin >> n;
      vector<int> card(static_cast<size_t>(n));
      for (int& value : card) cin >> value;
      vector<vector<int>> dp(static_cast<size_t>(n), vector<int>(static_cast<size_t>(n), 0));
      for (int length = 2; length < n; ++length) {
          for (int left = 0; left + length < n; ++left) {
              const int right = left + length;
              dp[static_cast<size_t>(left)][static_cast<size_t>(right)] = numeric_limits<int>::max();
              for (int middle = left + 1; middle < right; ++middle) {
                  const int candidate = dp[static_cast<size_t>(left)][static_cast<size_t>(middle)] +
                      dp[static_cast<size_t>(middle)][static_cast<size_t>(right)] +
                      card[static_cast<size_t>(left)] * card[static_cast<size_t>(middle)] *
                      card[static_cast<size_t>(right)];
                  dp[static_cast<size_t>(left)][static_cast<size_t>(right)] =
                      min(dp[static_cast<size_t>(left)][static_cast<size_t>(right)], candidate);
              }
          }
      }
      cout << dp[0][static_cast<size_t>(n - 1)] << '\n';
  }
