statement: >-
  城市是 n×m 高度網格，水利設施只能建在第一列。水可從較高格流向四鄰中嚴格較低的格。
  先判斷最下列是否每個城市都能獲水；若可以，再求最少需要建設的第一列設施數。
constraints:
  - 1 <= n, m <= 500
  - 1 <= h_(i,j) <= 10^6
  - 水只能流向高度嚴格較低的四鄰格
input_format: 第一行 n、m；接著 n 行各有 m 個高度。
output_format: 若不能覆蓋最下列，先輸出 0，再輸出未覆蓋城市數；否則先輸出 1，再輸出最少設施數。
samples:
  - input: |
      3 3
      1 5 1
      3 4 3
      1 2 1
    output: |
      1
      1
    explanation: 從第一列中央的高度 5 出發，可經高度 4 分流到兩側高度 3，最後覆蓋底列三格。
core_knowledge:
  - 依高度由低到高計算每格可到達的底列區間
  - 以最少區間覆蓋連續底列
judgment: 底列城市也能繼續向更低鄰格流動；只有第一列可建設施，且每個設施供水量無限。
hints:
  - 把每格能到達的最左、最右底列欄號記成一個區間；底列格先初始化為自身欄號。
  - 依高度遞增處理格子，從所有較低鄰格合併最左與最右端點；這與水流方向相反的 DP 次序一致。
  - 若底列全覆蓋，將第一列區間按左端點使用貪心：在目前位置可接上的區間中選右端最遠者。
solution_outline: >-
  將所有格依高度排序。底列格區間初始化為 [column,column]；每格合併所有較低鄰格已算好的區間。
  先以第一列區間標記底列覆蓋，若有缺口輸出其數量。否則對第一列有效區間做標準最少區間覆蓋貪心。
proof_or_invariant: >-
  高度嚴格下降使水流圖為 DAG。處理某格時，其所有出邊終點高度較低且區間已正確；
  可達底列集合是各終點集合的聯集。此地形下由一格到達的底列欄形成連續區間，因此合併端點得到精確區間。
  第一列設施等價於選區間覆蓋 1..m。貪心每步選所有左端不超過目前未覆蓋位置者中右端最遠的區間；
  任一最優解當步所選區間右端不會更遠，交換為貪心區間不增加後續需求，故設施數最少。
complexity:
  time: O(nm log(nm))
  space: O(nm)
common_errors:
  - 允許流到相同高度的鄰格
  - 未先輸出不能覆蓋時的未覆蓋底列數
  - 區間覆蓋時只按左端排序後逐個選，未取可用區間的最大右端

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n, m;
      cin >> n >> m;
      vector<vector<int>> height(n, vector<int>(m));
      vector<tuple<int, int, int>> cells;
      for (int row = 0; row < n; ++row) {
          for (int column = 0; column < m; ++column) {
              cin >> height[row][column];
              cells.push_back({height[row][column], row, column});
          }
      }
      sort(cells.begin(), cells.end());
      const int inf = m + 1;
      vector<vector<int>> left(n, vector<int>(m, inf));
      vector<vector<int>> right(n, vector<int>(m, -1));
      for (int column = 0; column < m; ++column) {
          left[n - 1][column] = column;
          right[n - 1][column] = column;
      }
      constexpr array<int, 4> dr{-1, 1, 0, 0};
      constexpr array<int, 4> dc{0, 0, -1, 1};
      vector<vector<bool>> reachable(n, vector<bool>(m, false));
      queue<pair<int, int>> pending;
      for (int column = 0; column < m; ++column) {
          reachable[0][column] = true;
          pending.push({0, column});
      }
      while (!pending.empty()) {
          const auto [row, column] = pending.front();
          pending.pop();
          for (int direction = 0; direction < 4; ++direction) {
              const int next_row = row + dr[direction];
              const int next_column = column + dc[direction];
              if (next_row < 0 || next_row >= n || next_column < 0 || next_column >= m
                  || reachable[next_row][next_column]
                  || height[next_row][next_column] >= height[row][column]) continue;
              reachable[next_row][next_column] = true;
              pending.push({next_row, next_column});
          }
      }
      for (const auto& [value, row, column] : cells) {
          for (int direction = 0; direction < 4; ++direction) {
              const int next_row = row + dr[direction];
              const int next_column = column + dc[direction];
              if (next_row < 0 || next_row >= n || next_column < 0 || next_column >= m
                  || height[next_row][next_column] >= value) continue;
              left[row][column] = min(left[row][column], left[next_row][next_column]);
              right[row][column] = max(right[row][column], right[next_row][next_column]);
          }
      }
      vector<pair<int, int>> intervals;
      for (int column = 0; column < m; ++column) {
          if (right[0][column] < 0) continue;
          intervals.push_back({left[0][column], right[0][column]});
      }
      int missing = 0;
      for (int column = 0; column < m; ++column) {
          if (!reachable[n - 1][column]) ++missing;
      }
      if (missing > 0) {
          cout << "0\n" << missing << '\n';
          return 0;
      }
      sort(intervals.begin(), intervals.end());
      int position = 0, index = 0, answer = 0;
      while (position < m) {
          int farthest = position - 1;
          while (index < static_cast<int>(intervals.size()) && intervals[index].first <= position) {
              farthest = max(farthest, intervals[index].second);
              ++index;
          }
          ++answer;
          position = farthest + 1;
      }
      cout << "1\n" << answer << '\n';
  }
