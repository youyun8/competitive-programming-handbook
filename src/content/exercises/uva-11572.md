statement: |-
  雪花依固定順序流過機器，每片以整數編號識別，相同編號代表相同雪花。包裝一旦開始，直到封箱前經過的雪花都必須裝入，因此一箱必為原序列的一段連續區間。求能選出的最長區間，使其中編號兩兩不同。

output_format: 每組輸出一行，表示不含重複編號的最長連續區間長度。

hints:
  - '掃到重複編號時，新的合法區間最早能從哪裡開始？'
  - '用表保存每個編號上一次出現的索引；只有該索引仍在目前視窗內時才推進左界。'
  - '讀到位置 right 的 id 時，令 left=max(left,last[id]+1)，再更新 last[id]=right 與答案 right-left+1。'
solution_outline: 逐一讀取雪花。以 unordered_map 保存每個編號最後一次出現的索引，left 為目前不重複視窗左界。若當前編號曾在 left 之後出現，就把 left 跳到舊位置下一格；更新最後位置與最大視窗長度。
proof_or_invariant: '處理每個 right 後，[left,right] 中沒有重複。若當前值上次出現在 p≥left，任何以不大於 p 為左界且包含 right 的區間都重複，故 left 至少須為 p+1；跳到 p+1 又只移除舊副本，能保持合法。若 p<left 則舊副本不在視窗，無須後退。因 left 是各 right 下最小合法左界，記錄的長度是該 right 結尾的最大合法長度，取最大即為答案。'

  - '把不連續的相異值集合當成答案'
  - '為 0 到 10^9 的所有編號配置陣列'
  - '忽略所有測試組合計可達一百萬筆，使用平方掃描'

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <unordered_map>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int test_count = 0;
      cin >> test_count;
      while (test_count-- > 0) {
          int n = 0;
          cin >> n;
          unordered_map<long long, int> last_position;
          last_position.reserve(static_cast<size_t>(n) * 2U + 1U);
          int left = 0;
          int answer = 0;
          for (int right = 0; right < n; ++right) {
              long long snowflake_id = 0;
              cin >> snowflake_id;
              const auto found = last_position.find(snowflake_id);
              if (found != last_position.end() && found->second >= left) {
                  left = found->second + 1;
              }
              last_position[snowflake_id] = right;
              answer = max(answer, right - left + 1);
          }
          cout << answer << '\n';
      }
      return 0;
  }
