statement: 給定從某個無限循環訊息中截取的長度 n 字串，求原始循環訊息可能的最短長度。
constraints:
  - '1 <= n <= 10^6'

input_format: 第一行為 n，第二行為接收到的字串。
output_format: 輸出最短循環訊息長度。
samples:
  - input: |-
      8
      cabcabca
    output: '3'
    explanation: 輸入是無限重複 `cab` 的連續八個字元，因此長度 3 可行，且不存在更短週期。
core_knowledge:
  - KMP 前綴函數給出整串最長真前綴兼後綴
  - 對有限截段而言，週期不必整除 n
  - 最短週期長度為 n-pi[n-1]
judgment: 只輸出最短長度；這是無限週期的截段問題，不能額外要求週期長度整除 n。
hints:
  - 若長度 p 是週期，位置 p 之後的字元會與前面相距 p 的字元相同。
  - 這代表字串前 n-p 個字元等於後 n-p 個字元；請找最長的前綴兼後綴。
  - 用 KMP 前綴函數求其長度 pi[n-1]，答案就是沒有被重疊覆蓋的 n-pi[n-1]。
solution_outline: 計算字串的 KMP 前綴函數，輸出 n 減去最後一個前綴函數值。
proof_or_invariant: >-
  設 b=pi[n-1]，則 s[0..b-1]=s[n-b..n-1]，所以 p=n-b 滿足所有可比較位置
  s[i]=s[i-p]，可作為循環長度。若有更短週期 q，便會產生長度 n-q>b 的前綴兼後綴，
  與 b 的最大性矛盾，故 p 最短。
common_errors:
  - 誤加 n%p==0 條件；輸入只是一段截取，不必含整數個週期
  - 使用 pi[n] 而非 pi[n-1]
  - O(n^2) 枚舉並逐一比較候選週期
complexity:
  time: O(n)
  space: O(n)

cpp_solution: |
  #include <iostream>
  #include <string>
  #include <vector>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n = 0;
      string text;
      cin >> n >> text;
      vector<int> prefix(static_cast<size_t>(n), 0);
      for (int i = 1; i < n; ++i) {
          int matched = prefix[static_cast<size_t>(i - 1)];
          while (matched > 0 && text[static_cast<size_t>(i)] != text[static_cast<size_t>(matched)]) {
              matched = prefix[static_cast<size_t>(matched - 1)];
          }
          if (text[static_cast<size_t>(i)] == text[static_cast<size_t>(matched)]) { ++matched; }
          prefix[static_cast<size_t>(i)] = matched;
      }
      cout << n - prefix.back() << '\n';
      return 0;
  }
