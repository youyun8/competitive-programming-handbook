  n 堆石子環形排列。每次只能合併相鄰兩堆，得分為新堆石子數；重複至剩一堆。
  分別求可能的最小與最大總得分。

hints:
  - 把序列複製一遍，任一環形切點都對應長度 n 的線性區間。
  - 固定區間 [l,r]，最後一次合併必把它切成 [l,k] 與 [k+1,r]。
  - 用前綴和 O(1) 求區間總石子數，同時計算最小與最大 DP，最後枚舉起點。
solution_outline: 將陣列加倍，按區間長度枚舉切點，以兩側成本加區間和更新最小值與最大值。
proof_or_invariant: >-
  任一區間合併方案的最後一步會合併兩個連續子區間，先前操作分別構成兩側的完整方案，因此成本
  等於兩側成本加整段石子和；反之任一切點的兩側方案都能如此合併。枚舉切點得到區間精確極值。
  加倍陣列的每個長度 n 區間對應環的一個切點，而每個環形方案最後必有一條被切開的邊，故枚舉
  所有起點後的全局最小、最大值正確。

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <limits>
  #include <vector>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false); cin.tie(nullptr);
      int n = 0; cin >> n;
      const int size = 2 * n;
      vector<int> prefix(static_cast<size_t>(size + 1), 0);
      for (int i = 1; i <= n; ++i) {
          int value = 0; cin >> value;
          prefix[static_cast<size_t>(i)] = value;
          prefix[static_cast<size_t>(i + n)] = value;
      }
      for (int i = 1; i <= size; ++i)
          prefix[static_cast<size_t>(i)] += prefix[static_cast<size_t>(i - 1)];
      vector<vector<int>> minimum(static_cast<size_t>(size + 1),
                                  vector<int>(static_cast<size_t>(size + 1), 0));
      vector<vector<int>> maximum = minimum;
      for (int length = 2; length <= n; ++length) for (int left = 1; left + length - 1 <= size; ++left) {
          const int right = left + length - 1;
          minimum[static_cast<size_t>(left)][static_cast<size_t>(right)] = numeric_limits<int>::max();
          const int sum = prefix[static_cast<size_t>(right)] - prefix[static_cast<size_t>(left - 1)];
          for (int split = left; split < right; ++split) {
              minimum[static_cast<size_t>(left)][static_cast<size_t>(right)] =
                  min(minimum[static_cast<size_t>(left)][static_cast<size_t>(right)],
                      minimum[static_cast<size_t>(left)][static_cast<size_t>(split)] +
                      minimum[static_cast<size_t>(split + 1)][static_cast<size_t>(right)] + sum);
              maximum[static_cast<size_t>(left)][static_cast<size_t>(right)] =
                  max(maximum[static_cast<size_t>(left)][static_cast<size_t>(right)],
                      maximum[static_cast<size_t>(left)][static_cast<size_t>(split)] +
                      maximum[static_cast<size_t>(split + 1)][static_cast<size_t>(right)] + sum);
          }
      }
      int best_min = numeric_limits<int>::max(), best_max = 0;
      for (int left = 1; left <= n; ++left) {
          best_min = min(best_min, minimum[static_cast<size_t>(left)][static_cast<size_t>(left + n - 1)]);
          best_max = max(best_max, maximum[static_cast<size_t>(left)][static_cast<size_t>(left + n - 1)]);
      }
      cout << best_min << '\n' << best_max << '\n';
  }
