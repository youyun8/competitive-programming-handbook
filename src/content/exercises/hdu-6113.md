title: HDU 6113 度度熊的 01 世界
section: '3.3'
statement: 判斷 01 圖是否為數字 0、1 或皆非。兩者都要求 1 恰一個四連通塊；0 還要求恰一個不接邊界的 0 塊，1 則沒有被包圍的 0 塊。
constraints:
  - 1 <= n,m <= 100
  - 多組資料讀至 EOF
  - 連通只計公共邊
judge: 只有不接觸圖邊界的 0 連通塊算被 1 完全包圍。
hints:
  - 先計算 1 的四連通塊數，必須恰為一。
  - 把圖外圍補一圈 0，計算擴張圖中的 0 連通塊。
  - 零塊數為一代表無洞，為二代表一個洞；其他皆不合法。
input_format: 每組 n、m，後接 n 行 01 字串。
output_format: 依分類輸出 0、1 或 -1。
samples:
  - input: |
      3 3
      111
      101
      111
      3 3
      010
      010
      010
      3 3
      101
      101
      011
    output: |-
      0
      1
      -1
    explanation: 三圖分別有一個洞、無洞、以及 1 不連通。
core_knowledge:
  - 二值連通分量
  - 邊界外部零區
solution_outline: 在補零邊框的圖上分別 flood fill 0 與 1 並分類。
proof_or_invariant: 補上的邊框把所有接邊界零格合成唯一外部塊，每個其餘零塊恰是一個洞；配合唯一 1 塊即與定義等價。
complexity:
  time: O(nm)
  space: O(nm)
common_errors:
  - 不補邊框導致多個外部零塊
  - 用八連通
  - 未要求 1 存在
