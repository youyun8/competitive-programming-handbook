core_knowledge: [四連通分量, 外部背景, 補邊框]
judgment: 只採上下左右連通；接觸原圖邊界的 `0` 都屬外部背景，不算洞。
hints:
  - 先計算 `1` 的四連通分量，必須恰為一個。
  - 在原圖外補一圈 `0`，由外框 flood-fill 即可標出所有外部背景。
  - 剩下未訪問的 `0` 分量數為洞數：0 個輸出 1，1 個輸出 0，其他輸出 -1。
solution_outline: 補零邊框後分別統計 `1` 分量與不含外部背景的 `0` 分量，依 `(1 分量,洞數)` 分類。
proof_or_invariant: 外框 flood-fill 恰涵蓋所有能沿零格通往圖外的背景；其餘每個零分量都被一格邊界內的 `1` 隔離，恰是一個洞。配合唯一的 `1` 分量，分類條件與題目定義等價。
complexity: { time: 'O(nm)', space: 'O(nm)' }
