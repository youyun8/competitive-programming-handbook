statement: n 座城市各有座標與人口。需以直線道路連成樹，其中恰有一條道路可免費建造。若免費道路兩端人口和為 A、其餘道路總長為 B，求 A/B 的最大值。
constraints: [1 <= T <= 10, 2 < n <= 1000, 0 <= x, y <= 1000, 0 < population < 100000, 城市座標互異]
input_format: 第一行 T；每組先給 n，接著 n 行 x、y、population。
output_format: 每組輸出最大比值，四捨五入至小數點後兩位。
samples:
  - input: |
      1
      3
      0 0 1
      1 0 2
      0 1 3
    output: |
      5.00
    explanation: 最小生成樹總長 2；免費連接人口 2 與 3 的城市，替換路徑上一條長度 1 的邊，其他道路長度為 1，故比值 5。自製範例已枚舉三點所有樹核對。
core_knowledge: [完全圖 Prim, MST 換邊性質, 樹上 minimax]
judgment: 固定免費邊後，最優其餘邊可由一棵 MST 移除該邊兩端樹路徑上的最大權邊得到。
hints:
  - 先在城市完全圖上求一棵 MST，記總長 sum。
  - 對每對城市 i、j，若把 ij 免費加入，應刪除 MST 中 i 到 j 路徑的最長邊。
  - 在 Prim 加入新點時，可用 max_on_path[new][v]=max(連父邊, max_on_path[parent][v]) 求出所有點對路徑最大邊。
solution_outline: O(n²) Prim 建 MST 並記每點父邊。每加入頂點 u，就由其父節點更新 u 到所有既有頂點的路徑最大邊。最後枚舉所有 i<j，計算 (population[i]+population[j])/(mst_sum-max_on_path[i][j]) 的最大值。
proof_or_invariant: 加入任意非樹邊 ij 會形成唯一環。若要求生成樹包含 ij，刪除環上最大的原 MST 邊可得最小總長；否則以更輕替換邊即可改進原 MST，矛盾。免費後其餘道路長即 mst_sum 減該最大邊。枚舉所有免費邊便涵蓋所有方案。
common_errors:
  [分母誤減歐氏距離 ij 而非樹路徑最大邊, Prim 更新路徑矩陣時使用尚未入樹的點, 輸出精度不是兩位, 距離使用 int]

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;
  struct City { double x, y; int population; };
  int main() {
      ios::sync_with_stdio(false); cin.tie(nullptr);
      int tests; cin >> tests;
      cout << fixed << setprecision(2);
      while (tests--) {
          int n; cin >> n;
          vector<City> city(static_cast<size_t>(n));
          for (auto& value : city) cin >> value.x >> value.y >> value.population;
          vector<vector<double>> distance(static_cast<size_t>(n), vector<double>(static_cast<size_t>(n)));
          for (int i = 0; i < n; ++i) for (int j = i + 1; j < n; ++j) {
              distance[static_cast<size_t>(i)][static_cast<size_t>(j)] = distance[static_cast<size_t>(j)][static_cast<size_t>(i)] =
                  hypot(city[static_cast<size_t>(i)].x - city[static_cast<size_t>(j)].x, city[static_cast<size_t>(i)].y - city[static_cast<size_t>(j)].y);
          }
          const double infinity = numeric_limits<double>::infinity();
          vector<double> best(static_cast<size_t>(n), infinity);
          vector<int> parent(static_cast<size_t>(n), -1);
          vector<char> used(static_cast<size_t>(n));
          vector<vector<double>> path_max(static_cast<size_t>(n), vector<double>(static_cast<size_t>(n)));
          best[0] = 0; double mst_sum = 0;
          for (int step = 0; step < n; ++step) {
              int u = -1;
              for (int i = 0; i < n; ++i) if (!used[static_cast<size_t>(i)] && (u < 0 || best[static_cast<size_t>(i)] < best[static_cast<size_t>(u)])) u = i;
              used[static_cast<size_t>(u)] = 1; mst_sum += best[static_cast<size_t>(u)];
              if (parent[static_cast<size_t>(u)] >= 0) {
                  int p = parent[static_cast<size_t>(u)];
                  for (int v = 0; v < n; ++v) if (used[static_cast<size_t>(v)] && v != u)
                      path_max[static_cast<size_t>(u)][static_cast<size_t>(v)] = path_max[static_cast<size_t>(v)][static_cast<size_t>(u)] =
                          max(best[static_cast<size_t>(u)], path_max[static_cast<size_t>(p)][static_cast<size_t>(v)]);
              }
              for (int v = 0; v < n; ++v) if (!used[static_cast<size_t>(v)] && distance[static_cast<size_t>(u)][static_cast<size_t>(v)] < best[static_cast<size_t>(v)]) {
                  best[static_cast<size_t>(v)] = distance[static_cast<size_t>(u)][static_cast<size_t>(v)]; parent[static_cast<size_t>(v)] = u;
              }
          }
          double answer = 0;
          for (int i = 0; i < n; ++i) for (int j = i + 1; j < n; ++j)
              answer = max(answer, (city[static_cast<size_t>(i)].population + city[static_cast<size_t>(j)].population) /
                                   (mst_sum - path_max[static_cast<size_t>(i)][static_cast<size_t>(j)]));
          cout << answer + 1e-9 << '\n';
      }
  }
