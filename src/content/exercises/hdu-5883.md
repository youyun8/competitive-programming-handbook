statement: >-
  有 n 座湖與 m 條雙向河流，每座湖 i 有數值 a_i。選一座湖出發，安排一條恰好經過每條
  河流一次的路徑 P_0,P_1,...,P_m，其幸運值為沿途所有湖泊數值的 XOR。求可得的最大
  幸運值；若不存在這種路徑則回報不可能。
constraints: [1 <= n <= 100000, 1 <= m <= 500000, 0 <= a_i <= 10000, 1 <= u_i, v_i <= n, 允許 u_i = v_i 的自環與重邊]
input_format: >-
  第一行為測試組數 t。每組先給 n m，接著 n 行依序給 a_i，再以 m 行給每條河流的兩端
  u_i v_i。
output_format: 每組輸出最大幸運值；若無法恰走每條河流一次，輸出 Impossible。
samples:
  - input: "2\n3 2\n3\n4\n5\n1 2\n2 3\n4 3\n1\n2\n3\n4\n1 2\n2 3\n2 4\n"
    output: "2\nImpossible"
    explanation: 第一組唯一的端點為湖 1、3，路徑 1→2→3 的幸運值為 3 XOR 4 XOR 5=2；第二組有四個奇度湖，故不存在歐拉路徑。
core_knowledge: [非零度頂點連通且奇度點數為零或二, 頂點出現次數只需看度數與端點, XOR 偶數次抵消]
judgment: 自環為端點增加兩度；連通性只檢查有河流的湖。全偶度時起點可任選非零度湖，且該湖比其餘湖多出現一次。
hints:
  - 先以 DSU 檢查所有非零度湖是否連通，並統計奇度湖數是否為 0 或 2。
  - 有兩個奇度端點時，湖 i 在頂點序列中出現 (degree_i+1)/2 次，只需 XOR 出現奇數次者。
  - 全為偶度時先算每湖 degree_i/2 次的 XOR，再枚舉非零度湖作起點，把其 a_i 額外 XOR 一次並取最大值。
solution_outline: >-
  讀邊時以 DSU 合併端點並累加度數。若含邊頂點不連通，或奇度點數不是 0、2，輸出
  Impossible。兩奇點時依 (degree+1)/2 的奇偶累積 XOR；零奇點時依 degree/2 的奇偶
  求基底，再枚舉每個非零度起點，以 base XOR a_i 更新最大值。
proof_or_invariant: >-
  一條使用全部邊的無向歐拉跡存在，恰需所有非零度頂點連通且奇度點為零或二。兩奇點時，
  端點各有一次未配對的邊，其出現次數為 (degree+1)/2；其餘偶度點每次進出配成一組，
  出現 degree/2 次，亦等於 (degree+1)/2 的整數除法。故 XOR 值完全由這些次數奇偶
  決定，與具體走法無關。全偶度時所有非起點各出現 degree/2 次，起點因首尾相同而多出現
  一次；枚舉所有可作起點的非零度湖便涵蓋全部可能值，取最大者即最優。
common_errors:
  [
    把孤立湖算成另一個連通分量,
    全偶度時漏掉起點的額外一次,
    枚舉度數為零的湖作起點,
    自環只增加一度,
    真的建出長達 m 的路徑而增加不必要成本
  ]
complexity: { time: O((n + m)*alpha(n)), space: O(n) }
