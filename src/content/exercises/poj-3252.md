statement: 給起始字串 str1、結尾字串 str2；對每個長字串，找出以 str1 開頭且以 str2 結尾的最長連續子字串。

  - 長字串筆數由輸入 n 給定

output_format: 對每個長字串輸出一行找到的最長子字串，包含首尾模式。
samples:
  - input: |-
      ab
      ba
      3
      aab11234ab56ba789baba
      abababa
      adsjjafshabbajafkalf
    output: |-
      ab11234ab56ba789baba
      abababa
      abba
    explanation: 最長答案必從最早出現的 ab 開始，並在其後最晚出現的 ba 結束。

hints:
  - 若要讓區間最長，左端應取 str1 的最早出現位置。
  - 右端應取 str2 的最晚出現位置，並確認它不早於左模式結束所需位置。
  - 使用 find 與 rfind，再以 substr 擷取到右模式尾端。
solution_outline: 每行找 str1 的第一次出現與 str2 的最後一次出現，輸出兩者涵蓋的完整區間。
proof_or_invariant: >-
  任一合法答案左端是某次 str1 出現，改成更早的出現只會延長且仍以 str1 開頭；同理把右端改成
  更晚的 str2 出現只會延長且仍合法。因此最早 str1 與最晚 str2 所定區間支配所有其他合法區間。

cpp_solution: |
  #include <iostream>
  #include <string>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false); cin.tie(nullptr);
      string first, last; int n = 0; cin >> first >> last >> n;
      while (n-- > 0) {
          string text; cin >> text;
          const size_t left = text.find(first);
          const size_t right = text.rfind(last);
          cout << text.substr(left, right + last.size() - left) << '\n';
      }
  }
