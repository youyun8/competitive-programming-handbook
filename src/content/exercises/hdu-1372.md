statement: 在標準 8×8 西洋棋盤上，求騎士從給定方格走到另一方格的最少步數。
constraints: [欄為 a..h, 列為 1..8, 輸入含一組以上資料並讀至 EOF]
input_format: 每行兩個方格名稱，以空格分隔。
output_format: 每組嚴格輸出 `To get from xx to yy takes n knight moves.`。
samples:
  - input: |
      e2 e4
      a1 h8
      f6 f6
    output: |
      To get from e2 to e4 takes 2 knight moves.
      To get from a1 to h8 takes 6 knight moves.
      To get from f6 to f6 takes 0 knight moves.
    explanation: 起終點相同時答案為零。
core_knowledge: [單位權圖 BFS, 棋盤座標轉換]
judgment: 騎士每步在兩軸分別移動 1 與 2 格，共八種方向。
hints:
  - 把每個棋格當頂點，合法騎士步當單位權邊。
  - 將 `a1` 轉成 `(0,0)`，只加入兩座標都在 0..7 的鄰格。
  - 入隊時標記距離；第一次抵達終點就是最短步數。
solution_outline: 對每行輸入重新 BFS；距離陣列初始化為 -1，從起點展開八個合法方向。
proof_or_invariant: 每條 BFS 邊恰對應一次合法騎士移動，故路徑長等於步數。BFS 按距離非遞減展開，第一次設定終點距離時不存在更短路。
complexity: { time: O(64), space: O(64) }
common_errors: [座標字母與數字轉換錯一格, 未處理起終點相同, 輸出句點或原座標格式不符]

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;
  int main(){ios::sync_with_stdio(false);cin.tie(nullptr);string from,to;constexpr array<int,8>dx={1,1,2,2,-1,-1,-2,-2};constexpr array<int,8>dy={2,-2,1,-1,2,-2,1,-1};while(cin>>from>>to){array<array<int,8>,8>dist{};for(auto&row:dist)row.fill(-1);const int sx=from[0]-'a',sy=from[1]-'1',tx=to[0]-'a',ty=to[1]-'1';queue<pair<int,int>>q;dist[sx][sy]=0;q.push({sx,sy});while(!q.empty()){auto[x,y]=q.front();q.pop();for(int d=0;d<8;++d){int nx=x+dx[d],ny=y+dy[d];if(nx>=0&&nx<8&&ny>=0&&ny<8&&dist[nx][ny]<0){dist[nx][ny]=dist[x][y]+1;q.push({nx,ny});}}}cout<<"To get from "<<from<<" to "<<to<<" takes "<<dist[tx][ty]<<" knight moves.\n";}}
