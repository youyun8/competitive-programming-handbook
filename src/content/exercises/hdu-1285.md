statement: >-
  有 n 支隊伍，輸入若干已知勝負；a b 表示 a 勝 b，因此排名中 a 必須在 b 前。保證資料
  可形成合法排名。輸出一個符合全部結果的排名；同時可選多隊時優先使用較小編號。

output_format: 每組輸出一行 n 個隊伍編號，以空格分隔，且為字典序最小的合法排名。

hints:
  - 將 a 勝 b 建成 a→b。
  - 把所有目前入度為零的隊伍放入最小堆。
  - 每次取最小編號並刪除出邊；重複結果只能計一次入度。
solution_outline: 以布林矩陣去重，統計入度；Kahn 演算法的零入度集合使用最小堆，依序輸出。
proof_or_invariant: >-
  堆內恰是所有尚未排名且沒有未排前驅的合法候選。選最小候選不會破壞任何限制，且任何
  其他合法序列若此位選較大者，與最小候選交換可得到字典序更小序列；逐位歸納即為最小解。
common_errors: [把敗者指向勝者, 使用普通佇列導致非最小序, 重複邊重複增加入度, 輸出多餘前後空格]

      ios::sync_with_stdio(false);cin.tie(nullptr);int n=0,m=0;
      while(cin>>n>>m){
          vector<vector<bool>> edge(static_cast<size_t>(n+1),vector<bool>(static_cast<size_t>(n+1),false));vector<int> indegree(static_cast<size_t>(n+1),0);
          for(int i=0;i<m;++i){int a=0,b=0;cin>>a>>b;if(!edge[static_cast<size_t>(a)][static_cast<size_t>(b)]){edge[static_cast<size_t>(a)][static_cast<size_t>(b)]=true;++indegree[static_cast<size_t>(b)];}}
          priority_queue<int,vector<int>,greater<int>> ready;for(int v=1;v<=n;++v)if(indegree[static_cast<size_t>(v)]==0)ready.push(v);
          vector<int> order;while(!ready.empty()){int u=ready.top();ready.pop();order.push_back(u);for(int v=1;v<=n;++v)if(edge[static_cast<size_t>(u)][static_cast<size_t>(v)]&&--indegree[static_cast<size_t>(v)]==0)ready.push(v);}
          for(int i=0;i<n;++i)cout<<order[static_cast<size_t>(i)]<<(i+1==n?'\n':' ');
      }
  }
