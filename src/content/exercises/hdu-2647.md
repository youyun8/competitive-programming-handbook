statement: >-
  公司要給 n 名員工發獎金，每人至少 888。每條要求 a b 表示 a 的獎金必須嚴格高於 b。
  求滿足全部要求的最小獎金總額；若要求矛盾則輸出 -1。
constraints: [1 <= n <= 10000, 0 <= m <= 20000, 員工編號為 1 到 n, 輸入可含多組資料直到 EOF]
input_format: 每組第一行 n m，接著 m 行 a b，表示 reward[a] > reward[b]。
output_format: 每組輸出最小總額；存在矛盾時輸出 -1。
samples:
  - input: "2 1\n1 2\n"
    output: '1777'
    explanation: 令 2 號為最低的 888，1 號至少為 889，總和 1777。
core_knowledge: [嚴格不等式轉成加一邊, DAG 最長路, 拓撲動態規劃]
judgment: 每人的獎金是整數；相等不符合「高於」，所以每條邊至少增加 1。
hints:
  - a>b 應建立 b→a，表示 a 至少是 b+1。
  - 所有人先設 888，沿拓撲序做 reward[v]=max(reward[v],reward[u]+1)。
  - 若拓撲排序未處理全部員工，限制中存在環。
solution_outline: 反向建立低薪到高薪的邊，以 Kahn 拓撲排序更新每點可行的最低獎金並累加；有環輸出 -1。
proof_or_invariant: >-
  點 v 出隊時所有前驅已確定，max(888, max(reward[u]+1)) 是滿足進邊的最小整數；
  任何可行方案都不得低於此值。依拓撲歸納，所得各點同時可行且逐點最小，因此總和最小。
  有向環會要求某獎金嚴格大於自身，必定無解。
common_errors: [把 a→b 建成同方向, 只以拓撲層數而未取最長前驅, 基準誤設為 0, 有環仍輸出部分總和]
complexity: { time: O(n + m), space: O(n + m) }

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <queue>
  #include <vector>
  using namespace std;
  int main(){
      ios::sync_with_stdio(false);cin.tie(nullptr);int n=0,m=0;
      while(cin>>n>>m){
          vector<vector<int>> graph(static_cast<size_t>(n+1));vector<int> indegree(static_cast<size_t>(n+1),0),reward(static_cast<size_t>(n+1),888);
          for(int i=0;i<m;++i){int a=0,b=0;cin>>a>>b;graph[static_cast<size_t>(b)].push_back(a);++indegree[static_cast<size_t>(a)];}
          queue<int> ready;for(int v=1;v<=n;++v)if(indegree[static_cast<size_t>(v)]==0)ready.push(v);
          int processed=0;long long total=0;
          while(!ready.empty()){int u=ready.front();ready.pop();++processed;total+=reward[static_cast<size_t>(u)];for(int v:graph[static_cast<size_t>(u)]){reward[static_cast<size_t>(v)]=max(reward[static_cast<size_t>(v)],reward[static_cast<size_t>(u)]+1);if(--indegree[static_cast<size_t>(v)]==0)ready.push(v);}}
          cout<<(processed==n?total:-1)<<'\n';
      }
  }
