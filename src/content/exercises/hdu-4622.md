statement: 給定小寫字串與多個區間 [l,r]，每次詢問子串 s[l..r] 中有多少種本質不同的非空子串。
constraints:
  - '1 <= T <= 5'
  - '1 <= |s| <= 2000'
  - 每組詢問數不超過 10000，且 1 <= l <= r <= |s|
input_format: 第一行 T；每組先給 s，再給 Q，接著 Q 行 l r。
output_format: 每筆詢問輸出一行不同子串數。
samples:
  - input: "1\nababa\n3\n1 1\n1 3\n2 4\n"
    output: "1\n5\n5\n"
    explanation: >-
      `aba` 的不同子串為 a、b、ab、ba、aba 共五種；`bab` 同樣有五種。
core_knowledge: [SAM 狀態的長度區間, 插入字元新增 len-last 減 len-link 個子串, O(n^2) 預處理區間答案]
judgment: 區間為 1-based 且含左右端點；相同內容不論出現幾次只計一種。
hints:
  - 對固定左端 l，依次把 s[l]、s[l+1]…加入一個新的後綴自動機。
  - SAM 每加入一字元，新產生的不同子串數是 len[last]-len[link[last]]。
  - 將累計值存成 answer[l][r]；n 僅 2000，O(n^2) 預處理後每次 O(1) 回答。
solution_outline: 枚舉左端點並清空 SAM，向右逐字擴展；每次把新 last 狀態的長度貢獻加入 distinct，存入二維答案表。
proof_or_invariant: SAM 狀態 v 代表長度 (len(link[v]),len(v)] 的新 endpos 等價類；擴展後以新位置結尾且首次出現的子串恰由 last 的這段長度區間表示，所以增量公式正確。固定 l 逐步擴展時累計值即 s[l..r] 的不同子串數。
common_errors: [不同左端點之間未清空 SAM, clone 也錯誤增加新子串數, 查詢下標未轉成 0-based]

  time: O(n^2 + Q)
  space: O(n^2)
