statement: >-
  有一個未知的 n 項整數序列，依序收到 m 條區間和陳述 `(l,r,s)`，表示第 l 項到第 r
  項之和為 s。陳述按輸入順序判斷：若它與先前所有被接受的陳述矛盾，就把它算作錯誤並忽略；
  否則接受它，供後續判斷。求錯誤陳述總數。
constraints:
  - 1 <= n <= 200000
  - 1 <= m <= 40000
  - 0 < l <= r <= n
  - 任一連續子序列的和保證落在 32 位元有號整數範圍
  - 官方時限為 1000 ms（非 Java），記憶體限制為 32768 KB
input_format: >-
  輸入可能有多筆資料，讀到 EOF。每筆先給 n、m，接著 m 行各有 l、r、s，
  表示閉區間 [l,r] 的和被回答為 s。
output_format: 每筆資料輸出一行整數，表示依序判定後被忽略的錯誤回答數。
samples:
  - input: |
      10 5
      1 10 100
      7 10 28
      1 3 32
      4 6 41
      6 6 1
    output: '1'
    explanation: >-
      前四條可共同成立，且可推出第 1 到第 6 項總和為 72；結合其他已接受關係後，
      最後一條所聲稱的值造成矛盾，因此錯誤數為 1。
core_knowledge:
  - 區間和可改寫為兩個前綴和的差
  - 帶權並查集維護同一連通分量內節點間的固定差值
  - 矛盾陳述必須忽略，不能加入後影響後續判定
judgment: >-
  對每條陳述只與先前「已接受」陳述比較；若兩端尚無可推導關係，該陳述總能被接受並連接兩個分量。
hints:
  - 令 prefix[i] 為前 i 項總和，則 [l,r] 的和可寫成哪兩個 prefix 的差？
  - 把 prefix[l-1] 與 prefix[r] 視為節點；並查集的邊權可記錄「本節點值減父節點值」。
  - 路徑壓縮時累加權值。若兩端同根，檢查 weight[r]-weight[l-1] 是否等於 s；不同根時依該等式設定新根的權值。
solution_outline: >-
  建立節點 0 到 n，節點 i 的值代表 prefix[i]。並查集令 weight[x] 為
  prefix[x]-prefix[parent[x]]；find_root 路徑壓縮後，weight[x] 便是
  prefix[x]-prefix[root]。對陳述 `(l,r,s)` 改用節點 `l-1` 與 r。
  若兩端同根，可直接計算 prefix[r]-prefix[l-1] 並判斷；不符時累加錯誤且不修改結構。
  若根不同，就依等式設定兩根之間的權值並合併。
proof_or_invariant: >-
  不變量是：每個節點 x 的 weight[x] 等於 prefix[x]-prefix[parent[x]]，因此沿父鏈相加可得
  x 與代表元的前綴和差。路徑壓縮把父節點改成代表元時，同時把舊父節點到代表元的差加上，
  故不變量保持。若兩端同根，它們的差已由已接受陳述唯一決定，只有等於 s 才相容；
  不等時忽略即可保持一致。若兩端根不同，兩個分量間尚無限制，設定根間差使
  prefix[r]-prefix[l-1]=s 後合併，所有原分量內差值皆未改變且新等式成立。
  依輸入順序歸納，並查集恰表示全部已接受陳述，所以計數正確。
common_errors:
  - 直接連接 l 與 r，忘記閉區間應改成前綴節點 l-1 與 r
  - 路徑壓縮只更新 parent，沒有先保存舊父節點並累加其權值
  - 根相同但矛盾時仍執行合併或改權，污染後續判定
  - 合併公式的方向顛倒；應先明確定義 weight[x] 是 x 減 parent[x]
complexity:
  time: O((n + m) alpha(n)) 每筆資料
  space: O(n)

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  class WeightedDisjointSet {
  public:
      explicit WeightedDisjointSet(int n)
          : parent_(static_cast<size_t>(n + 1)),
            weight_(static_cast<size_t>(n + 1), 0) {
          iota(parent_.begin(), parent_.end(), 0);
      }

      int find_root(int node) {
          const int parent = parent_[static_cast<size_t>(node)];
          if (parent != node) {
              parent_[static_cast<size_t>(node)] = find_root(parent);
              weight_[static_cast<size_t>(node)] +=
                  weight_[static_cast<size_t>(parent)];
          }
          return parent_[static_cast<size_t>(node)];
      }

      bool accept(int left, int right, long long sum) {
          const int left_root = find_root(left);
          const int right_root = find_root(right);
          if (left_root == right_root) {
              return weight_[static_cast<size_t>(right)] -
                         weight_[static_cast<size_t>(left)] ==
                     sum;
          }

          parent_[static_cast<size_t>(right_root)] = left_root;
          weight_[static_cast<size_t>(right_root)] =
              sum + weight_[static_cast<size_t>(left)] -
              weight_[static_cast<size_t>(right)];
          return true;
      }

  private:
      vector<int> parent_;
      vector<long long> weight_;
  };

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      int n, m;
      while (cin >> n >> m) {
          WeightedDisjointSet dsu(n);
          int wrong_count = 0;
          for (int query = 0; query < m; ++query) {
              int left, right;
              long long sum;
              cin >> left >> right >> sum;
              if (!dsu.accept(left - 1, right, sum)) {
                  ++wrong_count;
              }
          }
          cout << wrong_count << '\n';
      }
  }
