title: HDU 1240 Asteroids!
section: '3.3'
statement: 在 N×N×N 小行星場中，O 可通行、X 不可通行；每步改變一個座標 ±1，求指定起終點最少步數。
constraints:
  - 1 <= N <= 10
  - 資料集最多 100 組
  - 起終點皆為 O
judge: 輸入座標順序是欄 x、列 y、切片 z。
hints:
  - 把 (x,y,z) 視為節點。
  - 六個後繼只改一個座標，且必須界內為 O。
  - 距離初值 -1，第一次到終點即最短。
input_format: 每組以 `START N` 開始，接 N 層各 N 行，再給起點、終點及 END；讀至 EOF。
output_format: 可達輸出 `N steps`，否則 `NO ROUTE`。
samples:
  - input: |
      START 1
      O
      0 0 0
      0 0 0
      END
      START 3
      XXX
      XXX
      XXX
      OOO
      OOO
      OOO
      XXX
      XXX
      XXX
      0 0 1
      2 2 1
      END
    output: |-
      1 0
      3 4
    explanation: 第一組起終點相同；第二組在中間切片走四步。
core_knowledge:
  - 三維 BFS
  - 座標與輸入切片對應
solution_outline: 讀取切片為 grid[z][y][x]，從起點做六方向 BFS。
proof_or_invariant: 六方向邊與合法一步一一對應且等權，BFS 的首次到達距離因此最短。
complexity:
  time: O(N^3)
  space: O(N^3)
common_errors:
  - 弄反 x,y,z
  - 漏掉上下切片
  - 輸出格式缺少 N
