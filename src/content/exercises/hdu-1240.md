statement: 在 N×N×N 小行星空間中，`O` 為空、`X` 為障礙。太空船每步可沿任一座標軸正負方向移動一格，求起點到終點的最少步數。
constraints: [資料組數不超過 100, '1 <= N <= 10', 起終點皆為空格]
input_format: 每組以 `START N` 開始，接 N 個切面、每面 N 行；再給起點與終點三座標，最後一行 `END`。
output_format: 可達時輸出 `N 最少步數`，不可達輸出 `NO ROUTE`。
samples:
  - input: "START 1\nO\n0 0 0\n0 0 0\nEND\n"
    output: '1 0'
    explanation: 起點就是終點，不需移動。
core_knowledge: [三維座標映射, 六方向 BFS, 最短路]
judgment: 輸入座標順序是欄、列、切面；網格讀取順序則是切面、列、欄。
hints:
  - 將 `(x,y,z)` 對應到 `grid[z][y][x]`，避免座標軸讀反。
  - 從起點做六方向 BFS，第一次抵達終點即為最短步數。
  - '`START` 與 `END` 是每組資料的固定標記，也要從輸入流讀掉。'
solution_outline: 讀入立方網格，以三維距離陣列判重，從起點 BFS 所有界內 `O` 格並輸出終點距離。
proof_or_invariant: BFS 僅生成合法六鄰邊，且依步數非遞減出隊；因此首次設定每格距離時就是起點到該格的最短距離，終點未被設定恰表示無路。
complexity: { time: 'O(N^3)', space: 'O(N^3)' }
common_errors: [把座標順序當成切面列欄, 漏讀 START 或 END, 無路時仍輸出 N]

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;
  struct Point{int x,y,z;};
  int main(){ios::sync_with_stdio(false);cin.tie(nullptr);string marker;int n;while(cin>>marker>>n){vector<vector<string>> grid(n,vector<string>(n));for(int z=0;z<n;++z)for(int y=0;y<n;++y)cin>>grid[z][y];Point start,target;cin>>start.x>>start.y>>start.z>>target.x>>target.y>>target.z>>marker;vector distance(n,vector(n,vector<int>(n,-1)));queue<Point> pending;pending.push(start);distance[start.z][start.y][start.x]=0;constexpr int dx[6]={1,-1,0,0,0,0},dy[6]={0,0,1,-1,0,0},dz[6]={0,0,0,0,1,-1};while(!pending.empty()){Point p=pending.front();pending.pop();for(int d=0;d<6;++d){Point q{p.x+dx[d],p.y+dy[d],p.z+dz[d]};if(q.x<0||q.x>=n||q.y<0||q.y>=n||q.z<0||q.z>=n||grid[q.z][q.y][q.x]=='X'||distance[q.z][q.y][q.x]>=0)continue;distance[q.z][q.y][q.x]=distance[p.z][p.y][p.x]+1;pending.push(q);}}int answer=distance[target.z][target.y][target.x];if(answer<0)cout<<"NO ROUTE\n";else cout<<n<<' '<<answer<<'\n';}}
