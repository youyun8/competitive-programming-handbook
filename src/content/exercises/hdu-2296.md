statement: 每個模式有正權值；一個長度不超過 N 的小寫字串，其分數是各模式「重疊出現次數×權值」之和。輸出最高分字串；同分先選最短，再選字典序最小，可為空串。

  - input: "1\n2 1\na\n1\n"
    output: aa
    explanation: aa 使模式 a 出現兩次，分數 2 為最大；另以枚舉小 N、小字母表全部候選對拍。
core_knowledge: [AC 加權輸出, 定長狀態 DP, 多重 tie-break]
judgment: 出現可重疊；比較順序是分數最大、長度最短、字典序最小，空字串合法。
hints:
  - 終點加上模式權值，建 fail 時再累加 fail 的輸出權值。
  - 固定長度下，dp[state] 保存到達該狀態的最高分與字典序最小前綴。
  - 每完成一個長度就與全域答案比較；全域同分時先比長度，再比字典序。
solution_outline: 建加權 AC。由空字串開始逐層轉移 26 字元，同一長度與末態只留最佳分及最小字串；每層所有末態再按題目三層順序更新總答案。
proof_or_invariant: 固定長度、末態相同的兩個前綴，未來任意後綴帶來的轉移與增分完全相同，因此只保留分數較高、同分字典序較小者不會損失最優解。逐層枚舉涵蓋所有長度 0..N，總比較規則與題意一致。
common_errors: [輸出權值未沿 fail 累加, 忽略空字串與最短優先, 只按字典序比較不同長度候選]
complexity: { time: 'O(NS×26×N)（含字串比較/複製）', space: 'O(SN)' }
