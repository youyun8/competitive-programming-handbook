statement: 給定一條由整數貝殼編成的項鍊，對每個閉區間詢問其中有多少種不同的貝殼。
constraints:
  - '1 <= n, m <= 1000000'

  - '1 <= l <= r <= n'
input_format: 第一行 n，第二行 n 個貝殼編號，第三行 m，接著 m 行各給 l、r。
output_format: 依輸入順序逐行輸出每個區間的不同值數量。

      2
      3
      4

core_knowledge: [右端點掃描, 最後出現位置, BIT 區間和]
judgment: 詢問沒有修改且可離線；把每個值只在目前最後出現位置標 1，掃到 r 時 [l,r] 的標記數就是不同值數。
hints:
  - 將詢問依右端點遞增排序，讓序列只需從左向右掃一次。
  - 再次看見數值 x 時，先把 x 的舊位置標記減一，再把新位置加一。
  - 處理完位置 r 後，BIT 的區間和 [l,r] 正好是詢問答案，最後按原編號輸出。
solution_outline: 排序詢問後掃描右端點，以雜湊表記錄每個值最後位置，BIT 維護這些位置的 0/1 標記。
proof_or_invariant: 掃描到 r 時，每個在前綴中出現過的值恰有一個標記，位於不超過 r 的最後位置。該位置落在 [l,r] 當且僅當此值在區間中出現，因此區間和不重不漏。
complexity:
  time: O((n+m) log n)
  space: O(n+m)
common_errors:
  - 新值出現時忘記清除舊標記
  - 排序後直接依處理順序輸出
  - n 達百萬卻使用過多物件或遞迴結構
