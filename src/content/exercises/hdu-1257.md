statement: >-
  導彈依給定次序飛來。每套攔截系統的第一發可到任意高度，之後每次能攔截的高度不得高於
  前一次。求要依序攔截全部導彈，至少需配置幾套系統。
constraints:
  - 輸入含多組資料，讀到檔案結尾
  - 每組的導彈數 n 是正整數
  - 1 <= height_i <= 30000
  - 官方題面未另列 n 的上限
input_format: 每組先給導彈數 n，再給依序飛來的 n 個高度，直到 EOF。
output_format: 每組輸出一行最少系統數。
samples:
  - input: '8 389 207 155 300 299 170 158 65'
    output: '2'
    explanation: 一套可攔 389、300、299、170、158、65，另一套攔 207、155；一套無法容納整個非遞增序列。
core_knowledge:
  - 以最小可行末高度貪心分配序列
  - 最少非遞增子序列覆蓋數等於最長嚴格遞增子序列長度
judgment: 相等高度可由同一套系統依序攔截，因為後一發只要求不高於前一發。
hints:
  - 每套系統只需記錄它最近一次攔截的高度。
  - 新高度 h 應接到目前末高度不小於 h、且其中最小的系統；若沒有才開新系統。
  - 維護排序後的末高度，對 h 使用 lower_bound；找到便以 h 取代，找不到則附加。
solution_outline: >-
  以遞增陣列保存各系統目前的末高度。每來一枚高度 h，以 lower_bound 找第一個大於等於 h
  的末高度並替換成 h；若不存在就新增系統。陣列長度即答案。
proof_or_invariant: >-
  已處理任一前綴後，陣列長度是所需系統數，且在使用相同套數的方案中，排序後的末高度逐項
  儘可能小。把 h 放到最小且仍不小於 h 的末高度上，不影響較高系統留給未來的能力，並使該位置
  降到 h；若不存在可接系統，任何方案都必須新增一套。交換論證可將任一最佳方案改成此選擇而
  不變差，故每步與最終套數皆最少。
common_errors:
  - 使用 upper_bound，錯把相等高度視為不能接續
  - 求單一系統最多攔幾枚，而不是覆蓋全部所需的系統數
  - 忽略輸入有多組且沒有測試組數
complexity:
  time: O(n log n) 每組測試
  space: O(n)

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <vector>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n = 0;
      while (cin >> n) {
          vector<int> tails;
          tails.reserve(static_cast<size_t>(n));
          for (int i = 0; i < n; ++i) {
              int height = 0;
              cin >> height;
              const auto position = lower_bound(tails.begin(), tails.end(), height);
              if (position == tails.end()) {
                  tails.push_back(height);
              } else {
                  *position = height;
              }
          }
          cout << tails.size() << '\n';
      }
  }
