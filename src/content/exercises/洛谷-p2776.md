statement: |-
  n 個元素各自固定屬於 m 個小組之一。`push x` 時，若總佇列中已有 x 同組元素，x 排到該組最後一人之後；否則排到整個佇列尾端。`pop` 時移除並輸出整體最前方元素。依序處理所有合法操作。
constraints:
  - '元素編號為 0 到 n-1，小組編號為 0 到 m-1'
  - 'n <= 300000，m <= 300'
  - '操作數 q <= 100000'
  - '輸入保證所有操作合法'
input_format: 第一行為 n、m；第二行 n 個小組編號，表示每個元素所屬小組；下一行為操作數 q；接著 q 行為 `push x` 或 `pop`。
output_format: 每次 `pop` 輸出一行被移除的元素編號。
samples:
  - input: |
      4 2
      0 0 1 1
      6
      push 2
      push 0
      push 3
      pop
      pop
      pop
    output: |
      2
      3
      0
    explanation: 核實官方範例。2 與 3 同屬第 1 組，所以 3 插在 2 後方而非整體隊尾；此時順序為 2、3、0。
core_knowledge:
  - 外層佇列維護小組順序
  - 內層佇列維護各組成員順序
judgment: 若真的在單一序列中尋找同組最後位置並插入，最壞會是 O(q^2)；題目規則保證同組成員永遠連成一段，可用兩層佇列 O(1) 模擬。
hints:
  - 觀察任一時刻：同一小組若在隊中，其成員必然相鄰，且組內仍保持 push 的先後順序。
  - 為每組設一個成員佇列，另設一個只保存「目前非空小組」順序的外層佇列。
  - push 到空組時才把組號加入外層隊尾，接著把元素加入該組；pop 從外層隊首小組取人，若該組因此清空，再移除外層隊首。
solution_outline: 預存每個元素的小組。以 vector<queue<int>> 保存各組成員，另一個 queue<int> 保存活躍小組順序；按規則處理 push 與 pop。
proof_or_invariant: 外層佇列依整體先後保存所有非空小組，每個內層佇列依先後保存該組目前成員。push 到非空組只加在其內層尾端，恰位於該組最後；push 到空組時把整組加到整體尾端。pop 從最前組的最前成員取出，組空後移除組號。故兩層結構展平後始終等同題目佇列。
complexity:
  time: 'O(n + q)'
  space: 'O(n + m)'
common_errors:
  - 每次 push 都把組號加入外層佇列，造成同組重複
  - 內層佇列清空後忘記移除外層隊首
  - 混淆輸入第一行 n、m 的順序或把 0-based 編號加一

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int element_count, group_count;
      if (!(cin >> element_count >> group_count)) return 0;
      vector<int> group_of(element_count);
      for (int& group : group_of) cin >> group;
      vector<queue<int>> members(group_count);
      queue<int> active_groups;
      int operation_count;
      cin >> operation_count;
      while (operation_count--) {
          string operation;
          cin >> operation;
          if (operation == "push") {
              int element;
              cin >> element;
              const int group = group_of[element];
              if (members[group].empty()) active_groups.push(group);
              members[group].push(element);
          } else {
              const int group = active_groups.front();
              cout << members[group].front() << '\n';
              members[group].pop();
              if (members[group].empty()) active_groups.pop();
          }
      }
      return 0;
  }
