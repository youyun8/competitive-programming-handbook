statement: 老鼠從原點出發，造訪平面上全部 n 塊奶酪，終點不限；求最短總距離。
constraints:
  - 1 <= n <= 15
  - '|x_i|,|y_i| <= 200'
  - 座標最多三位小數
input_format: 第一行 n；其後 n 行為各奶酪座標。
output_format: 輸出最短距離，保留兩位小數。
samples:
  - input: |
      4
      1 1
      1 -1
      -1 1
      -1 -1
    output: '7.41'
    explanation: 狀態壓縮比較所有造訪順序後，最短路徑長度四捨五入為 7.41。
core_knowledge:
  - 子集合與末端點 DP
  - 歐氏距離
judgment: 不必回到原點；每塊奶酪只需造訪一次。
hints:
  - dp[mask][i] 表示已訪 mask 且停在 i 的最短距離。
  - 單點狀態由原點到該點距離初始化。
  - 從 mask 中移除 i，枚舉前一個末端 j 做轉移；完整集合取所有末端最小值。
solution_outline: 預算兩點距離，以 bitmask DP 枚舉集合與終點。
proof_or_invariant: 任一造訪 mask 且終於 i 的路徑，倒數第二點必為 mask\{i} 中某 j；取所有 j 最小值完整涵蓋最優子結構。初始化正確，歸納得完整集合答案。
complexity:
  time: O(2^n n^2)
  space: O(2^n n)
common_errors:
  - 強迫回原點
  - 未以原點距離初始化單點狀態
  - 輸出精度不足
