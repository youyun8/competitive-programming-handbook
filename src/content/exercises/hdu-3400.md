statement: 平面上有線段 AB、CD；在線段上速度分別為 P、Q，其他區域速度為 R。可從 A 沿 AB 到任意點、穿越平面至 CD 任意點，再沿 CD 到 D，求最短時間。
constraints: ['所有座標在 [0,1000]', '1 ≤ P,Q,R ≤ 10']
input_format: 第一行測試組數；每組三行：A、B 座標；C、D 座標；P、Q、R。
output_format: 每組輸出最短時間，四捨五入至兩位小數。

  - input: |
      1
      0 0 0 100
      100 0 100 100
      2 2 1
    output: |
      136.60
    explanation: 同時最佳化離開 AB 與進入 CD 的位置後，最短時間約為 136.60。
core_knowledge: ['線段參數化', '凸距離函數的巢狀三分']
judgment: 固定 AB 接點後，對 CD 接點的時間為凸函數；取其最小值後，外層對 AB 參數亦可三分。
hints:
  - '用 t∈[0,1] 表示線段端點間的點。'
  - '固定 AB 上的點，對 CD 參數三分最小化「跨越時間＋沿 CD 時間」。'
  - '外層再三分 AB 參數，總時間加上 A 到該點的線段時間。'
solution_outline: point(X,Y,t) 線性插值。inner(E) 三分 F∈CD 的 dist(E,F)/R+dist(F,D)/Q；外層三分 E∈AB 的 dist(A,E)/P+inner(E)。
proof_or_invariant: 歐氏距離沿線性參數為凸函數，加上線性距離仍凸；內層得到固定 E 的全域最小。部分最小化保留外層所需單谷結構，兩層三分均維持最小點於區間內並收斂。
common_errors: ['把速度乘上距離而非相除', 'CD 行進方向寫成 C 到接點', '內外層更新方向反轉', '輸出精度不足']

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;
  struct Point { double x, y; };
  static Point interpolate(const Point& a, const Point& b, double t) { return {a.x+(b.x-a.x)*t, a.y+(b.y-a.y)*t}; }
  static double distance(const Point& a, const Point& b) { return hypot(a.x-b.x, a.y-b.y); }
  int main() {
      ios::sync_with_stdio(false); cin.tie(nullptr);
      int tests; cin >> tests;
      while (tests--) {
          Point a,b,c,d; double p,q,r;
          cin>>a.x>>a.y>>b.x>>b.y>>c.x>>c.y>>d.x>>d.y>>p>>q>>r;
          const auto inner = [&](const Point& from) {
              double left=0,right=1;
              const auto cost = [&](double t) { const Point to=interpolate(c,d,t); return distance(from,to)/r+distance(to,d)/q; };
              for(int it=0;it<100;++it){double m1=left+(right-left)/3,m2=right-(right-left)/3;if(cost(m1)<cost(m2))right=m2;else left=m1;}
              return cost((left+right)/2);
          };
          const auto total = [&](double t){Point from=interpolate(a,b,t);return distance(a,from)/p+inner(from);};
          double left=0,right=1;
          for(int it=0;it<100;++it){double m1=left+(right-left)/3,m2=right-(right-left)/3;if(total(m1)<total(m2))right=m2;else left=m1;}
          cout<<fixed<<setprecision(2)<<total((left+right)/2)<<'\n';
      }
  }
