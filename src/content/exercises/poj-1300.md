statement: >-
  管家從房間 M 出發，每穿過一扇開門就立即把它關上，不能再穿過；要恰好關閉全部門並
  最後到達自己的房間 0。給定所有開門，判斷是否存在這樣的路徑。
constraints: [1 <= N <= 20, 每組門數不超過 100, 資料組數不超過 100, 同一對房間可有多扇門]
input_format: >-
  每組以 START M N 開始；接著 N 行，第 i 行只列出 i 通往較大編號房間的門，可為空；
  END 結束該組。ENDOFINPUT 結束全部輸入。
output_format: 可行輸出 YES X，其中 X 為關閉門數；否則輸出 NO。
samples:
  - input: "START 1 2\n1\n\nEND\nSTART 0 5\n1 2 2 3 3 4 4\n\n\n\n\nEND\nSTART 0 10\n1 9\n2\n3\n4\n5\n6\n7\n8\n9\n\nEND\nENDOFINPUT\n"
    output: "YES 1\nNO\nYES 10"
    explanation: 第一組從 1 經唯一門到 0；第二組房間 0 有多個奇度障礙；第三組存在從 0 回 0 的十門迴路。
core_knowledge: [使用每扇門一次等價於無向歐拉跡, 指定起終點的度數條件, 非零度頂點連通]
judgment: M 不等於 0 時恰由 M 與 0 為奇度端點；M 等於 0 時所有點必為偶度。
hints:
  - 每扇門是無向多重邊，走過後關閉正是「每條邊使用一次」。
  - 檢查所有有門房間是否在同一連通分量。
  - 起點等於終點時全偶；否則只有起點 M 與終點 0 為奇度。
solution_outline: 逐行解析門並建立鄰接表、度數與門數；DFS 檢查含邊頂點連通，再按 M 是否為零檢查精確奇度集合。
proof_or_invariant: >-
  任一歐拉跡的內部頂點每進必出，度數為偶；不同起終點各多一條未配對邊而為奇。單一路徑
  必涵蓋所有含邊頂點。無向歐拉跡定理亦保證連通及上述度數條件充分，所以判定完全等價。
common_errors: [忽略輸入中的空白房間行, 把每行鄰居當雙向重複輸入, 只數奇點而未確認正是 M 與 0, 同一房間對的多扇門被去重]
complexity: { time: O(N + E), space: O(N + E) }

cpp_solution: |
  #include <iostream>
  #include <sstream>
  #include <string>
  #include <vector>
  using namespace std;
  static void visit(int u,const vector<vector<int>>& graph,vector<bool>& seen){seen[static_cast<size_t>(u)]=true;for(int v:graph[static_cast<size_t>(u)])if(!seen[static_cast<size_t>(v)])visit(v,graph,seen);}
  int main(){
      ios::sync_with_stdio(false);cin.tie(nullptr);string marker;
      while(cin>>marker&&marker!="ENDOFINPUT"){int start=0,n=0;cin>>start>>n;string line;getline(cin,line);vector<vector<int>> graph(static_cast<size_t>(n));vector<int> degree(static_cast<size_t>(n),0);int doors=0;
          for(int u=0;u<n;++u){getline(cin,line);istringstream input(line);int v=0;while(input>>v){graph[static_cast<size_t>(u)].push_back(v);graph[static_cast<size_t>(v)].push_back(u);++degree[static_cast<size_t>(u)];++degree[static_cast<size_t>(v)];++doors;}}cin>>marker;
          vector<bool> seen(static_cast<size_t>(n),false);if(doors>0)visit(start,graph,seen);bool ok=doors==0?start==0:true;
          for(int v=0;v<n;++v){if(degree[static_cast<size_t>(v)]>0&&!seen[static_cast<size_t>(v)])ok=false;bool should_be_odd=start!=0&&(v==start||v==0);if((degree[static_cast<size_t>(v)]%2!=0)!=should_be_odd)ok=false;}
          if(ok)cout<<"YES "<<doors<<'\n';else cout<<"NO\n";

「走過就關門」把路徑限制精確轉成每條無向邊使用一次；指定終點只再限制兩個端點的奇偶性。
