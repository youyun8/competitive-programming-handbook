statement: >-
  線性鐵路有 n 個車站及重要值。炸斷 m 條站間鐵路後，每個連通段價值為段內所有無序站點對重要值乘積之和；求剩餘總價值最小值。
constraints:
  - 1 <= n <= 1000
  - 0 <= m < n
  - 重要值介於 1 與 100
  - 以 0 0 結束輸入
input_format: 每組第一行 n、m，第二行 n 個重要值。
output_format: 每組輸出最小剩餘戰略價值。
samples:
  - input: |-
      4 1
      4 5 1 2
      0 0
    output: |-
      17
    explanation: 在第一、二站間炸斷後，後三站價值為 5×1+5×2+1×2=17。
core_knowledge: ['鐵路切割', '區間成對乘積', '決策單調性']
judgment: m 次攻擊形成 m+1 個連續段；一段成本可由前綴和與平方和 O(1) 算出，且滿足 Monge 性。
hints:
  - cost(l,r)=((sum[r]-sum[l-1])²-(square[r]-square[l-1]))/2。
  - dp[g][i]=min_{k<i}(dp[g-1][k]+cost(k+1,i))，g 是連通段數。
  - 最佳 k 隨 i 單調，用分治決策優化計算每一層。
solution_outline: >-
  建立兩種前綴和。從零段 dp[0]=0 開始，重複 m+1 層；每層以 divide-and-conquer 搜尋各 i 的單調最佳切點。
proof_or_invariant: >-
  炸斷邊與把序列分成連續段一一對應。平方恆等式精確計算段內所有成對乘積。此區間權函數滿足四邊形不等式，因此分組 DP 的最佳切點單調；分治傳入的決策範圍必含真正最優值。
common_errors: ['攻擊 m 次卻只分 m 段', '成對乘積忘記除以二', '允許空連通段']
complexity:
  time: 'O(mn log n)'
  space: 'O(n)'

cpp_solution: |
  #include <algorithm>
  #include <functional>
  #include <iostream>
  #include <limits>
  #include <vector>
  using namespace std;
  int main(){ios::sync_with_stdio(false);cin.tie(nullptr);int n,attacks;while(cin>>n>>attacks&&(n||attacks)){vector<long long>sum(n+1),square(n+1);for(int i=1;i<=n;i++){long long x;cin>>x;sum[i]=sum[i-1]+x;square[i]=square[i-1]+x*x;}auto cost=[&](int l,int r){long long total=sum[r]-sum[l-1];return (total*total-(square[r]-square[l-1]))/2;};const long long inf=numeric_limits<long long>::max()/4;vector<long long>previous(n+1,inf),current(n+1,inf);previous[0]=0;for(int group=1;group<=attacks+1;group++){fill(current.begin(),current.end(),inf);function<void(int,int,int,int)>solve=[&](int left,int right,int opt_left,int opt_right){if(left>right)return;int mid=(left+right)/2,best=-1;for(int cut=opt_left;cut<=min(mid-1,opt_right);cut++){long long value=previous[cut]+cost(cut+1,mid);if(value<current[mid])current[mid]=value,best=cut;}solve(left,mid-1,opt_left,best);solve(mid+1,right,best,opt_right);};solve(group,n,group-1,n-1);previous.swap(current);}cout<<previous[n]<<'\n';}}
