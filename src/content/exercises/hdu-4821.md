statement: 對字串 S，統計長度 M*L 的區間，使它切成 M 個連續、各長 L 的區塊後，這 M 個區塊兩兩不同。
constraints: [S 只含小寫英文字母, '|S| <= 100000', '1 <= M*L <= |S|', 輸入有多組直到 EOF]
input_format: 每組第一行 M L，第二行字串 S。
output_format: 每組輸出一行符合條件的起點數量。
samples:
  - input: "3 3\nabcabcbcaabc\n"
    output: '2'
    explanation: 起點 2、3（1-based）的三個長度 3 區塊各不相同，其餘起點含重複區塊。
core_knowledge: [固定長度子串雜湊, 依起點模 L 分組, 多重集合滑動窗口]
judgment: 不同起點即不同子串，可重疊；每個候選必須恰切成 M 塊。
hints:
  - 先為每個長 L 的區塊取得可 O(1) 比較的雙雜湊。
  - 起點具有相同 modulo L 時，區塊邊界對齊，可把 M 塊看成長度 M 的滑動窗口。
  - 用計數表維護窗口內各雜湊的出現數；不同鍵數等於 M 時，所有區塊兩兩不同。
solution_outline: 計算兩組 64 位多項式前綴雜湊；對 residue=0..L-1 依步長 L 掃描區塊，維護最近 M 個雜湊的頻率與 distinct 數。
proof_or_invariant: 每個起點唯一屬於一個模 L 類；該類掃描時窗口恰含此起點開始的 M 個區塊。頻率表不變量是窗口內每種區塊指紋的精確次數，因此 distinct=M 等價於 M 塊互異。雙獨立 64 位指紋把不同區塊誤認相同的機率降至可忽略。
common_errors: [只掃 residue 0 而漏掉其他起點, 移除舊區塊後未刪除零頻鍵, 窗口尚未滿 M 就計數]
complexity: { time: O(|S|), space: O(|S|) }

cpp_solution: |
  #include <cstdint>
  #include <iostream>
  #include <string>
  #include <unordered_map>
  #include <utility>
  #include <vector>
  using namespace std;
  struct PairHash{size_t operator()(const pair<uint64_t,uint64_t>& x)const noexcept{return static_cast<size_t>(x.first^(x.second+(x.first<<6U)+(x.first>>2U)));}};
  int main(){ios::sync_with_stdio(false);cin.tie(nullptr);int m=0,l=0;string s;while(cin>>m>>l>>s){size_t n=s.size();constexpr uint64_t b1=1000003,b2=1000033;vector<uint64_t> h1(n+1),h2(n+1),p1(n+1,1),p2(n+1,1);for(size_t i=0;i<n;++i){uint64_t c=static_cast<unsigned char>(s[i])+1U;h1[i+1]=h1[i]*b1+c;h2[i+1]=h2[i]*b2+c;p1[i+1]=p1[i]*b1;p2[i+1]=p2[i]*b2;}auto get=[&](size_t i){size_t length=static_cast<size_t>(l);return pair<uint64_t,uint64_t>{h1[i+length]-h1[i]*p1[length],h2[i+length]-h2[i]*p2[length]};};long long answer=0;for(int residue=0;residue<l&&static_cast<size_t>(residue)<n;++residue){unordered_map<pair<uint64_t,uint64_t>,int,PairHash> frequency;vector<pair<uint64_t,uint64_t>> queue;for(size_t pos=static_cast<size_t>(residue);pos+static_cast<size_t>(l)<=n;pos+=static_cast<size_t>(l)){auto key=get(pos);queue.push_back(key);++frequency[key];if(queue.size()>static_cast<size_t>(m)){auto old=queue[queue.size()-static_cast<size_t>(m)-1U];if(--frequency[old]==0)frequency.erase(old);}if(queue.size()>=static_cast<size_t>(m)&&frequency.size()==static_cast<size_t>(m))++answer;}}cout<<answer<<'\n';}}
