statement: >-
  n 隻動物各屬於三個物種之一，三個物種的捕食關係形成循環：第一種吃第二種、第二種吃第三種、
  第三種吃第一種。依序收到 k 句話；`1 x y` 表示 x、y 同類，`2 x y` 表示 x 吃 y。
  一句話若編號越界、聲稱某動物吃自己，或與先前判定為真的話矛盾，就算假話且不納入後續推理。
  求假話總數。
constraints:
  - 1 <= n <= 50000
  - 0 <= k <= 100000
  - d 為 1 或 2；x、y 為正整數，但可能超過 n
  - 官方總時間限制為 1000 ms，記憶體限制為 65536 KB
input_format: 第一行為 n、k；接著 k 行各有 d、x、y，依輸入順序給出一句關係描述。
output_format: 輸出一個整數，表示假話總數。
samples:
  - input: |
      100 7
      1 101 1
      2 1 2
      2 2 3
      2 3 3
      1 1 3
      2 3 1
      1 5 5
    output: '3'
    explanation: >-
      第一條的 101 越界；第四條聲稱 3 吃自己；第五條與先前「1 吃 2、2 吃 3」
      所推出的關係矛盾。其餘句子均可與已接受資訊共存，所以共三句假話。
core_knowledge:
  - 三類循環關係可用模 3 的相對類別差表示
  - 帶權並查集在路徑壓縮時同步累加關係
  - 只有真話能合併集合，假話不得改變既有資訊
judgment: >-
  越界與「x 吃 x」優先判假；同類的 `1 x x` 是合法真話。邏輯衝突只依先前接受的真話判定。
hints:
  - 不必猜每隻動物的絕對物種；只要維護同一連通分量內兩者的相對物種即可。
  - 用 0 表示同類、1 表示前者吃後者、2 表示前者被後者吃，關係合成就是模 3 加法。
  - 令 relation[x] 為 x 相對父節點的值。壓縮後若同根就比較 `relation[x]-relation[y]`；異根則由目標關係反推新根的 relation。
solution_outline: >-
  將每隻動物設成一個並查集節點，relation[x] 定義為「x 的類別減去 parent[x] 的類別」模 3，
  並約定差 0 為同類、1 為前者吃後者、2 為前者被後者吃。find_root 壓縮路徑時把沿途關係相加。
  每句話先檢查編號和自食。合法句子所需差為 d-1；若 x、y 同根，直接比較現有差，
  不同根則把 x 的根接到 y 的根，並由等式設定根的 relation。衝突時只增加答案。
proof_or_invariant: >-
  不變量是 relation[x] 始終等於 x 類別減去父節點類別（模 3），所以沿父鏈相加可得 x
  相對代表元的類別差。路徑壓縮把原父節點到根的差加進 relation[x]，不變量仍成立。
  若 x、y 同根，兩者差已被先前真話唯一決定，與本句要求不同即必然矛盾；相同則可接受。
  若根不同，兩群之間尚無約束，將 x 的根接到 y 的根並令其差為
  `wanted-relation[x]+relation[y]`，恰使 x-y 等於 wanted，且不改變任一群內既有關係。
  歸納可知結構始終且只包含所有已接受真話，因此假話計數正確。
common_errors:
  - 將越界句子拿去存取陣列後才判斷，造成未定義行為
  - 把 `2 x x` 當成可接受，忽略任何物種都不吃同類中的自己
  - C++ 負數取餘仍可能為負，沒有用 `(value % 3 + 3) % 3` 正規化
  - 發現矛盾後仍合併兩個集合，導致後續真話被錯判
complexity:
  time: O((n + k) alpha(n))
  space: O(n)

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  class RelationSet {
  public:
      explicit RelationSet(int n)
          : parent_(static_cast<size_t>(n + 1)),
            relation_(static_cast<size_t>(n + 1), 0) {
          iota(parent_.begin(), parent_.end(), 0);
      }

      int find_root(int node) {
          const int parent = parent_[static_cast<size_t>(node)];
          if (parent != node) {
              parent_[static_cast<size_t>(node)] = find_root(parent);
              relation_[static_cast<size_t>(node)] =
                  normalize(relation_[static_cast<size_t>(node)] +
                            relation_[static_cast<size_t>(parent)]);
          }
          return parent_[static_cast<size_t>(node)];
      }

      bool accept(int first, int second, int wanted) {
          const int first_root = find_root(first);
          const int second_root = find_root(second);
          if (first_root == second_root) {
              return normalize(relation_[static_cast<size_t>(first)] -
                               relation_[static_cast<size_t>(second)]) ==
                     wanted;
          }
          parent_[static_cast<size_t>(first_root)] = second_root;
          relation_[static_cast<size_t>(first_root)] =
              normalize(wanted - relation_[static_cast<size_t>(first)] +
                        relation_[static_cast<size_t>(second)]);
          return true;
      }

  private:
      static int normalize(int value) {
          return (value % 3 + 3) % 3;
      }

      vector<int> parent_;
      vector<int> relation_;
  };

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      int n, k;
      cin >> n >> k;
      RelationSet dsu(n);
      int lie_count = 0;
      for (int statement_index = 0; statement_index < k; ++statement_index) {
          int type, first, second;
          cin >> type >> first >> second;
          if (first > n || second > n || (type == 2 && first == second)) {
              ++lie_count;
              continue;
          }
          if (!dsu.accept(first, second, type - 1)) {
              ++lie_count;
          }
      }
      cout << lie_count << '\n';
  }
