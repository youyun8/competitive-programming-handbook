statement: >-
  有重量分別為 1、2、3、5、10、20 的六種砝碼，給定每種數量。每個砝碼至多使用一次，
  求能組合出的不同正整數重量共有多少種。
constraints:
  - 依序輸入六個非負整數，代表六種砝碼數量
  - 官方資料中每種砝碼數量不超過 10
input_format: 一行六個整數，依序是重量 1、2、3、5、10、20 的砝碼數量。
output_format: 依 `Total=N` 格式輸出可稱出的不同正重量數。
samples:
  - input: '1 1 0 0 0 0'
    output: 'Total=3'
    explanation: 可選重量 1、重量 2，或兩者一起選，能稱出 1、2、3 共三種重量。
core_knowledge: [有限背包可達性, 二進位拆分]
judgment: 不使用任何砝碼所得的零不計入答案；相同總重量只計一次。
hints:
  - 最大可能重量是所有砝碼重量總和，只需記錄每個和是否可達。
  - 可把同種 count 個砝碼拆成數量 1、2、4、… 的若干 0/1 物品。
  - 對每個拆分物品讓重量由總和遞減更新，最後統計 dp[1..sum]。
solution_outline: 將六種有限數量以二進位分組拆成 0/1 物品，用布林背包標記所有可達重量。
proof_or_invariant: >-
  二進位分組的組大小能表示 0 到原數量的每個使用個數，且不會超量，因此拆分前後可選總重量集合相同。
  0/1 背包處理每組後，dp[s] 恰表示由已處理組合出 s；遞減更新確保每組至多使用一次。歸納處理
  全部組後，所有且僅有可稱重量被標記，排除零後統計即為答案。
common_errors: [把零重量也算入答案, 容量遞增造成拆分組重複使用, 輸出格式漏掉 Total=]
complexity:
  time: O(S * sum(log(count_i + 1)))
  space: O(S)，S 為所有砝碼總重量

cpp_solution: |
  #include <array>
  #include <iostream>
  #include <vector>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false); cin.tie(nullptr);
      constexpr array<int, 6> weight{{1, 2, 3, 5, 10, 20}};
      array<int, 6> count{};
      int total = 0;
      for (size_t i = 0; i < count.size(); ++i) {
          cin >> count[i];
          total += count[i] * weight[i];
      }
      vector<bool> reachable(static_cast<size_t>(total + 1), false);
      reachable[0] = true;
      for (size_t i = 0; i < count.size(); ++i) {
          int remaining = count[i];
          for (int block = 1; remaining > 0; block *= 2) {
              const int take = block < remaining ? block : remaining;
              const int item_weight = take * weight[i];
              for (int sum = total; sum >= item_weight; --sum)
                  reachable[static_cast<size_t>(sum)] =
                      reachable[static_cast<size_t>(sum)] ||
                      reachable[static_cast<size_t>(sum - item_weight)];
              remaining -= take;
          }
      }
      int answer = 0;
      for (int sum = 1; sum <= total; ++sum)
          if (reachable[static_cast<size_t>(sum)]) ++answer;
      cout << "Total=" << answer << '\n';
  }
