hints:
  - '固定左端時，右端要走到哪裡才第一次達標？'

  - '令 [left,right] 為目前視窗。加入 a[right] 後，在 sum>=S 時以 right-left+1 更新答案，再扣除 a[left++]。'
solution_outline: 對每組資料維護 left、window_sum 與答案。right 由左到右逐一加入元素；只要 window_sum 至少為 S，就記錄目前長度並移除左端。兩個指標皆不回頭。答案未更新時輸出 0。
proof_or_invariant: '每次處理 right 後，收縮迴圈依序考慮所有以該 right 結尾且總和達標的左端，直到再收縮便不達標。因元素皆正，對固定 right，更靠左的區間只會更長；停止時已找完該右端的最短可行區間。right 遍歷所有位置，所以全域最短值必被記錄。'

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <limits>
  #include <vector>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int test_count = 0;
      cin >> test_count;
      while (test_count-- > 0) {
          int n = 0;
          long long target = 0;
          cin >> n >> target;
          vector<int> values(static_cast<size_t>(n));
          for (int& value : values) { cin >> value; }

          int answer = numeric_limits<int>::max();
          int left = 0;
          long long window_sum = 0;
          for (int right = 0; right < n; ++right) {
              window_sum += values[static_cast<size_t>(right)];
              while (window_sum >= target) {
                  answer = min(answer, right - left + 1);
                  window_sum -= values[static_cast<size_t>(left)];
                  ++left;
              }
          }
          cout << (answer == numeric_limits<int>::max() ? 0 : answer) << '\n';
      }
      return 0;
  }
