statement: >-
  有 n 名玩家及 m 條 a=b、a>b 或 a<b 的分數關係。判斷所有關係是否互相矛盾；若不矛盾，
  再判斷能否唯一確定所有玩家所屬分數層級的高低次序。
constraints: [1 <= n <= 10000, 0 <= m <= 20000, 玩家編號為 0 到 n-1, 輸入包含多組資料直到 EOF]
input_format: 每組先給 n m，接著 m 行 a op b，其中 op 為 =、> 或 <。
output_format: 矛盾輸出 CONFLICT；合法但不能唯一決定輸出 UNCERTAIN；唯一決定輸出 OK。
samples:
  - input: "3 3\n0 > 1\n1 > 2\n0 > 2\n3 1\n0 = 1\n2 2\n0 > 1\n1 > 0\n"
    output: "OK\nUNCERTAIN\nCONFLICT"
    explanation: 第一組層級唯一為 0>1>2；第二組合併 0、1 後仍無法和 2 比較；第三組形成嚴格環。
core_knowledge: [DSU 合併等價類, 縮點後 DAG, 唯一拓撲序]
judgment: 相等玩家屬同一節點；唯一性只要求這些分數層級的先後唯一，層內玩家自然同分。
hints:
  - 先只處理所有等號，用 DSU 合併玩家。
  - 將不等號兩端換成代表元；若相同代表元間要求嚴格大小，立即矛盾。
  - 在縮點圖拓撲排序；某一步有多個零入度分量即不唯一，取不完則有環。
solution_outline: >-
  保存全部關係，第一遍 union 等號；第二遍將 >、< 正規化成「較高→較低」的分量邊並去重。
  若自環則 CONFLICT。Kahn 排序時統計每輪佇列大小：超過一個標記 UNCERTAIN；若處理分量數
  不足則 CONFLICT，否則依唯一標記輸出 OK 或 UNCERTAIN。
proof_or_invariant: >-
  等號具有等價關係，任何解都必須把 DSU 分量視為同一層。縮點後每條邊精確表示嚴格高低；
  自環或有向環會要求某層嚴格高於自身，故矛盾。DAG 每步零入度分量是所有可放的下一層，
  候選超過一個可交換而產生兩種排名；每步唯一則整個分量序列被迫唯一。
common_errors:
  [
    建不等邊前未先合併全部等號,
    忽略嚴格關係落在同一分量的矛盾,
    以玩家數而非 DSU 分量數檢查 processed,
    重複邊重複增加入度
  ]
complexity: { time: O((n + m)*alpha(n)), space: O(n + m) }

cpp_solution: |
  #include <iostream>
  #include <queue>
  #include <set>
  #include <tuple>
  #include <vector>
  using namespace std;
  struct Dsu{vector<int> p;explicit Dsu(int n):p(static_cast<size_t>(n)){for(int i=0;i<n;++i)p[static_cast<size_t>(i)]=i;}int find(int x){return p[static_cast<size_t>(x)]==x?x:p[static_cast<size_t>(x)]=find(p[static_cast<size_t>(x)]);}void unite(int a,int b){p[static_cast<size_t>(find(a))]=find(b);}};
  int main(){
      ios::sync_with_stdio(false);cin.tie(nullptr);int n=0,m=0;
      while(cin>>n>>m){
          vector<tuple<int,char,int>> relations;relations.reserve(static_cast<size_t>(m));Dsu dsu(n);
          for(int i=0;i<m;++i){int a=0,b=0;char op='=';cin>>a>>op>>b;relations.emplace_back(a,op,b);if(op=='=')dsu.unite(a,b);}
          vector<int> index(static_cast<size_t>(n),-1);int components=0;for(int v=0;v<n;++v){int root=dsu.find(v);if(index[static_cast<size_t>(root)]==-1)index[static_cast<size_t>(root)]=components++;}
          vector<set<int>> graph(static_cast<size_t>(components));vector<int> indegree(static_cast<size_t>(components),0);bool conflict=false;
          for(auto [a,op,b]:relations)if(op!='='){int left=index[static_cast<size_t>(dsu.find(a))],right=index[static_cast<size_t>(dsu.find(b))];int high=op=='>'?left:right,low=op=='>'?right:left;if(high==low){conflict=true;continue;}if(graph[static_cast<size_t>(high)].insert(low).second)++indegree[static_cast<size_t>(low)];}
          queue<int> ready;for(int v=0;v<components;++v)if(indegree[static_cast<size_t>(v)]==0)ready.push(v);bool uncertain=false;int processed=0;
          while(!ready.empty()){if(ready.size()>1U)uncertain=true;int u=ready.front();ready.pop();++processed;for(int v:graph[static_cast<size_t>(u)])if(--indegree[static_cast<size_t>(v)]==0)ready.push(v);}
          if(conflict||processed!=components)cout<<"CONFLICT\n";else if(uncertain)cout<<"UNCERTAIN\n";else cout<<"OK\n";
      }
  }
