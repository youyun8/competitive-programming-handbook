statement: 對每次區間詢問，取各種不同數值在區間內第一次出現的位置，依位置遞增排列，輸出第 ceil(k/2) 個位置；輸入端點會以上次答案加密。
constraints:
  - 'T <= 2，n, m <= 200000'
  - '0 <= a_i <= 200000'
  - 讀入 x、y 後，各自解碼為 (value+last_answer) mod n+1，再取小者為 l
input_format: 第一行 T；每組給 n、m、序列，接著 m 行各有兩個加密端點。
output_format: 每組輸出 `Case #k:`，並在同一行依序輸出答案。
samples:
  - input: |
      1
      5 3
      1 1 2 3 3
      0 4
      0 1
      2 3
    output: |
      Case #1: 3 4 2
    explanation: 首次詢問的首次位置為 1、3、4，中位位置是 3；後續端點須分別加上前次答案後取模解碼。
core_knowledge: [反向建版, 首次出現標記, 線段樹第 k 個一]
judgment: 第 l 個版本只標記每個值在後綴中的首次位置，故其 [l,r] 計數與第 k 個一可直接回答在線詢問。
hints:
  - 從右向左掃描；每加入 a_i，就取消它原本最近出現位置的標記，再標記 i。
  - root[l] 的區間 [l,r] 中，每種值恰在第一次出現的位置留下一個 1。
  - 先求不同值數量 k，再在同一版本中找第 (k+1)/2 個一；別忘了先解碼端點。
solution_outline: 反向建立 n 個可持久化 0/1 線段樹版本，維護每個值最近位置。詢問在 root[l] 求 [l,r] 和，再找對應順位的標記位置。
proof_or_invariant: 建立 root[i] 後，每個出現在後綴 i..n 的值恰有一個標記，且位於其最左出現處。因此限制到 [l,r] 正好留下各不同值在查詢區間的首次位置，順位查找即為題目答案。
complexity:
  time: O((n+m) log n)
  space: O(n log n)
common_errors:
  - 用前綴版本而標到區間內最後一次出現位置
  - 第 k 個標記搜尋時沒有排除 r 右側；計數雖限於 r，順位樹也須在有效前綴內
  - Case 輸出要求所有答案位於同一行

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;
  struct Node{int left=0,right=0,sum=0;};
  static int update(vector<Node>&t,int old,int low,int high,int p,int delta){int id=static_cast<int>(t.size());t.push_back(t[static_cast<size_t>(old)]);t[static_cast<size_t>(id)].sum+=delta;if(low==high)return id;int mid=(low+high)/2;if(p<=mid)t[static_cast<size_t>(id)].left=update(t,t[static_cast<size_t>(old)].left,low,mid,p,delta);else t[static_cast<size_t>(id)].right=update(t,t[static_cast<size_t>(old)].right,mid+1,high,p,delta);return id;}
  static int range_sum(const vector<Node>&t,int id,int low,int high,int ql,int qr){if(qr<low||high<ql)return 0;if(ql<=low&&high<=qr)return t[static_cast<size_t>(id)].sum;int mid=(low+high)/2;return range_sum(t,t[static_cast<size_t>(id)].left,low,mid,ql,qr)+range_sum(t,t[static_cast<size_t>(id)].right,mid+1,high,ql,qr);}
  static int kth(const vector<Node>&t,int id,int low,int high,int k){if(low==high)return low;int left=t[static_cast<size_t>(t[static_cast<size_t>(id)].left)].sum,mid=(low+high)/2;if(k<=left)return kth(t,t[static_cast<size_t>(id)].left,low,mid,k);return kth(t,t[static_cast<size_t>(id)].right,mid+1,high,k-left);}
