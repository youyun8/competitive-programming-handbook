statement: >-
  一棵有 n 個節點的二元樹，每條邊有蘋果數；保留恰好 q 條邊且保留部分仍與根節點 1 連通，求最多能留下多少蘋果。
constraints:
  - 1 <= n <= 100
  - 1 <= q <= n - 1
  - 邊權為非負整數
input_format: 第一行 n、q；接著 n-1 行各給一條邊的兩端點與蘋果數。
output_format: 輸出保留 q 條邊時的最大蘋果總數。
samples:

      5 2
      1 3 1
      1 4 10
      2 3 20
      3 5 20
    output: |-

    explanation: 保留 1–3 與 3–2 兩條邊，可留下 1+20=21 顆蘋果。
core_knowledge: ['樹形揹包', '子樹合併', '連通性']
judgment: 選中的邊必須形成包含根的連通子樹，且邊數固定，適合以子樹內保留邊數為容量。
hints:
  - 令 dp[u][j] 表示 u 的子樹中保留 j 條邊，且選取部分與 u 連通的最大權重。
  - 合併兒子 v 時，若從 v 取 k 條子樹邊，還要計入連接 u、v 的那一條邊。
  - 倒序枚舉目前容量，轉移 dp[u][j+k+1]，最後答案是 dp[1][q]。
solution_outline: >-
  從根做 DFS。每個節點先只有 dp[u][0]=0；逐一合併兒子 v，以分組揹包枚舉原有邊數 j 與 v 內邊數 k，加入 dp[v][k]+w(u,v)，並維護子樹可用邊數。
proof_or_invariant: >-
  對每個 u 歸納。任何包含 u 的連通選邊集合，在每個兒子子樹內不是空集，就是由父子邊加上一個包含 v 的連通集合；兩部分互不相交，轉移枚舉了唯一的邊數分配。反向組合各兒子的合法方案也保持連通，因此 dp 精確取到最優值。
common_errors: ['把 k 當成含父子邊的數量後又多加一次', '正序更新導致同一兒子重複使用', '輸出節點數 q 而不是邊數 q']

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <utility>
  #include <vector>
  using namespace std;
  struct Edge { int to; int weight; };
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n, q;
      cin >> n >> q;
      vector<vector<Edge>> graph(static_cast<size_t>(n + 1));
      for (int i = 1; i < n; ++i) {
          int u, v, weight;
          cin >> u >> v >> weight;
          graph[u].push_back({v, weight});
          graph[v].push_back({u, weight});
      }
      vector<vector<int>> dp(static_cast<size_t>(n + 1),
                             vector<int>(static_cast<size_t>(q + 1), -1));
      vector<int> edge_count(static_cast<size_t>(n + 1));
      auto dfs = [&](auto&& self, int u, int parent) -> void {
          dp[u][0] = 0;
          for (const Edge edge : graph[u]) {
              if (edge.to == parent) continue;
              self(self, edge.to, u);
              vector<int> next = dp[u];
              for (int used = 0; used <= min(q, edge_count[u]); ++used) {
                  if (dp[u][used] < 0) continue;
                  for (int take = 0; used + take + 1 <= q &&
                                     take <= edge_count[edge.to]; ++take) {
                      if (dp[edge.to][take] < 0) continue;
                      next[used + take + 1] =
                          max(next[used + take + 1],
                              dp[u][used] + dp[edge.to][take] + edge.weight);
                  }
              }
              edge_count[u] += edge_count[edge.to] + 1;
              dp[u].swap(next);
          }
      };
      dfs(dfs, 1, 0);
      cout << dp[1][q] << '\n';
  }
