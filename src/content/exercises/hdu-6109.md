statement: 一串等式或不等式約束原本由多組資料串接而成。每組完整約束不可滿足，但刪除該組最後一條後可滿足。恢復各組長度。

      2 2 1

      1 1 1
      3 1 1
      1 3 1
      1 3 0
    output: |

      6
    explanation: 前五條可同時滿足，最後一條要求已相等的 1、3 不等，故整組長度為六。
core_knowledge: *id001
judgment: 不等關係不具傳遞性，不能把「都與 x 不等」的兩個變數判成相等。
hints:
  - DSU 維護相等類，每個根另存與它不等的根。
  - 相等合併前先檢查兩根是否已有不等邊。
  - 合併根時以小併大轉移不等鄰居；遇矛盾即完成一組。
solution_outline: 逐組從空結構掃描；等式合併等價類與敵對集合，不等式加入根間邊，第一個矛盾位置就是組尾。
proof_or_invariant: DSU 分量恰是等式閉包，根間不等邊恰保存所有不等限制；同分量不等或有不等邊的兩分量相等正是且僅是矛盾。題目保證矛盾只出現在組末。
common_errors:
  - 把不等關係當二分圖 parity
  - 合併後未更新敵對根
  - 矛盾條件未計入該組長度
complexity:
  time: O(L log^2 L) 攤銷
  space: O(L)

  struct Condition {
      int first;
      int second;

  class DisjointSet {
  public:
      explicit DisjointSet(int n) : parent_(static_cast<size_t>(n)) {
          iota(parent_.begin(), parent_.end(), 0);
      }
      int find_root(int node) {
          if (parent_[static_cast<size_t>(node)] != node) {
              parent_[static_cast<size_t>(node)] = find_root(parent_[static_cast<size_t>(node)]);
          }
          return parent_[static_cast<size_t>(node)];
      }
      void unite(int first, int second) {
          first = find_root(first);
          second = find_root(second);
          if (first != second) { parent_[static_cast<size_t>(first)] = second; }
      }
  private:
      vector<int> parent_;
  };

  static bool satisfiable(const vector<Condition>& conditions, int left, int right) {
      vector<int> values;
      values.reserve(static_cast<size_t>(2 * (right - left + 1)));
      for (int index = left; index <= right; ++index) {
          values.push_back(conditions[static_cast<size_t>(index)].first);
          values.push_back(conditions[static_cast<size_t>(index)].second);
      }
      sort(values.begin(), values.end());
      values.erase(unique(values.begin(), values.end()), values.end());
      auto id = [&](int value) {
          return static_cast<int>(lower_bound(values.begin(), values.end(), value) - values.begin());
      };
      DisjointSet dsu(static_cast<int>(values.size()));
      for (int index = left; index <= right; ++index) {
          const Condition condition = conditions[static_cast<size_t>(index)];
          if (condition.equal == 1) { dsu.unite(id(condition.first), id(condition.second)); }
      }
      for (int index = left; index <= right; ++index) {
          const Condition condition = conditions[static_cast<size_t>(index)];
          if (condition.equal == 0 &&
              dsu.find_root(id(condition.first)) == dsu.find_root(id(condition.second))) {
              return false;
          }
      }
      return true;
  }
