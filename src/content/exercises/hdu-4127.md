statement: N×N 棋盤每格為 0..5。每步選一種顏色，把與左上角同色連通區全部改成該色，使它吸收新連通格；求讓全棋盤同色的最少步數。
constraints: [測資不超過 20 組, '2 <= N <= 8', 顏色為 0..5, N=0 結束]
input_format: 每組先給 N，再給 N 行、每行 N 個顏色整數。
output_format: 每組輸出最少步數。
samples:
  - input: "2\n0 0\n0 0\n3\n0 1 2\n1 1 2\n2 2 1\n0\n"
    output: "0\n3"
    explanation: 第一盤已完成；第二盤最少需三次選色。
core_knowledge: [連通區擴張, 剩餘顏色下界, IDA*]
judgment: 一步只改左上角所屬連通區，不是把棋盤上所有同色格同時改色。
hints:
  - 每個搜尋節點先 flood-fill 出目前左上連通區。
  - 連通區外仍出現幾種顏色，就至少還要幾步，因一步只選一種顏色吸收。
  - 不必嘗試目前顏色；套色後若連通區沒有變大，也可略過。
solution_outline: 從下界開始迭代加深，枚舉六色，把目前左上連通區改色後遞迴；以區外不同顏色數剪枝並在回溯時還原棋盤。
proof_or_invariant: 選色後恰有該色格能新加入連通區，因此每步至多消除區外一種顏色，區外顏色種類數為可採納下界。IDA* 逐深度完整枚舉所有有效選色序列，第一個成功上限就是最少步數。
complexity: { time: 'O(6^d·N²)', space: 'O(d·N²)' }
common_errors: [整張棋盤全域換色, 下界包含連通區內顏色, 回溯未完整還原]

  #include <bits/stdc++.h>
  using namespace std;
  int n,limit;array<array<int,8>,8> board;constexpr int dr[4]={-1,1,0,0},dc[4]={0,0,-1,1};
  vector<pair<int,int>> region(){vector<pair<int,int>> cells;bool seen[8][8]={};queue<pair<int,int>> pending;pending.push({0,0});seen[0][0]=true;int color=board[0][0];while(!pending.empty()){auto [r,c]=pending.front();pending.pop();cells.push_back({r,c});for(int d=0;d<4;++d){int nr=r+dr[d],nc=c+dc[d];if(nr>=0&&nr<n&&nc>=0&&nc<n&&!seen[nr][nc]&&board[nr][nc]==color){seen[nr][nc]=true;pending.push({nr,nc});}}}return cells;}
  int lower_bound_steps(const vector<pair<int,int>>&cells){bool inside[8][8]={},present[6]={};for(auto [r,c]:cells)inside[r][c]=true;for(int r=0;r<n;++r)for(int c=0;c<n;++c)if(!inside[r][c])present[board[r][c]]=true;return accumulate(begin(present),end(present),0);}
  bool search(int depth){auto cells=region();int h=lower_bound_steps(cells);if(h==0)return true;if(depth+h>limit)return false;int old_color=board[0][0];for(int color=0;color<6;++color)if(color!=old_color){auto saved=board;for(auto [r,c]:cells)board[r][c]=color;if(region().size()>cells.size()&&search(depth+1))return true;board=saved;}return false;}
