core_knowledge: [Burnside 引理, 二面體群各置換的循環數]
judgment: 反射也視為相同；作用群有 n 個旋轉及 n 個反射。
hints:
  - 旋轉 i 格後的位置置換有 gcd(n,i) 個循環，因此固定染色數為 3^gcd(n,i)。
  - n 為奇數時每個反射有 (n+1)/2 個循環。
  - n 為偶數時各有 n/2 個反射含 n/2+1 或 n/2 個循環，最後除以 2n。
solution_outline: 累加 n 個旋轉及 n 個反射的固定點數，依 Burnside 除以 2n。
proof_or_invariant: 一個染色被某個對稱固定，當且僅當該位置置換每個循環內顏色相同，因此有 3^(循環數) 種。Burnside 引理指出軌道數等於群元素固定點數平均，列舉二面體群全部 2n 個元素即可。
common_errors: [只計旋轉未計反射, 偶數 n 的兩類反射混為一類, n=0 時除以零]
complexity: { time: 'O(n log n) per case', space: 'O(1)' }

cpp_solution: |
  #include <iostream>
  #include <numeric>
  using namespace std;
  long long integer_power(int base, int exponent) {
      long long result = 1;
      while (exponent-- > 0) result *= base;
      return result;
  }
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n;
      while (cin >> n && n != -1) {
          if (n == 0) { cout << 0 << '\n'; continue; }
          long long fixed_sum = 0;
          for (int shift = 0; shift < n; ++shift)
              fixed_sum += integer_power(3, gcd(n, shift));
          if ((n & 1) != 0) {
              fixed_sum += static_cast<long long>(n) * integer_power(3, (n + 1) / 2);
          } else {
              fixed_sum += static_cast<long long>(n / 2) *
                           (integer_power(3, n / 2 + 1) + integer_power(3, n / 2));
          }
          cout << fixed_sum / (2 * n) << '\n';
      }
      return 0;
  }
