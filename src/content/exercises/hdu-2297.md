statement: 數軸上有 n 名選手，每人從給定位置出發，之後永遠以給定的正速度向同一方向等速前進。只有在某個非零時間區間內位置嚴格大於所有其他人的選手才算曾經領先；多人只在單一時刻並列最前不算。求無限時間內曾領先過的不同選手數。
constraints:
  - '1 <= n <= 50000'
  - 位置與速度為整數
  - 速度皆為正，且題目保證選手資料符合原題的互異條件
  - 多組測資，組數由第一行給出
input_format: 第一行為測資組數 T。每組先給 n，接著 n 行各給初始位置 p_i 與速度 v_i。
output_format: 每組輸出一個整數，表示曾在一段正長時間內單獨領先的選手數。
samples:
  - input: |
      2
      3
      1 1
      2 2
      3 3
      2
      1 1
      1 2
    output: |
      1
      1
    explanation: 第一組第三人從起點起位置與速度都較大，始終領先；第二組兩人同位置出發，但速度 2 的選手在任意正時間都單獨領先。
core_knowledge:
  - 每名選手的位置是時間 t>=0 上的一條直線 p+vt
  - 曾單獨領先者恰是所有運動直線上包絡的有效線段
  - 依斜率排序後，上包絡交替時間嚴格遞增
judgment: 依速度遞增處理直線，同速度只保留初始位置最大者。若新線在 t=0 已不低於包絡末線，末線永遠無法再領先；否則比較相鄰兩次交替時間，非嚴格遞增時彈掉中間線。全程用整數交叉相乘避免精度誤判。
hints:
  - 把第 i 人視為 y=v_i t+p_i；答案不是一般平面凸包全部頂點，而是 t>=0 上包絡真正佔有正長區間的直線。
  - 斜率遞增加入新線時，若其截距不小於棧頂截距，棧頂從 t=0 起就被支配，應先刪除。
  - 設三條連續候選為 a、b、c；若 a 與 b 的交替時間不小於 b 與 c，b 沒有任何單獨領先區間，以精確分數比較後彈棧。
solution_outline: 將選手按速度升序、同速度按位置降序排序並去除同速冗餘。維護上包絡棧；先移除截距不大於新線的末線，再以兩交點時間交叉相乘檢查嚴格遞增性，直到合法後推入。棧大小即答案。
proof_or_invariant: 棧中直線依速度遞增，且相鄰直線接管上包絡的時間嚴格遞增，因此每條都在兩次接管時間間擁有正長的單獨領先區間。新線截距較高時，較慢末線在 t>=0 全被支配；交替時間不遞增時，中間線在前一線失效前已被新線超越，也無有效區間。其餘線的包絡次序不受影響。歸納後棧恰為完整 t>=0 上包絡。
complexity:
  time: O(n log n)
  space: O(n)
common_errors:
  - 把只在一個交點瞬間並列第一的選手也計入
  - 忘記限制 t>=0，保留只在負時間位於包絡的直線
  - 用 double 比較非常接近的交替時間
  - 同速度保留較低初始位置的永遠被支配線

cpp_solution: |
  #include <bits/stdc++.h>
  #include <boost/multiprecision/cpp_int.hpp>
  using namespace std;
  using boost::multiprecision::int128_t;

  struct Runner { long long position; long long speed; };

  static bool obsolete(const Runner& first, const Runner& middle,
                       const Runner& last) {
      const int128_t left =
          int128_t(first.position - middle.position) *
          (last.speed - middle.speed);
      const int128_t right =
          int128_t(middle.position - last.position) *
          (middle.speed - first.speed);
      return left >= right;
  }

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int test_count;
      cin >> test_count;
      while (test_count-- > 0) {
          int n;
          cin >> n;
          vector<Runner> runners(static_cast<size_t>(n));
          for (Runner& runner : runners) {
              cin >> runner.position >> runner.speed;
          }
          sort(runners.begin(), runners.end(),
               [](const Runner& a, const Runner& b) {
                   return a.speed != b.speed
                              ? a.speed < b.speed
                              : a.position > b.position;
               });
          vector<Runner> unique_speed;
          for (const Runner& runner : runners) {
              if (unique_speed.empty() ||
                  unique_speed.back().speed != runner.speed) {
                  unique_speed.push_back(runner);
              }
          }
          vector<Runner> hull;
          for (const Runner& runner : unique_speed) {
              while (!hull.empty() &&
                     hull.back().position <= runner.position) {
                  hull.pop_back();
              }
              while (hull.size() >= 2U &&
                     obsolete(hull[hull.size() - 2U], hull.back(),
                              runner)) {
                  hull.pop_back();
              }
              hull.push_back(runner);
          }
          cout << hull.size() << '\n';
      }
      return 0;
  }
