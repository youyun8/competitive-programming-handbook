statement: 給定起始字串 A、目標字串 B 與若干替換規則；一次操作可在目前字串中選一段恰等於規則左側的子字串，換成右側。求不超過十次操作時，從 A 變成 B 的最少操作數。
constraints:
  - A、B 與規則字串只含英文字母，輸入至檔案結尾
  - 替換規則不超過 6 條
  - 只接受操作次數不超過 10 的解；否則視為無解
input_format: 第一行是 A 與 B；其後每行是一條規則的左側與右側，讀到 EOF。
output_format: 若能在十步內完成，輸出最少步數；否則輸出 `NO ANSWER!`。
samples:
  - input: |
      abcd xyz
      abc xu
      ud y
      y yz
    output: '3'
    explanation: 依序做 `abcd -> xud -> xd -> xyz`，共三次；逐層搜尋保證不會漏掉更短方案。
core_knowledge:
  - 字串改寫形成的隱式狀態圖
  - BFS 最短步數與雜湊集合判重
judgment: 每條規則可套用於目前字串內每一個匹配位置，且重疊位置也必須逐一考慮；答案深度上限是 10。
hints:
  - 把每個完整字串視為節點，一次合法替換視為一條等權邊。
  - 由佇列逐層展開；對每條規則枚舉所有出現位置，產生替換後的新字串並判重。
  - 深度 10 的節點不再展開；第一次取出目標字串時，其深度就是最少操作數。
solution_outline: 從 A 做 BFS，狀態同時保存字串與深度。對每個狀態、每條規則，以 find 從前一匹配位置加一繼續搜尋，將該次匹配替換後的字串加入尚未出現過的狀態。只展開深度小於 10 的狀態。
proof_or_invariant: BFS 佇列依操作次數非遞減取出狀態。展開一個字串時，程式枚舉每條規則及其所有可替換位置，恰好列出狀態圖的全部出邊；visited 只刪除已由更短或等長路徑到達的重複狀態。因此第一次到達 B 的深度是最短距離。若十層內皆未到達，便不存在符合題目上限的轉換。
complexity:
  time: O(S * R * L^2)，S 為十層內相異狀態數、R 為規則數、L 為搜尋到的最大字串長度
  space: O(S * L)
common_errors:
  - 每條規則只替換第一次出現的位置
  - 深度到 10 後仍繼續展開
  - 沒有判重，讓互逆規則反覆產生相同字串

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      string start, target;
      if (!(cin >> start >> target)) return 0;
      vector<pair<string, string>> rules;
      string from, to;
      while (cin >> from >> to) rules.push_back({from, to});
      queue<pair<string, int>> pending;
      unordered_set<string> visited;
      pending.push({start, 0});
      visited.insert(start);
      while (!pending.empty()) {
          const auto [current, depth] = pending.front();
          pending.pop();
          if (current == target) {
              cout << depth << '\n';
              return 0;
          }
          if (depth == 10) continue;
          for (const auto& [left, right] : rules) {
              size_t position = current.find(left);
              while (position != string::npos) {
                  string next = current.substr(0, position) + right
                              + current.substr(position + left.size());
                  if (visited.insert(next).second) pending.push({next, depth + 1});
                  position = current.find(left, position + 1);
              }
          }
      }
      cout << "NO ANSWER!\n";
  }
