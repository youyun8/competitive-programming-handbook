statement: >-
  依鍵值順序給 n 個成功搜尋頻率。建二元搜尋樹，使每個鍵的頻率乘其深度（根深度為 0）總和最小。
constraints:
  - 1 <= n <= 250
  - 頻率為非負整數
  - 輸入含多組資料直到 EOF
input_format: 每組第一行 n，第二行 n 個頻率。
output_format: 每組輸出最小搜尋成本。
samples:
  - input: |-
      3
      1 2 3
    output: |-
      4
    explanation: 以第三個鍵為根、第二個為其左子、第一個再下一層，成本為 3×0+2×1+1×2=4。
core_knowledge: ['最佳二元搜尋樹', '區間 DP', 'Knuth 單調性']
judgment: 選區間根後，兩側所有節點深度增加一，所以轉移需加左右區間頻率和，而不加根頻率。
hints:
  - dp[l][r] 表示 [l,r] 建樹、區間根深度視為 0 的最小成本。
  - 選 k 為根：dp[l][k-1]+dp[k+1][r]+sum(l,r)-freq[k]。
  - 代價滿足四邊形不等式，最佳根單調；k 只需枚舉 opt[l][r-1]..opt[l+1][r]。
solution_outline: >-
  以前綴和求區間頻率，按長度遞增做區間 DP，利用 Knuth 最佳決策單調性縮小根枚舉範圍。
proof_or_invariant: >-
  固定根 k 時，每個非根鍵在其子樹最佳成本外再增加一層，額外成本正是除根外的頻率和，得到轉移。此區間權函數具 Monge 性與包含單調性，Knuth 定理保證 opt[l][r-1]<=opt[l][r]<=opt[l+1][r]。
common_errors: ['把根頻率也加入額外深度', '使用失敗搜尋頻率的另一版 OBST 公式', '空區間 opt 邊界未初始化']
