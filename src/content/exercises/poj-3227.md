statement: 觀察者位於 (0,h)。一座山由 x 座標嚴格遞增的 n 個折線頂點描述，首尾在地面，且山稜依序上升、下降交替。求從觀察點能直接看見的山稜線段總長。
constraints:
  - '1 <= n <= 1000'
  - '0 <= x_i, y_i <= 1000'
  - 頂點 x 嚴格遞增，第一點與最後一點的 y 為 0
  - 奇數序位頂點高於前一點，偶數序位頂點低於前一點
  - n=h=0 結束
input_format: 多組資料。每組首行為 n、h，接著 n 行為依 x 遞增的山稜頂點；0 0 結束。
output_format: 每組輸出可見山稜總長，保留小數點後兩位。

    explanation: 官方三組範例中，依序掃描並保留目前最大的觀測射線斜率；只有斜率創新高的折線部分可見，累加後四捨五入得到所示長度。
core_knowledge:
  - 同一觀察點的射線可用斜率排序
  - 線性折線上一點的觀測斜率單調
  - 可見部分與目前最高視線的交點
judgment: x 嚴格遞增，所以較小 x 的山稜會遮住同一射線上較遠的點。掃描時維護先前點的最大觀測斜率；每段斜率若向上跨過此門檻，超過門檻的後綴恰為可見部分。
hints:
  - 對 x>0 的山稜點 P，從觀察者看向 P 的射線以 s=(P.y-h)/P.x 唯一表示；同斜率上只看得到最先遇到的點。
  - 一條直線山稜上 s 隨位置單調，因此若右端斜率不大於先前最大值，整段不會新增可見長度；反之可見部分是一個後綴。
  - 若左端也超過門檻，整段可見；否則求山稜線段與 y=h+max_slope*x 的交點，累加交點到右端的長度。
solution_outline: 從左到右掃描每條折線段，維護已掃區域最大視線斜率。右端斜率創新高時，依左端是否已高於門檻決定整段或交點後綴可見，累加長度並更新門檻。
proof_or_invariant: 掃到某頂點後，max_slope 是所有已掃山稜點相對觀察者的最大射線斜率。對下一條線段，斜率函數是分式線性且導數符號固定，故單調；只有其斜率大於 max_slope 的點，其射線才未在較小 x 處撞到舊山稜。這些點若存在必構成靠右端的連續後綴，交點公式精確找出起點。更新後不變量成立，最終累加即全部可見長度。
complexity:
  time: 每組 O(n)
  space: O(n)
common_errors:
  - 只把每個山峰與觀察者連線，漏掉部分可見線段
  - 用高度而非相對觀察者的射線斜率比較遮擋
  - 部分可見時把整條線段加入
  - x=0 的首點直接除法而產生無限或 NaN

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  struct Point { long double x; long double y; };

  static long double slope_from_viewer(const Point& point, long double height) {
      if (point.x == 0.0L) {
          return point.y < height
                     ? -numeric_limits<long double>::infinity()
                     : numeric_limits<long double>::infinity();
      }
      return (point.y - height) / point.x;
  }

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n;
      long double height;
      cout << fixed << setprecision(2);
      while (cin >> n >> height && !(n == 0 && height == 0.0L)) {
          vector<Point> points(static_cast<size_t>(n));
          for (Point& point : points) { cin >> point.x >> point.y; }
          long double maximum_slope = -numeric_limits<long double>::infinity();
          long double answer = 0.0L;
          for (int i = 0; i + 1 < n; ++i) {
              const Point a = points[static_cast<size_t>(i)];
              const Point b = points[static_cast<size_t>(i + 1)];
              const long double slope_a = slope_from_viewer(a, height);
              const long double slope_b = slope_from_viewer(b, height);
              const long double segment_length = hypotl(b.x - a.x, b.y - a.y);
              if (slope_b > maximum_slope) {
                  if (slope_a >= maximum_slope ||
                      !isfinite(static_cast<double>(maximum_slope))) {
                      answer += segment_length;
                  } else {
                      const long double numerator =
                          height + maximum_slope * a.x - a.y;
                      const long double denominator =
                          (b.y - a.y) - maximum_slope * (b.x - a.x);
                      const long double ratio = numerator / denominator;
                      answer += (1.0L - ratio) * segment_length;
                  }
              }
              maximum_slope = max(maximum_slope, slope_b);
          }
          cout << answer << '\n';
      }
  }
