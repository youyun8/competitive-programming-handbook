statement: 維護一個游標與可編輯文字，支援移動游標、在游標後插入字串、刪除游標後若干字元、輸出游標後若干字元，以及游標前後移一格。
constraints:
  - 操作總數不超過 500000
  - 任意時刻文字長度不超過 2000000
  - 插入內容由 ASCII 32 至 126 的可見字元組成
input_format: 第一行操作數；其後每項為 Move k、Insert n 加 n 個字元、Delete n、Get n、Prev 或 Next。
output_format: 每個 Get 操作輸出指定文字並換行。
samples:
  - input: |
      8
      Insert 5
      hello
      Move 0
      Get 5
      Move 5
      Prev
      Insert 1
      X
      Move 0
      Get 6
    output: |
      hello
      hellXo
    explanation: 游標位置表示其左側已有多少字元；移到末端再向前一格後插入 X，得到 hellXo。
core_knowledge: [隱式序列樹, 按大小 split, merge, 線性輸出子樹]
judgment: 操作只依位置切割與拼接序列，不需要按鍵值搜尋，適合用隱式 Treap（也可用原章節塊狀鏈表）。
hints:
  - 令游標 cursor 等於其左側字元數；Move、Prev、Next 只改這個整數。
  - 以子樹大小作隱式索引，split(root,k) 分成前 k 字元與其餘部分。
  - Insert 合併 left+new+right；Delete 丟棄中段；Get 中序走訪中段後再原樣合併回去。
solution_outline: 以隱式 Treap 儲存字元，靠 split/merge 完成區間插入、刪除和擷取；游標獨立記錄。
proof_or_invariant: Treap 的中序序列始終等於目前文字，size 是子樹字元數。按 cursor 與長度切出的中段恰為操作範圍，合併保持各段原相對順序，因此所有操作正確。
complexity:
  time: 每次編輯期望 O(log L + output_length)
  space: O(插入過的總字元數)
common_errors:
  - 把游標當成右側第一字元的一基索引而產生 off-by-one
  - Insert 讀取時用 >> 而丟失空格
  - Get 後未將三段合併回原樹
