statement: 維護陣列的時間版本：目前版本可做區間加與區間和查詢，也能查詢指定歷史版本，或把目前時間退回指定版本；區間修改才產生下一版本。
constraints:
  - '1 <= n, m <= 100000'
  - 初值、加值及區間和須以 64 位元有號整數儲存
  - 'C l r d、Q l r、H l r t、B t 的區間與版本皆合法'
input_format: 多組資料直到 EOF；每組先給 n、m 與初值，後接 m 個命令。C 修改、Q 查目前、H 查歷史、B 回溯。
output_format: 每個 Q 或 H 命令輸出一行；每組資料後輸出空行。
samples:
  - input: |
      3 6
      1 2 3
      Q 1 3
      C 1 2 5
      Q 1 3
      H 1 2 0
      B 0
      Q 2 3
    output: |
      6
      16
      3
      5
    explanation: 第一次修改後目前陣列為 6、7、3；歷史版本 0 的前兩項仍為 1、2，回到版本 0 後第 2 到 3 項和為 5。
core_knowledge: [可持久化懶線段樹, 路徑複製, 版本根]
judgment: 區間加只會接觸 O(log n) 個完整覆蓋節點與邊界路徑；複製受影響節點並共享其餘子樹即可保存全部時間版本。
hints:
  - 每次 C 從目前版本根開始，沿修改會經過的節點做路徑複製。
  - 完整覆蓋時可把增量留在該節點；查詢向下時攜帶祖先尚未下推的增量。
  - Q、H 不建版本；C 建立 current+1，B 只把 current 指向指定歷史根。
solution_outline: 建立版本 0，區間加時 clone 節點並更新 sum、lazy，保存新根。查詢以額外參數累積祖先 lazy。B 改變目前版本編號。
proof_or_invariant: 每個版本根的 sum 等於該版本區間和，lazy 表示已計入本節點 sum、但未寫入子節點的整段增量。更新只複製被碰觸節點，因此舊根可達節點不變；帶入祖先 lazy 的查詢還原所有增量。
complexity:
  time: 每次修改或查詢 O(log n)，回溯 O(1)
  space: O(n+m log n)
common_errors:
  - 回溯後從最後建立版本而非目前版本繼續修改
  - 查詢時漏加祖先 lazy，或下推時改壞共享子節點
  - 區間和使用 int 溢位

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;
  struct Node{int left=0,right=0;long long sum=0,lazy=0;};
  static int build(vector<Node>&t,const vector<long long>&a,int l,int r){int id=static_cast<int>(t.size());t.push_back({});if(l==r){t[static_cast<size_t>(id)].sum=a[static_cast<size_t>(l)];return id;}int mid=(l+r)/2;t[static_cast<size_t>(id)].left=build(t,a,l,mid);t[static_cast<size_t>(id)].right=build(t,a,mid+1,r);t[static_cast<size_t>(id)].sum=t[static_cast<size_t>(t[static_cast<size_t>(id)].left)].sum+t[static_cast<size_t>(t[static_cast<size_t>(id)].right)].sum;return id;}
  static int add(vector<Node>&t,int old,int l,int r,int ql,int qr,long long d){int id=static_cast<int>(t.size());t.push_back(t[static_cast<size_t>(old)]);if(ql<=l&&r<=qr){t[static_cast<size_t>(id)].sum+=d*(r-l+1);t[static_cast<size_t>(id)].lazy+=d;return id;}int mid=(l+r)/2;if(ql<=mid)t[static_cast<size_t>(id)].left=add(t,t[static_cast<size_t>(old)].left,l,mid,ql,qr,d);if(qr>mid)t[static_cast<size_t>(id)].right=add(t,t[static_cast<size_t>(old)].right,mid+1,r,ql,qr,d);t[static_cast<size_t>(id)].sum=t[static_cast<size_t>(t[static_cast<size_t>(id)].left)].sum+t[static_cast<size_t>(t[static_cast<size_t>(id)].right)].sum+t[static_cast<size_t>(id)].lazy*(r-l+1);return id;}
  static long long query(const vector<Node>&t,int id,int l,int r,int ql,int qr,long long carry){if(ql<=l&&r<=qr)return t[static_cast<size_t>(id)].sum+carry*(r-l+1);carry+=t[static_cast<size_t>(id)].lazy;int mid=(l+r)/2;long long result=0;if(ql<=mid)result+=query(t,t[static_cast<size_t>(id)].left,l,mid,ql,qr,carry);if(qr>mid)result+=query(t,t[static_cast<size_t>(id)].right,mid+1,r,ql,qr,carry);return result;}
