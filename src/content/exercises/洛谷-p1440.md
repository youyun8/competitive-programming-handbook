statement: 給定 n 個正整數。對每個位置 i，輸出它之前至多 m 個元素的最小值；若 i 前方沒有任何元素，輸出 0。當前元素本身不包含在查詢範圍。
constraints:
  - '1 <= n <= 2 * 10^6'
  - '1 <= m <= 2 * 10^6'
  - '1 <= a_i <= 3 * 10^7'
input_format: 第一行為 n、m；第二行為 n 個正整數。
output_format: 輸出 n 行；第 i 行是第 i 項之前最多 m 項的最小值，第一行固定為 0。
samples:
  - input: |

      7 8 1 4 3 2
    output: |
      0
      7
      7
      1
      1
      3
    explanation: 核實官方範例。例如第 5 項為 3，其前方至多兩項是 1、4，故輸出 1；注意不包含當前的 3。
core_knowledge:
  - 前置窗口與一般滑動窗口的邊界差異
  - 遞增單調佇列
judgment: n 可達兩百萬；需要 O(n) 處理，且每次答案查詢必須在加入當前值之前完成。
hints:
  - 第 i 個答案只查看索引 [i-m,i-1]；先把「不包含 i」這件事寫在窗口定義中。
  - 以雙端佇列存索引，讓其對應值遞增；過期索引從隊首離開，被新值支配的索引從隊尾離開。
  - 掃到 i 時，先淘汰索引小於 i-m 的隊首並輸出隊首值（i=0 輸出 0），之後才用 a[i] 維護單調性並入隊。
solution_outline: 由左至右掃描。每輪先移除早於 i-m 的候選，輸出目前佇列隊首所指最小值；再移除所有不小於當前值的隊尾並加入當前索引，供後續位置使用。
proof_or_invariant: 輸出位置 i 前，佇列內索引都在 [i-m,i-1]，且值嚴格遞增，因此隊首是指定範圍最小值。較早且不小於新值的索引被刪除是安全的，因新值更晚過期且不更差。輸出後才加入 i，故當前元素不會誤入自己的答案。
complexity:
  time: 'O(n)'
  space: 'O(m)'
common_errors:
  - 先加入當前值再輸出，錯把 a_i 包含在範圍內
  - 過期條件使用小於等於 i-m，錯刪仍合法的左端點
  - 忘記第一項前方沒有元素時必須輸出 0

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n, m;
      if (!(cin >> n >> m)) return 0;
      vector<int> values(n);
      for (int& value : values) cin >> value;
      deque<int> candidates;
      for (int i = 0; i < n; ++i) {
          while (!candidates.empty() && candidates.front() < i - m) {
              candidates.pop_front();
          }
          cout << (candidates.empty() ? 0 : values[candidates.front()]) << '\n';
          while (!candidates.empty() && values[candidates.back()] >= values[i]) {
              candidates.pop_back();
          }
          candidates.push_back(i);
      }
      return 0;
  }
