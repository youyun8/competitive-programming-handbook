  給一棵以 1 為根的樹，刪除最少邊，使某個剩餘連通塊恰有 p 個節點；這個連通塊不必包含原根。

judgment: 目標連通塊可把任一節點當最高點；子樹內保留節點數與切掉兒子邊的代價可做 DP。
hints:
  - 令 dp[u][j] 為在 u 子樹內保留含 u 的 j 點連通塊，需切掉的最少兒子邊數。
  - 初始化 dp[u][1]=兒子數；合併兒子 v 並取 k 點時，原先假設切掉的 u–v 邊要減回 1。
  - 若 u 不是原根，最後還要切掉 u 與父親的邊；枚舉 u 作目標連通塊最高點。
solution_outline: >-
  後序計算子樹大小與 dp。每點先只留自己並切全部兒子；逐兒子做揹包，合併非空方案時代價 dp[u][j]+dp[v][k]-1。答案取 dp[1][p] 或 dp[u][p]+1。
proof_or_invariant: >-
  任何含 u 且位於 u 子樹的連通塊，在每個兒子子樹中要麼不取（必切父子邊），要麼取一個含該兒子的連通塊。初始化與 -1 恰好對應兩種情況，故歸納得到最小內部切邊數。每個全樹連通塊有唯一最高點，再補其父邊即完整計數。

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <limits>
  #include <vector>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n, target;
      cin >> n >> target;
      vector<vector<int>> children(static_cast<size_t>(n + 1));
      for (int i = 1; i < n; ++i) {
          int parent, child; cin >> parent >> child;
          children[parent].push_back(child);
      }
      const int infinity = numeric_limits<int>::max() / 4;
      vector<vector<int>> dp(static_cast<size_t>(n + 1),
                             vector<int>(static_cast<size_t>(target + 1), infinity));
      vector<int> size(static_cast<size_t>(n + 1));
      auto dfs = [&](auto&& self, int u) -> void {
          size[u] = 1;
          dp[u][1] = static_cast<int>(children[u].size());
          for (int v : children[u]) {
              self(self, v);
              for (int total = min(target, size[u] + size[v]); total >= 2; --total)
                  for (int take = 1; take <= min(size[v], total - 1); ++take)
                      if (dp[u][total - take] < infinity && dp[v][take] < infinity)
                          dp[u][total] = min(dp[u][total],
                              dp[u][total - take] + dp[v][take] - 1);
              size[u] += size[v];
          }
      };
      dfs(dfs, 1);
      int answer = dp[1][target];
      for (int u = 2; u <= n; ++u)
          if (size[u] >= target) answer = min(answer, dp[u][target] + 1);
      cout << answer << '\n';
  }
