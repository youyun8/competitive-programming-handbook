judgment: 本題雖列於佇列章題單，核心其實是 Kadane 動態規劃；每個位置只需比較延續前段或從當前值重新開始。
hints:
  - 先只考慮「必須以位置 i 結尾」的最佳非空子段；它只有延續上一段或從 i 重新開始兩種來源。
  - 若前一段總和小於 0，帶著它只會讓當前值變差，應從 i 重啟並記錄新起點；等於 0 時保留舊段可符合較早答案。
  - 以第一個元素初始化全域答案；只有目前總和嚴格更大時才更新答案與端點，便不會在相同最大值時覆蓋較早解。
solution_outline: 線性掃描並維護 current_sum 與 current_left。前綴段和為負時從當前元素重啟，否則延續；當 current_sum 嚴格超過 best_sum 時記錄總和及兩端點。
proof_or_invariant: 掃到 i 後，current_sum 是所有以 i 結尾非空子段的最大和，current_left 是依規則保留的最早起點：負的前段必須捨棄，非負前段延續不劣。best_sum 則是至 i 為止所有子段的最大值；只在嚴格變大時更新可保留最先答案。歸納可知最終總和與端點正確。
complexity:
  time: '每組 O(N)'
  space: 'O(1)'
common_errors:

  - current_sum 等於 0 時重啟，可能改掉題目要求的較早區間
  - 忘記測試組之間的空行或 Case 格式

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int test_count;
      cin >> test_count;
      for (int case_id = 1; case_id <= test_count; ++case_id) {
          int n;
          cin >> n;
          long long current_sum = 0, best_sum = numeric_limits<long long>::lowest();
          int current_left = 1, best_left = 1, best_right = 1;
          for (int i = 1; i <= n; ++i) {
              int value;
              cin >> value;
              if (current_sum < 0) {
                  current_sum = value;
                  current_left = i;
              } else {
                  current_sum += value;
              }
              if (current_sum > best_sum) {
                  best_sum = current_sum;
                  best_left = current_left;
                  best_right = i;
              }
          }
          if (case_id > 1) cout << '\n';
          cout << "Case " << case_id << ":\n";
          cout << best_sum << ' ' << best_left << ' ' << best_right << '\n';
      }
  }
