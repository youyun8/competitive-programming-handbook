proof_or_invariant: 轉移矩陣乘 [a_i,a_{i-1}]^T 後，第一分量依定義為 a_{i+1}，第二分量為 a_i。重複 n-2 次即從 [a_2,a_1] 到 [a_n,a_{n-1}]；快速冪不改變此矩陣乘積。

      Matrix result;

          if ((exponent & 1ULL) != 0ULL) { result = multiply(result, base_matrix); }
          base_matrix = multiply(base_matrix, base_matrix);
