statement: |-
  給定若干不含空白的字串。對每個字串，判斷它從左向右讀與從右向左讀是否完全相同。

  - '每筆資料是一個不含空白的字串'

output_format: 每個字串輸出一行；若為回文輸出 yes，否則輸出 no。
samples:
  - input: |
      4
      level
      abcde
      noon
      haha
    output: |
      yes
      no
      yes
      no
    explanation: level 與 noon 的對稱位置字元都相同；abcde 與 haha 至少有一對對稱字元不同。
core_knowledge:
  - '左右指標同步向中央移動'
  - '對稱位置為 left 與 length-1-left'
judgment: '只需找到一組不相同的對稱字元即可否定回文；不需要建立反轉字串。'
hints:
  - '先想想第一個字元應與哪一個位置比較。'
  - '令 left 從 0 開始、right 從字串末端開始，每輪比較後讓兩者向中央靠近。'
  - '若任一輪字元不同就標記為非回文；直到 left 不小於 right 都相同才輸出 yes。'
solution_outline: 對每個字串設 left=0、right=長度減一。當 left<right 時比較兩端字元；不同便停止並輸出 no，相同則 left 加一、right 減一。若沒有發現不等字元，輸出 yes。
proof_or_invariant: '每輪開始時，區間外已檢查過的所有對稱字元都相同。若當前兩端不同，字串必非回文；若相同，移除這一對後不影響內部是否對稱。迴圈正常結束時所有對稱字元皆已相等，故字串為回文。'
common_errors:
  - '把題目要求的全小寫 yes/no 輸出成其他大小寫'
  - '右指標誤設為 length，造成越界'
  - '只比較前後第一對字元，未繼續檢查內部'

  time: '每個長度為 L 的字串為 O(L)，全部為 O(字元總數)'
  space: 'O(L)：儲存當前字串；判斷本身只需 O(1) 額外空間'

cpp_solution: |
  #include <iostream>
  #include <string>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int test_count = 0;
      cin >> test_count;
      while (test_count-- > 0) {
          string text;
          cin >> text;
          bool is_palindrome = true;
          size_t left = 0;
          size_t right = text.size();
          while (left < right) {
              --right;
              if (text[left] != text[right]) {
                  is_palindrome = false;
                  break;
              }
              ++left;
          }
          cout << (is_palindrome ? "yes" : "no") << '\n';
      }
      return 0;
  }
