statement: 給定若干篇文章各自包含的單字，對每個查詢單字，輸出包含它的所有文章編號。
constraints:
  - '1 <= n <= 1000'
  - 每篇文章最多 500 個小寫單字，每個單字長度不超過 20
  - '1 <= m <= 10000'
input_format: 第一行 n；每篇先給單字數再給各單字；接著 m 與 m 個查詢單字。
output_format: 每個查詢輸出包含該單字的文章編號，遞增且不重複；沒有則輸出空行。
samples:
  - input: "3\n2 hello world\n2 hello trie\n1 world\n3\nhello\nworld\nnone\n"
    output: "1 2\n1 3\n\n"
    explanation: hello 出現在文章 1、2，world 出現在 1、3，none 未出現。
core_knowledge: [倒排索引, Trie 終點掛文章串列, 同篇文章去重]
judgment: 文章編號從 1 開始；同一文章重複出現同一單字時仍只輸出一次。
hints:
  - 查詢只關心「單字到文章」的反向關係，而不是文章原本的順序。
  - 把單字插入 Trie，並在終止節點保存出現過的文章編號。
  - 文章按編號讀入，因此只要終點串列最後一項不同就附加，天然維持遞增且去重。
solution_outline: 建 Trie；讀第 i 篇時把 i 附加到每個單字終點的 postings，查詢走到終點後直接列出 postings。
proof_or_invariant: 每個終止節點唯一對應完整單字，其 postings 在讀完前 i 篇後恰含前 i 篇中包含此字的編號；同篇去重且依讀入順序附加，故答案不漏不重且遞增。
common_errors: [同篇重複單字導致重複編號, 查不到單字時沿 Trie 建新節點, 輸出多餘前導空格]
complexity:
  time: O(L + A)，L 為輸入與查詢總字元數，A 為輸出量
  space: O(L + P)，P 為不同單字與文章的關聯數

  #include <array>
  #include <iostream>
  #include <string>
  #include <vector>
  using namespace std;
  struct Node{array<int,26> next{};vector<int> articles;};
  int main(){ios::sync_with_stdio(false);cin.tie(nullptr);int n=0;cin>>n;vector<Node> trie(1);
      for(int article=1;article<=n;++article){int count=0;cin>>count;while(count--){string word;cin>>word;int u=0;for(char c:word){size_t x=static_cast<size_t>(c-'a');if(trie[static_cast<size_t>(u)].next[x]==0){trie[static_cast<size_t>(u)].next[x]=static_cast<int>(trie.size());trie.push_back({});}u=trie[static_cast<size_t>(u)].next[x];}auto& list=trie[static_cast<size_t>(u)].articles;if(list.empty()||list.back()!=article)list.push_back(article);}}
      int queries=0;cin>>queries;while(queries--){string word;cin>>word;int u=0;bool found=true;for(char c:word){int v=trie[static_cast<size_t>(u)].next[static_cast<size_t>(c-'a')];if(v==0){found=false;break;}u=v;}if(found){const auto& list=trie[static_cast<size_t>(u)].articles;for(size_t i=0;i<list.size();++i){if(i>0)cout<<' ';cout<<list[i];}}cout<<'\n';}
