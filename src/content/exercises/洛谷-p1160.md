statement: |-
  n 位同學的編號為 1 到 n。起初隊伍只有 1 號；之後依編號由 2 到 n 入列，每位新同學 i 都會被安排在某位已入列同學 k 的左邊或右邊。全部入列後，再依序執行 m 次移除指令；若指定編號早已離隊，該指令不產生效果。請輸出所有操作完成後，隊伍由左至右的編號。
constraints:
  - '1 < m <= n <= 100000'
  - '對每個 2 <= i <= n：1 <= k < i，p 為 0 或 1'
  - '每次移除指令中的 x 滿足 1 <= x <= n；同一編號可能被重複指定'
input_format: |-
  第一行輸入整數 n。接下來 n-1 行依序描述 2 到 n 號同學：描述 i 號的該行含 k、p；p=0 表示把 i 放在 k 左邊，p=1 表示放在 k 右邊。下一行輸入 m，之後 m 行各輸入一個要移除的編號 x。
output_format: 一行輸出操作結束後仍在隊伍中的同學編號，由左至右以空格分隔。
samples:
  - input: |
      4
      1 0
      2 1
      1 0
      2
      3
      3
    output: |
      2 4 1
    explanation: |-
      這是核實過的官方範例。2 號放在 1 號左邊後為 [2,1]；3 號放在 2 號右邊後為 [2,3,1]；4 號放在 1 號左邊後為 [2,3,4,1]。第一次移除 3 得 [2,4,1]，第二次再指定 3 時，因 3 已離隊而忽略，故輸出 2 4 1。
core_knowledge:
  - 以編號直接索引節點的靜態雙向鏈結串列
  - 在已知節點旁 O(1) 插入
  - 以存活標記使重複刪除不影響結構
judgment: |-
  n、m 可達 100000。若用陣列真的搬動元素，單次插入或刪除可能花 O(n)，總時間最差為 O(n^2)。由於每次操作都直接給出同學編號，可用兩個陣列記錄每個編號的左右鄰居，讓插入與首次刪除皆為 O(1)。
hints:
  - 不必在陣列裡搬動整段隊伍；對每位同學，只要知道他目前左、右兩側緊鄰誰，就足以描述整條隊伍。
  - 加入 0 號虛擬節點代表隊伍兩端。要把 i 插到 k 左邊，找出 k 原本的左鄰，並同時改好新節點與兩側舊節點的連結；插到右邊完全對稱。
  - 刪除 x 時先檢查存活標記。若仍在隊中，令 x 的左鄰與右鄰互相連接；最後從虛擬節點的右鄰一路向右輸出即可。
solution_outline: |-
  建立 left_of、right_of 兩個長度 n+1 的陣列，0 號作為首尾共用的虛擬節點。初始化 0 與 1 互為左右鄰居，形成 0→1→0。對 i=2..n，若 p=0，就把 i 接在 left_of[k] 與 k 之間；若 p=1，就接在 k 與 right_of[k] 之間。每次刪除指令先查看 alive[x]，只有 x 尚在隊伍時才把 left_of[x] 與 right_of[x] 直接相連並清除標記。最後由 right_of[0] 出發，沿 right_of 走到 0。
proof_or_invariant: |-
  在每次插入或有效刪除後，對每個仍在隊伍中的相鄰節點 a、b，都有 right_of[a]=b 且 left_of[b]=a；由 right_of[0] 沿右鏈走到 0 的順序恰為目前隊伍由左至右的順序。插入時只把一條 a↔b 邊替換為 a↔i↔b，不改變其他節點次序；刪除時只把 a↔x↔b 縮回 a↔b，也不改變其餘相對次序。alive 使已刪節點不會被再次改鏈。因此所有操作後沿右鏈輸出的正是最終隊伍。
common_errors:
  - 插入時只更新新節點的左右鄰居，漏改兩側舊節點指向新節點的連結。
  - 未記錄節點是否仍存活，讓重複刪除破壞已修好的鏈。
  - 沒有處理隊首或隊尾操作；使用 0 號虛擬節點可統一邊界。
  - 把 p=0 與 p=1 的方向寫反。
complexity:
  time: 'O(n+m)：每次插入與刪除指令皆為 O(1)，最後走訪至多 n 個節點'
  space: 'O(n)：左右鄰居與存活標記各以編號索引'

cpp_solution: |
  #include <iostream>
  #include <vector>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      int n = 0;
      cin >> n;
      vector<int> left_of(static_cast<size_t>(n) + 1, 0);
      vector<int> right_of(static_cast<size_t>(n) + 1, 0);
      vector<bool> alive(static_cast<size_t>(n) + 1, true);

      left_of[0] = 1;
      right_of[0] = 1;
      left_of[1] = 0;
      right_of[1] = 0;

      for (int student = 2; student <= n; ++student) {
          int target = 0;
          int side = 0;
          cin >> target >> side;

          if (side == 0) {
              const int neighbor = left_of[static_cast<size_t>(target)];
              left_of[static_cast<size_t>(student)] = neighbor;
              right_of[static_cast<size_t>(student)] = target;
              right_of[static_cast<size_t>(neighbor)] = student;
              left_of[static_cast<size_t>(target)] = student;
          } else {
              const int neighbor = right_of[static_cast<size_t>(target)];
              left_of[static_cast<size_t>(student)] = target;
              right_of[static_cast<size_t>(student)] = neighbor;
              right_of[static_cast<size_t>(target)] = student;
              left_of[static_cast<size_t>(neighbor)] = student;
          }
      }

      int m = 0;
      cin >> m;
      while (m-- > 0) {
          int student = 0;
          cin >> student;
          if (!alive[static_cast<size_t>(student)]) {
              continue;
          }

          const int left_neighbor = left_of[static_cast<size_t>(student)];
          const int right_neighbor = right_of[static_cast<size_t>(student)];
          right_of[static_cast<size_t>(left_neighbor)] = right_neighbor;
          left_of[static_cast<size_t>(right_neighbor)] = left_neighbor;
          alive[static_cast<size_t>(student)] = false;
      }

      bool first_output = true;
      for (int student = right_of[0]; student != 0;
           student = right_of[static_cast<size_t>(student)]) {
          if (!first_output) {
              cout << ' ';
          }
          first_output = false;
          cout << student;
      }
      cout << '\n';
      return 0;
  }
