statement: >-
  帶權樹的每點都有礦物，k 個機器人同從指定節點 s 出發；必須造訪全部節點，機器人可在任意處離開，求總行走能量最小值。
constraints:
  - 1 <= n <= 10000
  - 1 <= k <= 10
  - 1 <= 邊權 <= 10000
  - 輸入含多組資料直到 EOF
input_format: 每組第一行 n、s、k，接著 n-1 行給邊的兩端與權重。
output_format: 每組輸出最小總能量。
samples:
  - input: |-
      3 1 1
      1 2 1
      1 3 1
      3 1 2
      1 2 1
      1 3 1
    output: |-
      3
      2
    explanation: 一台需走 1→2→1→3，兩台可分別走向 2、3。
core_knowledge: ['多機器人樹形 DP', '回程與終點', '分組揹包']
judgment: 子樹若沒有機器人留在其中，連接邊需往返；若有 j 台留在其中，該邊只需由 j 台各走入一次。
hints:
  - 令 dp[u][j] 為遍歷 u 子樹後有 j 台機器人留在其中的最小成本，j=0 表示全部返回 u。
  - 合併兒子 v 的基準是 dp[v][0]+2w；若分配 x>=1 台則改用 dp[v][x]+xw。
  - 按 j 倒序做分組揹包，答案為 dp[s][k]；多餘機器人可走相同零長路徑。
solution_outline: >-
  以 s 根樹，後序合併每個兒子。對每個總機器人數先加入往返方案，再枚舉分配到兒子的正機器人數取較小值。
proof_or_invariant: >-
  任何遍歷方案對父子邊只有兩類：兒子子樹內無終點時至少往返一次；有 x 個終點時 x 台各進入一次且子樹內按 dp 最優。不同兒子互不相交，揹包枚舉全部分配，歸納即得最小成本。
common_errors: ['把 j=0 誤認為不用遍歷子樹', '有 x 台終止時仍加 2w', '合併時正序覆寫同一兒子']
complexity:
  time: 'O(nk^2)'
  space: 'O(nk)'
