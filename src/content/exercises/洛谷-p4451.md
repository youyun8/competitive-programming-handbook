judgment: 拆分有順序，1+2 與 2+1 是不同方案。
hints:
  - Fibonacci 正項生成函數是 A(x)=x/(1-x-x^2)。
  - 任意非空有序串的生成函數是 A/(1-A)=x/(1-2x-x^2)。
  - 因此答案 s_n=2s_(n-1)+s_(n-2)；逐位處理十進位指數即可。
solution_outline: 使用轉移矩陣 [[2,1],[1,0]]。由 n 的十進位字串先減一，逐位維護 result=result^10·matrix^digit，最後取 result[0][0]。
proof_or_invariant: 一個拆分是由一個以上、權值生成函數為 A 的部件依序組成，故總生成函數 Σ_(m>=1)A^m=A/(1-A)=x/(1-2x-x²)。比較係數得到 s_0=0、s_1=1 與二階遞推；矩陣冪恰實作此遞推。逐位 invariant 為 result=M^(已讀十進位前綴)。
common_errors: [把有序拆分當整數分割, 直接把萬位 n 轉成整數, 矩陣指數使用 n 而非 n-1]

cpp_solution: |
  #include <array>
  #include <iostream>
  #include <string>
  using namespace std;
  constexpr long long mod_value = 1000000007;
  struct Matrix { array<array<long long, 2>, 2> value{}; };
  Matrix multiply(const Matrix &a, const Matrix &b) {
      Matrix result;
      for (int i = 0; i < 2; ++i)
          for (int k = 0; k < 2; ++k)
              for (int j = 0; j < 2; ++j)
                  result.value[static_cast<size_t>(i)][static_cast<size_t>(j)] =
                      (result.value[static_cast<size_t>(i)][static_cast<size_t>(j)] +
                       a.value[static_cast<size_t>(i)][static_cast<size_t>(k)] *
                           b.value[static_cast<size_t>(k)][static_cast<size_t>(j)]) %
                      mod_value;
      return result;
  }
  Matrix power(Matrix base, int exponent) {
      Matrix result;
      result.value[0][0] = 1;
      result.value[1][1] = 1;
      while (exponent > 0) {
          if ((exponent & 1) != 0) result = multiply(result, base);
          base = multiply(base, base);
          exponent >>= 1;
      }
      return result;
  }
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      string n;
      cin >> n;
      for (int i = static_cast<int>(n.size()) - 1; i >= 0; --i) {
          if (n[static_cast<size_t>(i)] > '0') { --n[static_cast<size_t>(i)]; break; }
          n[static_cast<size_t>(i)] = '9';
      }
      Matrix transition;
      transition.value[0][0] = 2;
      transition.value[0][1] = 1;
      transition.value[1][0] = 1;
      Matrix result;
      result.value[0][0] = 1;
      result.value[1][1] = 1;
      for (char digit : n) {
          result = multiply(power(result, 10), power(transition, digit - '0'));
      }
      cout << result.value[0][0] << '\n';
      return 0;
  }
