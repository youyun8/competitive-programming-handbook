statement: >-
  給兩個只含小寫英文字母的字串。一次操作可刪除一個字元、插入一個字元，或把一個字元
  改成另一個字元。求把第一個字串轉換成第二個字串所需的最少操作次數。
constraints:
  - 兩個字串皆只含小寫英文字母
  - 兩字串長度皆小於 2000
input_format: 第一行是原字串，第二行是目標字串。
output_format: 輸出一個整數，表示最少操作次數。
samples:
  - input: |-
      sfdqxbw
      gfdgw
    output: '4'
    explanation: 例如刪除 s、把 q 改成 g，再刪除 x 與 b，共四次可得到 gfdgw；DP 證明不能更少。
core_knowledge:
  - Levenshtein distance 的前綴 DP
  - 插入、刪除、替換三種末步轉移
judgment: 每次操作成本都是一；只需輸出最少次數，不必輸出操作序列。
hints:
  - 用兩個前綴長度定義狀態，空字串轉成長度 j 的前綴需要 j 次插入。
  - 比較兩個前綴末字元；相同時不需新操作，不同時枚舉刪除、插入與替換的最後一步。
  - 每格只依賴上、左、左上三格；逐列計算並保存上一列，可把空間壓成 O(m)。
solution_outline: >-
  令 dp[i][j] 為第一字串前 i 個字元變成第二字串前 j 個字元的最少操作。空前綴初始化為
  對方長度。末字元相同取 dp[i-1][j-1]；否則取上、左、左上的最小值加一。實作用兩列。
proof_or_invariant: >-
  任一最優轉換的最後一步若處理不同末字元，必是刪除原字串末字元、插入目標末字元，或替換
  原末字元，分別留下 dp[i-1][j]、dp[i][j-1]、dp[i-1][j-1] 子問題。末字元相同時可直接
  配對它們，最優值等於左上狀態。轉移枚舉所有可能最後一步且每個候選可行，配合空前綴基底，
  依 i+j 歸納即得最少操作數。
common_errors:
  - 混淆插入與刪除所對應的上方、左方狀態
  - 空字串列初始化成零，而不是 0、1、2、…
  - 字元相同時仍強制加一
complexity:
  time: O(n * m)
  space: O(m)

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <numeric>
  #include <string>
  #include <vector>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      string source;
      string target;
      cin >> source >> target;

      vector<int> previous(target.size() + 1U);
      vector<int> current(target.size() + 1U);
      iota(previous.begin(), previous.end(), 0);
      for (size_t i = 1; i <= source.size(); ++i) {
          current[0] = static_cast<int>(i);
          for (size_t j = 1; j <= target.size(); ++j) {
              if (source[i - 1U] == target[j - 1U]) {
                  current[j] = previous[j - 1U];
              } else {
                  current[j] = 1 + min({previous[j], current[j - 1U], previous[j - 1U]});
              }
          }
          previous.swap(current);
      }
      cout << previous.back() << '\n';
  }
