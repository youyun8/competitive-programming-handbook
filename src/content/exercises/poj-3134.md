title: POJ 3134 Power Calculus
section: '3.9'
statement: 從 x^1 開始，每步可把目前已得到的任兩個冪相乘或相除，得到指數的和或差。求得到 x^n 的最少步數。
constraints:
  - 1 <= n <= 1000
  - 多組資料，以 0 結束
  - 中間指數可由已有指數和或絕對差產生
judge: 一步只能使用當前鏈中已得到的兩個冪；重複指數沒有幫助。
judgment: 新指數必須由鏈中任意兩個既有指數相加或取絕對差得到，不能使用尚未生成的中間值；只要鏈中任一位置等於 n 即完成，n=1 時答案為 0。
hints:
  - 從深度 0 開始逐步增加上限做 IDDFS。
  - 若目前最大指數即使每步翻倍，剩餘步數內仍小於 n，可剪枝。
  - 下一指數枚舉任兩個已有指數的和與絕對差，略過非正、過大及重複值。
input_format: 每行一個 n，以 0 結束。
output_format: 每個 n 輸出最少步數。
samples:
  - input: |
      1
      15
      0
    output: |-
      0
      5
    explanation: x 已是一次方；15 可用五步加減鏈得到。
core_knowledge:
  - 加減鏈
  - 迭代加深 DFS
solution_outline: 維護目前可用指數鏈，以倍增上界剪枝的 IDDFS 枚舉加減結果。
proof_or_invariant: 固定深度時 DFS 枚舉每步由任兩個已有指數產生的所有有用正結果；倍增是單步最大增長，剪枝是必要條件。首個成功深度因此最小。
complexity:
  time: 指數型，n<=1000 且 IDDFS 剪枝可行
  space: O(answer)
common_errors:
  - 只允許與最後指數運算
  - 漏掉差的絕對值
  - 未做倍增下界剪枝
