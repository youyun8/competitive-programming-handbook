statement: 若干城市由無環雙向加權道路組成森林。回答兩城市之間距離；若不連通則輸出 Not connected。
constraints:
  - '1 <= n <= 10000'
  - '0 <= m <= 10000'
  - '1 <= query_count <= 1000000'
  - 每組道路不形成環，輸入直到 EOF
input_format: 每組先給 n、m、q；接著 m 行 u、v、w，再接 q 行詢問 u、v。
output_format: 每個詢問輸出距離，或固定字串 Not connected。
samples:
  - input: |
      4 2 3
      1 2 3
      3 4 5
      1 2
      1 3
      3 4
    output: |
      3
      Not connected
      5
    explanation: 1、2 與 3、4 分屬兩棵樹。
core_knowledge: [component_id, binary_lifting, root_distance]
judgment: 圖保證為森林；每個分量任選根即可套用 LCA 距離公式，查詢前須先判斷分量。
hints:
  - 從每個尚未訪問的節點各做一次 DFS/BFS，填 component、depth 與根距離。
  - 同分量時以倍增求 LCA。
  - 距離為 distance[u]+distance[v]-2distance[lca]；不同分量直接輸出指定字串。
solution_outline: 逐分量 BFS 建立父表第一層、深度、距離與分量編號，再建完整倍增表並回答詢問。
proof_or_invariant: 每個森林分量都是樹，同分量兩點唯一簡單路徑經 LCA，距離公式成立；component 不同時不存在路徑。
complexity:
  time: O((n+m)log n+q log n)
  space: O(n log n+m)
common_errors:
  - 只從節點 1 建表而漏掉其他分量
  - 不連通時仍拿兩棵樹的 LCA 計算
  - 忘記輸入有多組且沒有測資數
