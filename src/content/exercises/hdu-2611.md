statement: 給定 n 個整數，輸出前 P 個互異非遞減子序列。先按長度遞增；同長度按子序列數值的字典序排序。
constraints:
  - 1 < n <= 100
  - 1 < P <= 100000
  - 元素不超過 32 位有號整數
input_format: 多組資料至 EOF；每組 n、P，再給 n 個整數。
output_format: 依序逐行輸出，每組後空一行。
samples:
  - input: |
      3 5
      1 3 2
    output: |
      1
      2
      3
      1 2
      1 3
    explanation: 同長度改以數值比較，所以單元素順序為 1、2、3。
core_knowledge:
  - 數值字典序 DFS
  - 以最早可用位置代表相同值
judgment: 與 Sequence One 的差別只在同長度排序鍵；仍需保證每條數值序列唯一。
hints:
  - 固定長度後，每層應按候選數值遞增，而非按原索引。
  - 對每個可選數值，只使用 start 之後最早出現的位置；較早位置保留最多後繼。
  - 遞迴仍要求下一位置更大、下一值不小於目前末值。
solution_outline: 每層收集 start 後可選值及其最早位置，以有序 map 依值遞增展開；逐長度輸出至 P。
proof_or_invariant: 最早位置支配同值較晚位置，任何可接在較晚位置後的序列也可接在較早位置後，故不漏互異值序列。map 次序使 DFS 葉按數值字典序，外層長度完成整體排序。
complexity:
  time: O(Pn log n)
  space: O(n)
common_errors:
  - 沿原索引直接 DFS，得到 Sequence One 順序
  - 同值使用多個位置而重複
  - 沒有維持原索引遞增
