  - 將每個姓名逐字走過一棵共享前綴的樹。

  - 查詢走不到或終點未登記是 WRONG；登記終點再用布林值區分 OK 與 REPEAT。
solution_outline: 建立 26 叉 Trie，終點標記 registered；查詢完整走訪後依 registered 與 called 狀態輸出並更新。
proof_or_invariant: Trie 中從根到節點的路徑字元唯一表示一個前綴，registered 恰標記名冊中的完整姓名；called 只在首次成功點名後設置，因此三種輸出互斥且完整。
common_errors: [把姓名前綴當完整姓名, WRONG 查詢時意外建立節點, REPEAT 後忘記保持已點名狀態]

  struct Node { array<int,26> next{}; bool registered=false; bool called=false; };
  int main(){ios::sync_with_stdio(false);cin.tie(nullptr);int n=0;cin>>n;vector<Node> trie(1);
      for(int i=0;i<n;++i){string s;cin>>s;int u=0;for(char c:s){size_t x=static_cast<size_t>(c-'a');if(trie[static_cast<size_t>(u)].next[x]==0){trie[static_cast<size_t>(u)].next[x]=static_cast<int>(trie.size());trie.push_back({});}u=trie[static_cast<size_t>(u)].next[x];}trie[static_cast<size_t>(u)].registered=true;}
      int m=0;cin>>m;while(m--){string s;cin>>s;int u=0;bool found=true;for(char c:s){int v=trie[static_cast<size_t>(u)].next[static_cast<size_t>(c-'a')];if(v==0){found=false;break;}u=v;}if(!found||!trie[static_cast<size_t>(u)].registered)cout<<"WRONG\n";else if(trie[static_cast<size_t>(u)].called)cout<<"REPEAT\n";else{cout<<"OK\n";trie[static_cast<size_t>(u)].called=true;}}
