statement: |-
  給定 n 個城市與 m 條可建道路，每條道路有代價。接著 q 次消息各把第 k 條道路的代價永久改為 d；每次修改後，輸出使所有城市連通的最小總代價。
constraints:
  - '1 <= n <= 20000，1 <= m,q <= 50000'
  - '1 <= x_i,y_i <= n，0 <= 邊權 <= 50000000'
input_format: '第一行 n,m,q；接著 m 行 u,v,w；再接 q 行 k,d。'
output_format: '共 q 行，第 i 行是套用前 i 次修改後的最小生成樹權重。'

    explanation: '依序改變指定邊權後，重新選取當下權重最小的生成樹。'
core_knowledge:
  - '某時間區間內被修改的邊視為動態邊，其餘為靜態邊。'
  - '把動態邊設成 -INF 後仍被 Kruskal 選到的靜態邊，在整段時間都必選，可收縮。'
  - '把動態邊設成 +INF 後仍未被選到的靜態邊，在整段時間都不會用到，可刪除。'
judgment: '單次重跑 Kruskal 為 O(qm log m)；時間分治可在共享修改區間中一次完成安全收縮與刪邊。'
hints:
  - '對時間區間 [L,R]，先標記這段期間可能改權的所有邊。'
  - '令這些動態邊極小；Kruskal 選到的靜態邊即使動態邊取最有利權重仍不可替代，因此可加入固定答案並縮點。'
  - '縮點後令動態邊極大；Kruskal 仍不選的靜態邊即使動態邊最不利也無需使用，因此可永久刪除，再遞迴兩半。'
solution_outline: |-
  對 q 個時間點遞迴分治。每層先以 -INF Kruskal 找出必選靜態邊，累加其真實權重並收縮端點；再以 +INF Kruskal，只保留被選靜態邊及所有動態邊。候選圖規模因這兩步受到控制。葉節點套用該次修改，對縮減後候選圖跑一次 Kruskal，加上沿途固定權重即得答案。
proof_or_invariant: |-
  在節點 [L,R] 入口，候選圖與 fixed 保留該區間每個時刻的 MST 權重。動態邊取 -INF 是其最有利情況；此時仍需選的靜態邊不可能被任何實際動態權重替代，故收縮安全。動態邊取 +INF 是其最不利情況；此時仍不入 MST 的靜態邊在任何實際情況皆不需要，故刪除安全。兩轉換保持入口不變量，葉節點 Kruskal 因而得到真實答案。
common_errors:
  - '分治右半前未讓左半修改永久生效。'
  - '把動態邊本身當成必選邊加入 fixed。'
  - '縮點後未刪除自環，或使用 int 累加 MST 權重。'
complexity:

  space: 'O((m+q) log q)（遞迴候選邊副本）'
