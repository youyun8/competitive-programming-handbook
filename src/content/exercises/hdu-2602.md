statement: >-
  收藏家面前有 n 塊骨頭，第 i 塊骨頭有價值 value_i 與體積 volume_i。背包最多容納
  capacity 單位體積，每塊骨頭至多選一次。求可放進背包的骨頭總價值最大值。

core_knowledge:
  - 0/1 背包以容量作狀態
  - 一維壓縮後容量必須遞減枚舉
judgment: 每塊骨頭只能選零次或一次；容量可以有剩餘，不要求恰好裝滿。
hints:
  - 先考慮只看過前 i 塊骨頭、容量上限為 c 時的最佳價值。
  - 新骨頭只有不選與選入兩種決策；選入時從容量 c-volume_i 的舊答案轉移。
  - 壓成一維後，讓 c 從 capacity 遞減到 volume_i，避免同一塊骨頭在本輪被重複使用。
solution_outline: >-
  令 dp[c] 是已處理骨頭中，體積不超過 c 的最大價值。初值全為零。逐塊處理骨頭，
  對容量由大到小更新 dp[c]=max(dp[c],dp[c-volume_i]+value_i)，最後輸出 dp[capacity]。
proof_or_invariant: >-
  處理完前 i 塊後，dp[c] 等於從這 i 塊中選取且總體積不超過 c 的最大價值。第 i 塊若不選，
  最佳值保留原 dp[c]；若選，移除它後是前 i-1 塊在容量 c-volume_i 的最佳解。兩者取大涵蓋
  且只涵蓋全部可行解。容量遞減使右側仍是前一階段值，所以不會重複選同一塊。歸納可得答案正確。
common_errors:
  - 容量遞增更新，意外把題目做成完全背包
  - 將價值列與體積列的順序讀反
  - 誤以為背包必須恰好裝滿
complexity:
  time: O(n * capacity) 每組測試
  space: O(capacity)

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <vector>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      int test_cases = 0;
      cin >> test_cases;
      while (test_cases-- > 0) {
          int n = 0;
          int capacity = 0;
          cin >> n >> capacity;
          vector<int> value(static_cast<size_t>(n));
          vector<int> volume(static_cast<size_t>(n));
          for (int& x : value) {
              cin >> x;
          }
          for (int& x : volume) {
              cin >> x;
          }

          vector<int> dp(static_cast<size_t>(capacity + 1), 0);
          for (int i = 0; i < n; ++i) {
              for (int c = capacity; c >= volume[static_cast<size_t>(i)]; --c) {
                  const int candidate =
                      dp[static_cast<size_t>(c - volume[static_cast<size_t>(i)])] +
                      value[static_cast<size_t>(i)];
                  dp[static_cast<size_t>(c)] = max(dp[static_cast<size_t>(c)], candidate);
              }
          }
          cout << dp[static_cast<size_t>(capacity)] << '\n';
      }
  }
