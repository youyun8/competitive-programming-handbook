judgment: 固定 g 後，dp[i] 需取座標落在一段區間內的最大前驅值；n 達五十萬，必須線性判定，再以 O(log x_n) 次判定二分最小 g。
hints:
  - 先忽略如何求最小值：固定 g 後，合法跳距離為 low=max(1,d-g)、high=d+g；判斷能否取得 k 分。
  - 定義 dp[i] 為到格子 i 的最大分數。其前驅 j 的座標需在 [x_i-high,x_i-low]，這個座標窗口隨 i 單調右移。
  - 用指標依序把 x_j<=x_i-low 的可達狀態加入遞減佇列，再移除 x_j<x_i-high 的隊首；隊首轉移出 dp[i]。可行性隨 g 不減，於 [0,max(x_n,d)] 二分。
solution_outline: 將起點作為座標 0、分數 0 的狀態。可行性函式以遞減單調佇列維護每個 i 的合法可達前驅最大 dp，任一 dp[i]>=k 即成功。先測足夠大的上界，不可行則輸出 -1；否則二分第一個可行 g。
proof_or_invariant: |-
  固定 g 時，處理 i 前，佇列恰含座標位於 [x_i-high,x_i-low] 的可達前驅中未被較晚且 dp 不小者支配的索引，dp 值遞減，所以隊首給出完整轉移最大值，判定正確。增加 g 只會擴張合法距離區間，不會使原路徑失效，因此可行性單調，二分所得第一個可行值即最小花費。
complexity:

  space: 'O(n)'

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n;
      long long d, target;
      if (!(cin >> n >> d >> target)) return 0;
      vector<long long> position(n + 1), score(n + 1);
      for (int i = 1; i <= n; ++i) cin >> position[i] >> score[i];
      const long long unreachable = numeric_limits<long long>::lowest() / 4;
      auto feasible = [&](long long cost) {
          const long long low = max(1LL, d - cost);
          const long long high = d + cost;
          vector<long long> dp(n + 1, unreachable);
          dp[0] = 0;
          deque<int> candidates;
          int incoming = 0;
          for (int i = 1; i <= n; ++i) {
              while (incoming < i &&
                     position[incoming] <= position[i] - low) {
                  if (dp[incoming] != unreachable) {
                      while (!candidates.empty() &&
                             dp[candidates.back()] <= dp[incoming]) {
                          candidates.pop_back();
                      }
                      candidates.push_back(incoming);
                  }
                  ++incoming;
              }
              while (!candidates.empty() &&
                     position[candidates.front()] < position[i] - high) {
                  candidates.pop_front();
              }
              if (!candidates.empty()) {
                  dp[i] = dp[candidates.front()] + score[i];
                  if (dp[i] >= target) return true;
              }
          }
          return false;
      };
      long long left = 0;
      long long right = max(position[n], d);
      if (!feasible(right)) {
          cout << -1 << '\n';
          return 0;
      }
      while (left < right) {
          const long long middle = left + (right - left) / 2;
          if (feasible(middle)) right = middle;
          else left = middle + 1;
      }
      cout << left << '\n';
      return 0;
  }
