statement: >-
  ACboy 有 n 門課與最多 m 天可讀書。對每門課 i，已知投入 j 天可得到的收益 profit[i][j]。
  同一天不能分給兩門課；每門課可投入零天。安排至多 m 天，使總收益最大。
constraints:
  - 輸入含多組資料，以 n = 0 且 m = 0 結束
  - 1 <= n <= 100
  - 1 <= m <= 100
  - 官方題面未另列收益值範圍
input_format: >-
  每組先給 n、m，接著 n 列各有 m 個整數；第 i 列第 j 個數是第 i 門課投入 j 天的收益。
output_format: 每組輸出一行最大總收益。
samples:
  - input: |-
      2 2
      1 2
      1 3
      0 0
    output: '3'
    explanation: 把兩天都投入第二門課可得收益 3，優於各投入一天所得的 2。
core_knowledge:
  - 每門課是一組互斥的投入方案
  - 分組背包的資源分配 DP
judgment: 可少於 m 天；將未用天數視為沒有收益即可，答案仍是容量上限 m 的最大值。
hints:
  - 處理一門課時，必須從投入 0、1、…、m 天的方案中恰選一個。
  - 令 dp[d] 表示已處理課程使用至多 d 天的最大收益，枚舉新課投入 k 天。
  - 每門課以一份 old_dp 轉移到 new_dp，避免在同一輪重複選取該課的多個方案。
solution_outline: >-
  初始 dp 全為零。對每門課複製舊陣列，對每個容量 d 枚舉投入天數 k=1..d，
  以 dp[d-k]+profit[i][k] 更新新值；投入零天對應保留 dp[d]。處理完輸出 dp[m]。
proof_or_invariant: >-
  處理前 i 門課後，dp[d] 是對這些課分配至多 d 天的最大收益。第 i 門課投入某個唯一的 k，
  移除它後其餘分配是前 i-1 門在 d-k 天內的可行解；枚舉 k=0..d 因而涵蓋全部方案。
  每個候選由合法舊狀態加該課的一個方案而成，亦必可行。歸納後 dp[m] 即全局最優值。
common_errors:
  - 原地轉移造成同一門課被選取多個投入方案
  - 忘記投入零天的方案，強迫每門課至少讀一天
  - 把矩陣的列與投入天數方向讀反
complexity:
  time: O(n * m^2)
  space: O(m)

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <vector>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n = 0;
      int days = 0;
      while (cin >> n >> days && (n != 0 || days != 0)) {
          vector<int> dp(static_cast<size_t>(days + 1), 0);
          for (int course = 0; course < n; ++course) {
              vector<int> profit(static_cast<size_t>(days + 1), 0);
              for (int used = 1; used <= days; ++used) {
                  cin >> profit[static_cast<size_t>(used)];
              }
              vector<int> next = dp;
              for (int capacity = 1; capacity <= days; ++capacity) {
                  for (int used = 1; used <= capacity; ++used) {
                      next[static_cast<size_t>(capacity)] =
                          max(next[static_cast<size_t>(capacity)],
                              dp[static_cast<size_t>(capacity - used)] +
                                  profit[static_cast<size_t>(used)]);
                  }
              }
              dp.swap(next);
          }
          cout << dp[static_cast<size_t>(days)] << '\n';
      }
  }
