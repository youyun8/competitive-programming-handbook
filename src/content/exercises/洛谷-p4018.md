statement: 一堆 n 顆石子，兩人輪流取 p^k 顆，其中 p 為質數、k 為自然數且不超過剩餘量；取走最後一顆者勝。October 先手，判斷勝者。
constraints: [1 <= test_cases <= 100000, 1 <= n <= 50000000]
input_format: 第一行 T，接著 T 行各一個 n。
output_format: 先手勝輸出 October wins!，否則輸出 Roy wins!。
samples:
  - input: |-
      2
      6
      7
    output: |-
      Roy wins!
      October wins!
    explanation: 六的倍數是必敗態；7 可取 1 留下 6。
core_knowledge: [必敗態閉包, 質數冪的模六性質]
judgment: k 是自然數，故 k=0 時 p^k=1 也是合法取法。
hints:
  - 先檢查 1 到 6 的勝敗，猜測所有六的倍數必敗。
  - 質數冪不可能含質因數 2 與 3，因此不可能是 6 的倍數。
  - 從非六倍數可取其模 6 的餘數；1、2、3、4、5 都是質數冪。
solution_outline: 每筆只判斷 n mod 6；為零輸出 Roy wins!，否則輸出 October wins!。
proof_or_invariant: 從 6 的倍數取任意合法質數冪後，不會仍是 6 的倍數。反之，任何 n=6q+r、1<=r<=5，可取 r（依序為 1、2、3、2²、5）回到 6q。由終止態 0 是必敗態歸納，六的倍數恰為必敗態。
common_errors: [誤認 k 必須為正而漏掉 1, 實際篩質數導致超時, 勝者輸出顛倒]
complexity: { time: 'O(T)', space: 'O(1)' }
cpp_skeleton: |
  #include <iostream>

cpp_solution: |
  #include <iostream>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int test_cases;
      cin >> test_cases;
      while (test_cases-- > 0) {
          int stones;
          cin >> stones;
          cout << (stones % 6 == 0 ? "Roy wins!\n" : "October wins!\n");
      }
      return 0;
  }
