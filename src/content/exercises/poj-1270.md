statement: >-
  給定一組以小寫字母表示的變數，以及若干形如 x < y 的先後限制。請列出所有同時滿足
  這些限制的變數排列；每個變數在排列中恰好出現一次。
constraints:
  - 每組資料有 2 到 20 個相異的小寫字母
  - 每組資料有 1 到 50 條先後限制
  - 每組資料保證存在 1 到 300 個合法排列
  - 總時間限制 1000 ms，記憶體限制 65536 kB
input_format: >-
  輸入包含多組資料直到 EOF。每組恰有兩行：第一行列出所有變數，第二行依序列出限制；
  第二行每相鄰兩個字母 x y 表示 x 必須排在 y 前面。
output_format: >-
  對每組資料逐行輸出所有合法排列，並按字典序排列。相鄰兩組資料的輸出之間留一個空行。

    explanation: >-
      第一組只有 a<b 與 b<f；每一步按字母順序嘗試目前入度為零的字母，得到四種排列。
      第二組的四條限制都指向 v，因此先列出其餘字母的合法交錯，再在條件允許時放入 v。
core_knowledge:
  - 拓撲排序中，尚未選取且目前入度為零的頂點都是下一個位置的候選
  - 回溯可枚舉所有拓撲序；按字母順序嘗試候選即可直接產生字典序輸出
  - 選取頂點時暫時刪除其出邊，返回上一層時必須完整恢復入度
judgment: 每組資料的每個合法拓撲序各輸出一次；順序與組間空行都屬於答案格式。
hints:
  - 把 x y 轉成有向邊 x→y，並計算每個出現字母的入度。
  - 建構答案的下一個位置時，只考慮尚未使用且目前入度為零的字母。
  - 依字母序選候選；遞迴前將其後繼入度減一，遞迴後恢復，長度等於變數數量時輸出。
solution_outline: >-
  將變數排序並以 0 到 k-1 編號，建立鄰接矩陣避免同一限制被重複計入。深度優先回溯時，
  由小到大掃描所有頂點；若頂點未使用且入度為零，就把它接到目前字串，將所有後繼入度
  減一後遞迴，再逐一加回。因為每層候選均按字母序嘗試，完整字串自然按字典序產生。
proof_or_invariant: >-
  每次進入遞迴時，current 恰由已選頂點構成，indegree[v] 恰等於尚未選頂點指向 v 的邊數。
  因此入度為零等價於把 v 接在 current 後不違反任何限制。每個合法排列的下一個字母在
  對應狀態必為零入度，故遞迴不會漏解；不同選擇序列產生不同排列，故不重複。回溯恢復
  所有入度與 used 狀態，維持不變量。候選依字母遞增探索，所以輸出也是字典序。
common_errors:
  - 把第二行每個字母都當成獨立限制，而不是每兩個字母組成一條邊
  - 回溯後忘記恢復後繼入度，導致後面的分支少列合法排列
  - 沒有忽略輸入中的空白行，造成兩行錯配
  - 每組輸出後都多印空行，導致最後一組格式不符
complexity:
  time: O(A * V * (V + E))，A 為合法排列數；這是包含所有回溯前綴的保守輸出敏感上界
  space: O(V + E)，不計輸出內容

cpp_solution: |
  #include <algorithm>
  #include <array>
  #include <iostream>
  #include <sstream>
  #include <string>
  #include <vector>
  using namespace std;

  static void enumerate_orders(const vector<char>& variables,
                               const vector<vector<int>>& graph,
                               vector<int>& indegree, vector<bool>& used,
                               string& current) {
      if (current.size() == variables.size()) {
          cout << current << '\n';
          return;
      }
      for (size_t vertex = 0; vertex < variables.size(); ++vertex) {
          if (used[vertex] || indegree[vertex] != 0) { continue; }
          used[vertex] = true;
          current.push_back(variables[vertex]);
          for (int next : graph[vertex]) { --indegree[static_cast<size_t>(next)]; }
          enumerate_orders(variables, graph, indegree, used, current);
          for (int next : graph[vertex]) { ++indegree[static_cast<size_t>(next)]; }
          current.pop_back();
          used[vertex] = false;
      }
  }

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      string variable_line;
      string constraint_line;
      bool first_case = true;
      while (getline(cin, variable_line)) {
          if (variable_line.empty()) { continue; }
          if (!getline(cin, constraint_line)) { break; }

          vector<char> variables;
          istringstream variable_stream(variable_line);
          char symbol = '\0';
          while (variable_stream >> symbol) { variables.push_back(symbol); }
          sort(variables.begin(), variables.end());

          array<int, 26> index{};
          index.fill(-1);
          for (size_t i = 0; i < variables.size(); ++i) {
              index[static_cast<size_t>(variables[i] - 'a')] = static_cast<int>(i);
          }
          vector<vector<int>> graph(variables.size());
          vector<vector<bool>> has_edge(
              variables.size(), vector<bool>(variables.size(), false));
          vector<int> indegree(variables.size(), 0);
          istringstream constraint_stream(constraint_line);
          char from_symbol = '\0';
          char to_symbol = '\0';
          while (constraint_stream >> from_symbol >> to_symbol) {
              const int from = index[static_cast<size_t>(from_symbol - 'a')];
              const int to = index[static_cast<size_t>(to_symbol - 'a')];
              if (!has_edge[static_cast<size_t>(from)][static_cast<size_t>(to)]) {
                  has_edge[static_cast<size_t>(from)][static_cast<size_t>(to)] = true;
                  graph[static_cast<size_t>(from)].push_back(to);
                  ++indegree[static_cast<size_t>(to)];
              }
          }

          if (!first_case) { cout << '\n'; }
          first_case = false;
          vector<bool> used(variables.size(), false);
          string current;
          enumerate_orders(variables, graph, indegree, used, current);
      }
  }
