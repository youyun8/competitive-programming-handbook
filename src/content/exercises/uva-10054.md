statement: >-
  每顆珠子兩端各有一種顏色。要把所有珠子恰使用一次串成封閉項鍊，相鄰珠子的接觸端顏色

core_knowledge: [珠子作無向邊且顏色作頂點, 歐拉迴路充要條件, Hierholzer 演算法]
judgment: 所有非零度顏色必須連通且度數為偶數；平行珠子不可去重。
hints:
  - 把顏色視為頂點，每顆珠子視為可反向使用的無向邊。
  - 封閉地使用每條邊一次要求所有非零度頂點連通且度數皆偶數。
  - Hierholzer 沿未用邊走到底，回溯時記錄邊，再反轉即可輸出。
solution_outline: 以 51×51 計數矩陣保存多重邊並統計度數；檢查偶度與 DFS 連通，再用遞迴 Hierholzer 消耗邊，反轉回溯邊序。
proof_or_invariant: >-
  項鍊進出每種顏色次數相等，所以度數必偶；一條項鍊也使所有有邊顏色連通。反之連通偶度
  無向多重圖存在歐拉迴路。Hierholzer 每次刪除一條真實珠子，回溯拼接的各閉合子巡迴涵蓋
  全部邊一次，反轉後相鄰端點相同。
common_errors: [將相同顏色對去重, 只檢查偶度未檢查連通, 從度數零的顏色開始, 忘記案例間空行]

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <queue>
  #include <utility>
  #include <vector>
  using namespace std;
  static void tour(int u,vector<vector<int>>& count,vector<pair<int,int>>& edges){for(int v=1;v<=50;++v)while(count[static_cast<size_t>(u)][static_cast<size_t>(v)]>0){--count[static_cast<size_t>(u)][static_cast<size_t>(v)];--count[static_cast<size_t>(v)][static_cast<size_t>(u)];tour(v,count,edges);edges.emplace_back(u,v);}}
  int main(){
      ios::sync_with_stdio(false);cin.tie(nullptr);int cases=0;cin>>cases;
      for(int test=1;test<=cases;++test){
          int n=0;cin>>n;vector<vector<int>> count(51,vector<int>(51,0));vector<int> degree(51,0);int start=0;
          for(int i=0;i<n;++i){int a=0,b=0;cin>>a>>b;if(start==0)start=a;++count[static_cast<size_t>(a)][static_cast<size_t>(b)];++count[static_cast<size_t>(b)][static_cast<size_t>(a)];++degree[static_cast<size_t>(a)];++degree[static_cast<size_t>(b)];}
          bool ok=true;for(int v=1;v<=50;++v)if(degree[static_cast<size_t>(v)]%2!=0)ok=false;
          vector<bool> seen(51,false);queue<int> ready;if(start!=0){ready.push(start);seen[static_cast<size_t>(start)]=true;}while(!ready.empty()){int u=ready.front();ready.pop();for(int v=1;v<=50;++v)if(count[static_cast<size_t>(u)][static_cast<size_t>(v)]>0&&!seen[static_cast<size_t>(v)]){seen[static_cast<size_t>(v)]=true;ready.push(v);}}
          for(int v=1;v<=50;++v)if(degree[static_cast<size_t>(v)]>0&&!seen[static_cast<size_t>(v)])ok=false;
          if(test>1){cout<<'\n';}
          cout<<"Case #"<<test<<'\n';
          if(!ok){cout<<"some beads may be lost\n";continue;}
          vector<pair<int,int>> edges;tour(start,count,edges);reverse(edges.begin(),edges.end());for(auto [a,b]:edges)cout<<a<<' '<<b<<'\n';
      }
  }
