statement: 有 n 種物品，第 i 種有 a_i 件同類物品。從中共取 m 件排成序列，求不同序列數。
constraints: [1 <= n <= 10, 1 <= m <= 10, 答案與中間運算不超過 2^31]
input_format: 多組直到 EOF；每組第一行 n、m，第二行 n 個數量 a_i。
output_format: 每組輸出一行排列數。

core_knowledge: [多重集合排列, 指數生成函數係數, 插入組合數]
judgment: 同種類物品不可區分，不同排列位置序列才算不同。
hints:
  - 第 i 種物品的 EGF 是 Σ_(k=0..a_i) x^k/k!。
  - 也可做整數 DP：已有 j 個物品的序列，加入 k 個相同新物品。
  - 新物品占 j+k 個位置中的 k 個，乘上 C(j+k,k)。
solution_outline: 預處理 0..10 組合數；逐種類轉移 next[j+k]+=dp[j]C(j+k,k)，其中 k 不超過該種數量。
proof_or_invariant: dp[j] 計數處理完目前種類後長度 j 的所有序列。加入 k 個新種類物品時，只需從 j+k 個位置選 k 個放新物品，其餘位置依序放原序列；此構造一一對應且不同 k 不交。故轉移完整、不重複。
common_errors: [把問題當成只選數量的普通生成函數, 忘記同類物品不可區分, 轉移時覆寫舊層]
complexity: { time: 'O(nm^2)', space: 'O(m)' }

cpp_solution: |
  #include <algorithm>
  #include <array>
  #include <iostream>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      array<array<long long, 11>, 11> choose{};
      for (int n = 0; n <= 10; ++n) {
          choose[static_cast<size_t>(n)][0] = choose[static_cast<size_t>(n)][static_cast<size_t>(n)] = 1;
          for (int k = 1; k < n; ++k)
              choose[static_cast<size_t>(n)][static_cast<size_t>(k)] =
                  choose[static_cast<size_t>(n - 1)][static_cast<size_t>(k - 1)] +
                  choose[static_cast<size_t>(n - 1)][static_cast<size_t>(k)];
      }
      int type_count, target;
      while (cin >> type_count >> target) {
          array<long long, 11> dp{};
          dp[0] = 1;
          for (int type = 0; type < type_count; ++type) {
              int quantity;
              cin >> quantity;
              array<long long, 11> next{};
              for (int used = 0; used <= target; ++used)
                  for (int take = 0; take <= min(quantity, target - used); ++take)
                      next[static_cast<size_t>(used + take)] +=
                          dp[static_cast<size_t>(used)] *
                          choose[static_cast<size_t>(used + take)][static_cast<size_t>(take)];
              dp = next;
          }
          cout << dp[static_cast<size_t>(target)] << '\n';
      }
      return 0;
  }
