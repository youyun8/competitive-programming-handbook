statement: 對每個小寫字串，求本質不同的非空迴文子字串數量。

    output: "Case #1: 5\nCase #2: 3"
    explanation: ababa 的不同迴文為 a、b、aba、bab、ababa；另以集合枚舉短字串全部子串對拍。
core_knowledge: [迴文樹節點, 最長迴文後綴, 本質不同計數]
judgment: 相同內容無論出現幾次只計一次；空字串不計。
hints:
  - 建立長度 -1 與 0 的兩個根，last 指向目前整個前綴的最長迴文後綴。
  - 加入字元時沿 fail 找到兩側字元相同的最長後綴，再走對應字元邊。
  - 若該邊不存在就新建一個迴文節點；每種不同迴文恰建立一次，因此答案是節點數減二。
solution_outline: 對每個測試重建迴文樹，逐字擴展；新邊時建立長度加二的節點並求其 fail。輸出除兩個虛根外的節點數。
proof_or_invariant: 每個節點唯一代表一個不同迴文，轉移 c 從迴文 p 代表 c+p+c。擴展時所有新出現迴文都是目前前綴的後綴，沿 fail 找到最長可擴展者即可建立唯一的新最長後綴；其餘較短者已存在，故節點數恰為不同迴文數。
common_errors: [兩個根的長度與 fail 初始化錯誤, 邊界比較前未放哨兵, 把出現次數加總而非新節點數]
