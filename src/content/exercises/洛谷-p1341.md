statement: >-
  給定 n 個互不相同的無序字母對，大小寫有別。構造長度 n+1 的字串，使每個輸入字母對
  恰好成為字串中某對相鄰字母；若有多解，輸出 ASCII 字典序最小者，無解則回報。
constraints: [每個字母為大寫或小寫英文字母, 無序字母對彼此不同, 字母對兩字可以相同, n 的上限由有限字母對數決定]
input_format: 第一行 n；接著 n 行各為兩個相鄰字母組成的字串。
output_format: 輸出字典序最小的合法字串；不存在時輸出 No Solution。
samples:
  - input: "4\naZ\ntZ\nXt\naX\n"
    output: 'XaZtX'
    explanation: 四條無向邊形成歐拉迴路；從 ASCII 最小的 X 開始並優先走較小鄰點得到 XaZtX。
core_knowledge: [字母作頂點且字母對作無向邊, 無向歐拉跡條件, 按 ASCII 掃描鄰點]
judgment: 大寫字母 ASCII 小於小寫字母；自環字母對會為該點增加兩度。
hints:
  - 要使用每個字母對一次，等價於找使用每條無向邊一次的歐拉跡。
  - 必須所有有邊頂點連通，且奇度點數為 0 或 2；兩奇點時從較小奇點開始。
  - Hierholzer 每次按 ASCII 由小到大取邊，回溯記點並反轉，可得最小合法字串。
solution_outline: >-
  用 128×128 計數矩陣保存邊並統計度數，以 DSU 檢查非零度字母連通。選最小奇度字母，
  若無奇點則選最小非零度字母；遞迴 Hierholzer 按 ASCII 消耗邊，反轉回溯頂點序列。
proof_or_invariant: >-
  相鄰字母對與無向邊一一對應，因此合法字串正是歐拉跡的頂點序列。連通且奇點為 0 或 2
  是無向歐拉跡充要條件。起點取最小必要端點，且每次優先最小可走邊；Hierholzer 的回溯
  拼接不遺漏邊，標準首次分歧交換論證保證最終頂點序列字典序最小。
common_errors: [以字母表順序而非 ASCII 排序大小寫, 自環只增加一次度數, 未檢查不同連通分量, 直接輸出回溯序而忘記反轉]

  #include <algorithm>
  #include <iostream>
  #include <string>
  #include <vector>
  using namespace std;
  struct Dsu{vector<int> p;Dsu():p(128){for(int i=0;i<128;++i)p[static_cast<size_t>(i)]=i;}int find(int x){return p[static_cast<size_t>(x)]==x?x:p[static_cast<size_t>(x)]=find(p[static_cast<size_t>(x)]);}void unite(int a,int b){p[static_cast<size_t>(find(a))]=find(b);}};
  static void tour(int u,vector<vector<int>>& edge,vector<int>& reversed){for(int v=0;v<128;++v)while(edge[static_cast<size_t>(u)][static_cast<size_t>(v)]>0){--edge[static_cast<size_t>(u)][static_cast<size_t>(v)];--edge[static_cast<size_t>(v)][static_cast<size_t>(u)];tour(v,edge,reversed);}reversed.push_back(u);}
  int main(){
      ios::sync_with_stdio(false);cin.tie(nullptr);int n=0;cin>>n;vector<vector<int>> edge(128,vector<int>(128,0));vector<int> degree(128,0);Dsu dsu;
      for(int i=0;i<n;++i){string pair;cin>>pair;int a=static_cast<unsigned char>(pair[0]),b=static_cast<unsigned char>(pair[1]);++edge[static_cast<size_t>(a)][static_cast<size_t>(b)];++edge[static_cast<size_t>(b)][static_cast<size_t>(a)];++degree[static_cast<size_t>(a)];++degree[static_cast<size_t>(b)];dsu.unite(a,b);}
      int odd=0,min_odd=-1,min_nonzero=-1,root=-1;bool ok=true;for(int v=0;v<128;++v)if(degree[static_cast<size_t>(v)]>0){if(min_nonzero==-1)min_nonzero=v;if(root==-1)root=dsu.find(v);else if(root!=dsu.find(v))ok=false;if(degree[static_cast<size_t>(v)]%2!=0){++odd;if(min_odd==-1)min_odd=v;}}
      if(odd!=0&&odd!=2){ok=false;}
      if(!ok){cout<<"No Solution\n";return 0;}
      int start=odd==2?min_odd:min_nonzero;
      vector<int> reversed;tour(start,edge,reversed);reverse(reversed.begin(),reversed.end());for(int value:reversed)cout<<static_cast<char>(value);cout<<'\n';
  }
