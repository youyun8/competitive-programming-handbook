  - 總瓷磚數 N=n(n+1)/2，恆等置換有 N 個循環。

solution_outline: 計算三類循環數，以位移生成 2 的冪，按 Burnside 公式相加除六。
proof_or_invariant: 固定二色染色必須在置換每個循環內同色，故有 2^c 種。120 度旋轉除可能的中心固定塊外皆為三循環，循環數 ceil(N/3)；反射軸上的 ceil(n/2) 塊單獨成環，其餘兩兩成環。Burnside 對六個群元素平均即得公式。
common_errors: [只計旋轉不計反射, 反射循環數忘記軸上固定塊, 用 64 位元儲存答案]

cpp_solution: |
  #include <boost/multiprecision/cpp_int.hpp>
  #include <iostream>
  using boost::multiprecision::cpp_int;
  using namespace std;
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n;
      cin >> n;
      const int tile_count = n * (n + 1) / 2;
      const int rotation_cycles = (tile_count + 2) / 3;
      const int fixed_on_axis = (n + 1) / 2;
      const int reflection_cycles = (tile_count + fixed_on_axis) / 2;
      const cpp_int answer =
          ((cpp_int(1) << tile_count) +
           2 * (cpp_int(1) << rotation_cycles) +
           3 * (cpp_int(1) << reflection_cycles)) /
          6;
      cout << answer << '\n';
      return 0;
  }
