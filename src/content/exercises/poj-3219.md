statement: 給定 n 與 k，不必算出巨大的組合數 C(n,k)，只需判斷它除以 2 的餘數。
constraints:
  - 0 <= k <= n < 2^31
  - n > 0
  - 輸入含多組資料，讀到 EOF 為止
  - 時間限制 1000 ms，記憶體限制 131072 kB
input_format: 每行兩個整數 n、k；輸入以 EOF 結束。
output_format: 每組輸出一行 0 或 1，表示 C(n,k) mod 2。
samples:
  - input: |
      1 1
      1 0
      2 1
    output: |
      1
      1
      0
    explanation: 前兩個組合數皆為 1；C(2,1)=2，所以第三組為偶數。
core_knowledge:
  - Lucas 定理在模數 2 時可逐二進位判斷
  - C(n,k) 為奇數恰若 k 的每個 1 位元也都是 n 的 1 位元
judgment: 每組資料只輸出組合數的奇偶位，不得輸出組合數本身。
hints:
  - 先觀察模 2 時，小組合數只有 C(0,0)、C(1,0)、C(1,1) 為 1。
  - 把 n、k 寫成二進位，Lucas 定理會把答案拆成每一位的小組合數乘積。
  - 乘積為 1 的條件是不存在 k_i=1 且 n_i=0；位元式可寫成 (k & ~n)==0。
solution_outline: 逐組讀入無號整數 n、k；若 k 含有任何 n 沒有的 1 位元便輸出 0，否則輸出 1。
proof_or_invariant: >-
  由 Lucas 定理，C(n,k) mod 2 等於所有二進位位上的 C(n_i,k_i) 乘積。
  唯一為 0 的合法小情形是 n_i=0、k_i=1。因此答案為奇數恰若 k 的 1 位元集合
  是 n 的 1 位元集合之子集，這正是 (k & ~n)==0。
common_errors:
  - 用階乘直接計算而溢位
  - 把判斷式誤寫成 (n & k)==0
  - 只讀一組資料，忽略輸入直到 EOF
complexity:
  time: 每組 O(1)
  space: O(1)

cpp_solution: |
  #include <cstdint>
  #include <iostream>
  using namespace std;

  static bool is_odd(uint32_t n, uint32_t k) {
      return (k & ~n) == 0U;
  }

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      uint32_t n, k;
      while (cin >> n >> k) {
          cout << (is_odd(n, k) ? 1 : 0) << '\n';
      }
      return 0;
  }
