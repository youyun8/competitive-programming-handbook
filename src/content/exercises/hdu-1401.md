statement: 8×8 棋盤放四枚相同棋子。一步可把一枚棋移到上下左右相鄰空格；若相鄰格有棋，則可跳過它到同方向再下一個空格。判斷能否在至多八步內由起始配置變成目標配置。
constraints: [棋盤固定 8×8, 每個配置恰有四枚棋, 可連續讀到 EOF]
input_format: 每組兩行，每行八個整數，依序為四枚棋子的列、行座標（皆為 1..8）。
output_format: 每組可在八步內到達輸出 YES，否則輸出 NO。

    explanation: 兩配置間存在不超過八次的合法移動序列。
core_knowledge: [64 位棋盤遮罩, 無標號棋子正規化, 雙向 BFS]
judgment: 跳躍只跨越恰好一枚相鄰棋，落點必須在棋盤內且為空；四枚棋相同，狀態不含棋子編號。
hints:
  - 用 64 位整數的四個 1 表示配置，天然消除棋子排列差異。
  - 從起點與終點各展開至深度四；兩側狀態集合相交即存在至多八步路徑。
  - 對每枚棋與四方向，先看相鄰格；被占時把落點再沿同方向推一格，最後檢查界內且未占。
solution_outline: 分別以 BFS 建立起始與目標四步內可達集合，生成所有合法移動後檢查兩集合是否相交。
proof_or_invariant: 每條狀態邊恰對應一次合法移動，且移動可逆。任一長度不超過八的路徑可在中點分成兩段，各不超過四步，故兩側集合必相交；反之交點串接兩段可逆路徑即得合法的至多八步方案。
complexity: { time: 'O(S)', space: 'O(S)' }

  #include <bits/stdc++.h>
  using namespace std;
  using U=uint64_t;
  vector<U> next_states(U state){vector<U> result;constexpr int dr[4]={-1,1,0,0},dc[4]={0,0,-1,1};for(int p=0;p<64;++p)if((state>>p)&1ULL){int r=p/8,c=p%8;for(int d=0;d<4;++d){int nr=r+dr[d],nc=c+dc[d];if(nr<0||nr>=8||nc<0||nc>=8)continue;int to=nr*8+nc;if((state>>to)&1ULL){nr+=dr[d];nc+=dc[d];if(nr<0||nr>=8||nc<0||nc>=8)continue;to=nr*8+nc;}if((state>>to)&1ULL)continue;result.push_back((state^(1ULL<<p))|(1ULL<<to));}}return result;}
  unordered_set<U> reach(U start){unordered_set<U> seen{start};queue<pair<U,int>> pending;pending.push({start,0});while(!pending.empty()){auto [state,depth]=pending.front();pending.pop();if(depth==4)continue;for(U next:next_states(state))if(seen.insert(next).second)pending.push({next,depth+1});}return seen;}
