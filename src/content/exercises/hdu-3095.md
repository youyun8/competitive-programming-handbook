core_knowledge:
  - 12! / 2 ≈ 2.4 億個可達盤面，單向 BFS 走不完，需要從兩端各走一半
  - 盤面可用排列的字典序名次（Lehmer code）壓成單一整數當作雜湊鍵

judgment: >-
  起點與終點都是單一盤面、每步成本相同、轉移可逆，而且狀態數大到單向 BFS 撐不住——
  這正是雙向廣搜的標準題型。先用奇偶性擋掉無解的測資，再從兩端同時展開。
hints:
  - >-
    先估狀態數：12 格的排列有 12! ≈ 4.79 億種，其中只有一半可達。單向 BFS 要展開到
    十幾層就已經吃光記憶體，代表要從「深度減半」下手。
  - >-
    把盤面轉成一個整數再放進雜湊表，才有辦法判重。常用做法是算排列的字典序名次：
    對每個位置數出後面有幾個比它小的元素，逐位乘上階乘基底。

    在展開之前先做奇偶性檢查：一次移動會把空格移到相鄰格，同時交換一對元素，
    逆序數的奇偶性與空格列號的奇偶性會同時翻轉，所以「逆序數 + 空格列號」的奇偶性
    是不變量。起始與目標的這個值不同就直接輸出 -1。
  - >-
    兩側各自維護「盤面 → 距離」的雜湊表，每次挑元素較少的那一側展開一整層；
    產生新盤面時查另一側的表，有就記下 df + db。整層展開完才回報這層的最小值，
    否則可能拿到非最短的相遇點。
solution_outline: >-
  先比對起始與目標的「逆序數 + 空格列號」奇偶性，不同就輸出 -1。相同則做雙向 BFS：
  正向從起始盤面、反向從目標盤面出發，各自用 unordered_map 記錄盤面名次到距離的對應，
  每輪挑較小的 frontier 展開一整層，展開時檢查對側是否已經到過該盤面；整層做完後若有
  相遇，回報這層算出的最小 df + db。
proof_or_invariant: >-
  一次移動是把空格與相鄰滑塊交換，這相當於對排列做一次對換，逆序數奇偶性必定翻轉；
  同時空格只在上下移動時改變列號，左右移動時逆序數的翻轉來自同列相鄰交換。合起來看，
  「逆序數 + 空格列號」的奇偶性在每一步都保持不變，因此奇偶性不同時目標不可達。
  奇偶性相同時，兩個盤面必定互相可達（3×4 滑塊拼圖的可達類恰為兩個奇偶類）。
  雙向 BFS 的正確性同一般情形：轉移可逆使正反兩側走同一張無向圖；若最短路長度為 L，
  把它切成 df + db = L，中點必同時被兩側標記，因此在兩側深度和達到 L 的那一層必定相遇。
  由於整層展開完才回報，回報的必是最小值。
common_errors:
  - 直接用字串或 vector 當雜湊鍵，記憶體與比較成本都被放大
  - 忘了先做奇偶性判斷，讓無解測資把搜尋跑到爆記憶體
  - 一相遇就回傳而沒把該層展開完，得到非最短的答案
  - 把盤面誤當成 4 列 3 行，導致空格的相鄰關係與奇偶性判斷全錯
  - 跨測資沒有清空兩側的雜湊表
complexity:

  space: O(b^(L/2))，兩側雜湊表各存一半深度的盤面

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  // 3 列 4 行、11 個滑塊加一個空格；0 代表空格。
  static const int rows = 3;
  static const int columns = 4;
  static const int cells = rows * columns;
  static const int step_limit = 40;

  // 排列的字典序名次（Lehmer code），把盤面壓成單一整數當雜湊鍵。
  static uint32_t rank_of(const array<int, cells>& board) {
      uint32_t code = 0;
      for (int index = 0; index < cells; ++index) {
          int smaller = 0;
          for (int other = index + 1; other < cells; ++other) {
              if (board[static_cast<size_t>(other)] < board[static_cast<size_t>(index)]) ++smaller;
          }
          code = code * static_cast<uint32_t>(cells - index) + static_cast<uint32_t>(smaller);
      }
      return code;
  }

  // 「逆序數 + 空格列號」的奇偶性，每走一步都不會改變。
  static int parity_of(const array<int, cells>& board) {
      int inversions = 0;
      for (int index = 0; index < cells; ++index) {
          if (board[static_cast<size_t>(index)] == 0) continue;
          for (int other = index + 1; other < cells; ++other) {
              if (board[static_cast<size_t>(other)] == 0) continue;
              if (board[static_cast<size_t>(other)] < board[static_cast<size_t>(index)]) ++inversions;
          }
      }
      int blank_row = 0;
      for (int index = 0; index < cells; ++index) {
          if (board[static_cast<size_t>(index)] == 0) blank_row = index / columns;
      }
      return (inversions + blank_row) & 1;
  }

  static void expand(const array<int, cells>& board, vector<array<int, cells>>& out) {
      int blank = 0;
      for (int index = 0; index < cells; ++index) {
          if (board[static_cast<size_t>(index)] == 0) blank = index;
      }
      int blank_row = blank / columns;
      int blank_column = blank % columns;
      const int row_step[4] = {-1, 1, 0, 0};
      const int column_step[4] = {0, 0, -1, 1};
      out.clear();
      for (int direction = 0; direction < 4; ++direction) {
          int row = blank_row + row_step[direction];
          int column = blank_column + column_step[direction];
          if (row < 0 || row >= rows || column < 0 || column >= columns) continue;
          array<int, cells> next = board;
          swap(next[static_cast<size_t>(blank)], next[static_cast<size_t>(row * columns + column)]);
          out.push_back(next);
      }
  }

  static int bidirectional(const array<int, cells>& start, const array<int, cells>& goal) {
      if (start == goal) return 0;
      if (parity_of(start) != parity_of(goal)) return -1;
      unordered_map<uint32_t, int> forward_seen;
      unordered_map<uint32_t, int> backward_seen;
      forward_seen[rank_of(start)] = 0;
      backward_seen[rank_of(goal)] = 0;
      vector<array<int, cells>> forward_frontier{start};
      vector<array<int, cells>> backward_frontier{goal};
      int forward_depth = 0;
      int backward_depth = 0;
      vector<array<int, cells>> moves;
      while (forward_depth + backward_depth < step_limit) {
          bool go_forward = forward_frontier.size() <= backward_frontier.size();
          auto& frontier = go_forward ? forward_frontier : backward_frontier;
          auto& own = go_forward ? forward_seen : backward_seen;
          auto& other = go_forward ? backward_seen : forward_seen;
          int depth = go_forward ? ++forward_depth : ++backward_depth;
          vector<array<int, cells>> next_frontier;
          int best = INT_MAX;
          for (const auto& board : frontier) {
              expand(board, moves);
              for (const auto& next : moves) {
                  uint32_t code = rank_of(next);
                  if (own.count(code)) continue;
                  own[code] = depth;
                  auto found = other.find(code);
                  if (found != other.end()) best = min(best, depth + found->second);
                  next_frontier.push_back(next);
              }
          }
          frontier.swap(next_frontier);
          if (best != INT_MAX) return best;
          if (frontier.empty()) return -1;
      }
      return -1;
  }

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      array<int, cells> start{};
      array<int, cells> goal{};
      while (true) {
          for (int index = 0; index < cells; ++index) {
              if (!(cin >> start[static_cast<size_t>(index)])) return 0;
          }
          for (int index = 0; index < cells; ++index) {
              cin >> goal[static_cast<size_t>(index)];
          }
          cout << bidirectional(start, goal) << '\n';
      }
  }

## 待核實項目

這一頁的題面是重建的，可信度低於本站其他題卡，請務必先核對再使用。

- **題目身分**：先前查證時，公開搜尋結果會把 HDU 3095 錯配到 CodeVS 3095「黑心的市長」
  與 HDU 2955「Robberies」，兩者都不是本題。本頁沒有取得 HDU 原題頁或正式賽事 PDF。
- **盤面形狀**：本頁採用「eleven puzzle = 3 列 4 行、11 個滑塊」的通用定義——與八數碼
  （3×3、8 塊）、十五數碼（4×4、15 塊）同一系列，狀態數 12!/2 也正好符合本節把它歸在
  雙向廣搜的理由。但這是推得的，不是從原題讀到的。若實際盤面不同（例如十字形），
  只需改 `rows`、`columns` 與 `expand` 的相鄰關係，搜尋與奇偶性以外的部分都能沿用。
- **輸入輸出格式**：假設每筆測資給起始與目標兩個盤面、讀到 EOF 結束、無解輸出 -1。
  原題也可能固定目標盤面、用 `X` 表示空格，或以測資組數開頭。
- **樣例**：本頁樣例是自製的回歸測資，經與單向 BFS 對拍確認，但不是原題官方樣例。
