statement: >-
  給一棵帶正權樹，對每個節點輸出它到所有其他節點的最遠距離。
constraints:
  - 1 <= n <= 10000

  - 輸入可含多組資料直到 EOF

core_knowledge: ['換根 DP', '最長與次長向下鏈']
judgment: 每個節點的最遠路徑不是走入某個兒子，就是先走向父親；需把父側資訊傳回。
hints:
  - 第一次 DFS 記錄每點向子樹走的最長 down1、次長 down2，以及最長鏈來自哪個兒子。
  - 傳給兒子 v 時，父親可用的向下鏈若來自 v，就改用 down2，避免折返同一子樹。
  - up[v]=w(u,v)+max(up[u], best_excluding_v[u])，答案為 max(down1[u],up[u])。
solution_outline: >-
  建無向樹。第一遍後序求兩條最大向下距離；第二遍前序依最長鏈來源選擇排除兒子的替代值，計算每個兒子的向上距離。
proof_or_invariant: >-
  從 u 出發的簡單路徑第一條邊要麼進某個兒子子樹，要麼走向父親，兩類互斥且涵蓋全部。down1 是前者最大值，up 是後者最大值。傳給 v 時，父側路徑只能使用 u 的 up 或其他兒子，排除 v 後的最大值恰為公式。
common_errors: ['傳 up 時使用來自同一兒子的 down1 造成折返', '只有一個兒子時次長值未設為零', '未處理多組 EOF 輸入']

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <utility>
  #include <vector>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n;
      while (cin >> n) {
          vector<vector<pair<int,int>>> graph(static_cast<size_t>(n + 1));
          for (int v = 2; v <= n; ++v) {
              int parent, weight; cin >> parent >> weight;
              graph[parent].push_back({v, weight});
              graph[v].push_back({parent, weight});
          }
          vector<long long> first(static_cast<size_t>(n + 1));
          vector<long long> second(static_cast<size_t>(n + 1));
          vector<long long> upward(static_cast<size_t>(n + 1));
          vector<int> source(static_cast<size_t>(n + 1), -1);
          auto down_dfs = [&](auto&& self, int u, int parent) -> void {
              for (auto [v, weight] : graph[u]) if (v != parent) {
                  self(self, v, u);
                  const long long value = first[v] + weight;
                  if (value > first[u]) {
                      second[u] = first[u]; first[u] = value; source[u] = v;
                  } else if (value > second[u]) second[u] = value;
              }
          };
          auto up_dfs = [&](auto&& self, int u, int parent) -> void {
              for (auto [v, weight] : graph[u]) if (v != parent) {
                  const long long other = source[u] == v ? second[u] : first[u];
                  upward[v] = max(upward[u], other) + weight;
                  self(self, v, u);
              }
          };
          down_dfs(down_dfs, 1, 0);
          up_dfs(up_dfs, 1, 0);
          for (int u = 1; u <= n; ++u) cout << max(first[u], upward[u]) << '\n';
      }
  }
