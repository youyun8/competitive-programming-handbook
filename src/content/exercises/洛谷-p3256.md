statement: n 輛賽車在無限長直線上，車 i 的初始位置為 k_i，之後以固定速度 v_i 行駛。若某輛車曾在任意 t>=0 時位於領跑位置（允許與其他車並列），它就獲獎。求所有獲獎車編號。
constraints:
  - '1 <= n <= 10000'
  - '0 <= k_i <= 1000000000'
  - '0 <= v_i <= 1000000000'
input_format: 第一行為賽車數 n；第二行依序給 n 個初始位置 k_i；第三行依序給 n 個速度 v_i。
output_format: 第一行輸出獲獎車數；第二行按編號遞增輸出獲獎車編號，編號間以一個空白分隔且行末不加多餘空白。
samples:
  - input: |
      4
      0 1 2 3
      4 3 2 1
    output: |
      4
      1 2 3 4
    explanation: 本站自製交會範例。四條位置函數都在 t=1 時等於 4；即使其中部分車只在這一瞬間並列領先，也符合「曾經沒有車在前方」，所以四輛皆獲獎。
core_knowledge:
  - 每輛車對應 t>=0 上的一次函數
  - 領跑車是所有直線的上包絡
  - 並列瞬間要求保留零長度包絡段
judgment: 位置是 k_i+v_i t。按速度排序後，上包絡上的斜率單調增加，可用棧維護每條線開始領先的交點時間；只在新交點嚴格早於上一開始時間時彈棧，才能保留僅在單點並列領先的車。
hints:
  - 把車 i 寫成直線 position_i(t)=k_i+v_i t；獲獎車就是 t>=0 的上包絡成員。
  - 相同速度只可能保留初始位置最大的直線；若 k、v 都相同，這些車全程重合，應把它們的編號一起保留。
  - 速度遞增加入直線，與棧頂交點若嚴格早於棧頂開始領先時間才彈出；建完後，一條線的結束時間是下一條的開始時間，只要結束時間 >=0 就曾在允許時間領先。
solution_outline: 依速度分組，每組只留下最大初始位置及其所有重合編號。用單調棧建立上包絡並以分數保存開始時間；保留所有包絡結束時間非負的線組，彙整編號排序輸出。
proof_or_invariant: 棧中斜率嚴格遞增，開始時間非遞減，且每條線在自己的開始到下一開始之間等於上包絡。新線與棧頂交點若早於棧頂開始時間，棧頂沒有任何領先時刻，安全彈出；相等時棧頂在該瞬間並列領先，必須保留。歸納得到完整上包絡。限制 t>=0 後，非末線有可行領先時刻當且僅當下一開始時間 >=0，末線則終將領先。
complexity:
  time: O(n log n)
  space: O(n)
common_errors:
  - 忽略 t>=0，把只在負時間領先的車算入
  - 相同速度時保留初始位置較小的車
  - 三線同點相交時用 <= 彈棧，漏掉只在單一時刻並列領先的車
  - 用浮點交點比較導致接近共點時順序錯誤

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  struct Car {
      long long intercept;
      long long slope;
      int id;
  };

  struct LineGroup {
      long long intercept;
      long long slope;
      vector<int> ids;
  };

  struct Fraction {
      long long numerator;
      long long denominator;
  };

  struct HullEntry {
      LineGroup line;
      Fraction start;
  };

  static bool fraction_less(const Fraction& a, const Fraction& b) {
      return a.numerator * b.denominator < b.numerator * a.denominator;
  }

  static Fraction intersection_time(const LineGroup& slower,
                                    const LineGroup& faster) {
      return {slower.intercept - faster.intercept,
              faster.slope - slower.slope};
  }

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n;
      cin >> n;
      vector<long long> initial(static_cast<size_t>(n));
      for (long long& value : initial) { cin >> value; }
      vector<Car> cars(static_cast<size_t>(n));
      for (int i = 0; i < n; ++i) {
          long long speed;
          cin >> speed;
          cars[static_cast<size_t>(i)] =
              {initial[static_cast<size_t>(i)], speed, i + 1};
      }
      sort(cars.begin(), cars.end(), [](const Car& a, const Car& b) {
          if (a.slope != b.slope) { return a.slope < b.slope; }
          if (a.intercept != b.intercept) {
              return a.intercept > b.intercept;
          }
          return a.id < b.id;
      });

      vector<LineGroup> groups;
      for (size_t i = 0; i < cars.size();) {
          size_t end = i;
          while (end < cars.size() && cars[end].slope == cars[i].slope) {
              ++end;
          }
          LineGroup group{cars[i].intercept, cars[i].slope, {}};
          for (size_t j = i; j < end &&
                             cars[j].intercept == cars[i].intercept;
               ++j) {
              group.ids.push_back(cars[j].id);
          }
          groups.push_back(move(group));
          i = end;
      }

      vector<HullEntry> hull;
      for (LineGroup& line : groups) {
          while (hull.size() >= 2) {
              const Fraction crossing =
                  intersection_time(hull.back().line, line);
              if (!fraction_less(crossing, hull.back().start)) { break; }
              hull.pop_back();
          }
          const Fraction start =
              hull.empty()
                  ? Fraction{numeric_limits<long long>::min(), 1}
                  : intersection_time(hull.back().line, line);
          hull.push_back({move(line), start});
      }

      vector<int> winners;
      for (size_t i = 0; i < hull.size(); ++i) {
          const bool reaches_nonnegative_time =
              i + 1 == hull.size() || hull[i + 1].start.numerator >= 0;
          if (reaches_nonnegative_time) {
              winners.insert(winners.end(), hull[i].line.ids.begin(),
                             hull[i].line.ids.end());
          }
      }
      sort(winners.begin(), winners.end());
      cout << winners.size() << '\n';
      for (size_t i = 0; i < winners.size(); ++i) {
          if (i != 0) { cout << ' '; }
          cout << winners[i];
      }
      cout << '\n';
  }
