statement: 統計閉區間 [L,R] 中的 11 位手機號碼：必須出現至少三個連續相同數字，且不能同時含數字 4 與 8。

core_knowledge: [數位 DP, 連續段狀態, 禁止特徵組合]
judgment: 號碼恰為 11 位且首位不為零；三連號可以更長，但 4 與 8 不可同時出現。
hints:
  - 以 count(x) 統計不超過 x 的合法 11 位號碼，再作前綴差。
  - 狀態保存上一位、目前連續長度（封頂 3）、是否已有三連號、是否見過 4 與 8。
  - 一旦 seen4 與 seen8 同時為真便剪枝；第一位從 1 開始枚舉。
solution_outline: 對 11 個數位做記憶化 DFS，非 tight 狀態快取，終點檢查三連號與禁忌數字條件。
proof_or_invariant: >-
  狀態完整記錄後續合法性所需資訊：上一位及連續長度決定加入新位是否形成三連號，兩個 seen
  位元決定是否同時含 4、8。每個不超過上界的 11 位號碼對應唯一枚舉路徑，非法組合立即排除，
  終點只接受已有三連號者，因此 count(x) 無重無漏；前綴相減得到區間答案。
common_errors: [允許首位為零, 只判斷恰好三連而漏掉更長連號, 沒有排除同時出現 4 與 8]

cpp_solution: |
  #include <algorithm>
  #include <array>
  #include <cstring>
  #include <functional>
  #include <iostream>
  #include <string>
  using namespace std;
  static long long count_to(long long x) {
      if (x < 10000000000LL) return 0;
      const string digits = to_string(x);
      long long memo[11][11][4][2][2][2];
      memset(memo, -1, sizeof(memo));
      function<long long(int, int, int, bool, bool, bool, bool)> dfs =
          [&](int position, int previous, int run, bool triple, bool seen4, bool seen8,
              bool tight) -> long long {
          if (seen4 && seen8) return 0;
          if (position == 11) return triple ? 1 : 0;
          long long& cached = memo[position][previous][run][triple ? 1 : 0]
                                   [seen4 ? 1 : 0][seen8 ? 1 : 0];
          if (!tight && cached != -1) return cached;
          const int limit = tight ? digits[static_cast<size_t>(position)] - '0' : 9;
          const int first = position == 0 ? 1 : 0;
          long long ways = 0;
          for (int digit = first; digit <= limit; ++digit) {
              const int next_run = digit == previous ? min(3, run + 1) : 1;
              ways += dfs(position + 1, digit, next_run, triple || next_run >= 3,
                          seen4 || digit == 4, seen8 || digit == 8,
                          tight && digit == limit);
          }
          if (!tight) cached = ways;
          return ways;
      };
      return dfs(0, 10, 0, false, false, false, true);
  }
  int main() {
      ios::sync_with_stdio(false); cin.tie(nullptr);
      long long left = 0, right = 0; cin >> left >> right;
      cout << count_to(right) - count_to(left - 1) << '\n';
  }
