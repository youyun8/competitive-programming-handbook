statement: >-
  禮物與每個盒子都有 d 個邊長。若可重新排列內盒的維度，使其每一維都嚴格小於外盒對應維度，

input_format: 每組第一行 N d；下一行為禮物的 d 個邊長；再接 N 行，每行是一個盒子的 d 個邊長。輸入到 EOF。
output_format: 輸出最多可使用的盒子數；若沒有任何盒子能裝下禮物，輸出 Please look for another gift shop!

core_knowledge: [排序後的逐維嚴格支配, 偏序 DAG, 最長鏈 DP]
judgment: 兩個 d 維盒子可經排列後巢狀，若且唯若各自升序排序後，內盒每個位置都嚴格小於外盒。
hints:
  - 先把禮物與每個盒子的 d 個邊長各自升序排序，旋轉／排列條件便化成逐位置比較。
  - 再將所有盒子的排序向量按字典序排序；能放入的方向只可能由較前向較後，不會形成環。
  - 令 dp[i] 為以盒 i 當最外層的最大盒數；禮物能放入 i 時先設為 1，再由所有可放入 i 的 j 轉移。
solution_outline: >-
  對禮物與每個盒子的維度排序，再把盒子向量按字典序排序。逐盒計算最長鏈：
  若禮物逐維嚴格小於盒 i，令 dp[i]=1；對每個 j<i，若 dp[j]>0 且盒 j 逐維嚴格小於 i，
  更新 dp[i]=max(dp[i],dp[j]+1)。所有 dp 的最大值即答案。
proof_or_invariant: >-
  必要性可由排序後第 k 小元素證明：若存在完美配對使每個內邊小於其外邊，而第 k 個排序內邊
  不小於第 k 個外邊，前 k 個外邊就只能配到至多 k-1 個更小內邊，違反鴿籠原理；充分性則
  直接按相同排名配對。故逐維比較精確刻畫可包含關係。嚴格支配必使字典序嚴格增加，所以
  排序後所有前驅都在較小索引。歸納假設 dp[j] 已是以 j 結尾的最長合法鏈，枚舉所有能進入
  i 的 j 再取最大值，恰涵蓋且只涵蓋所有以 i 結尾的鏈；最後取全域最大即最優。
common_errors:
  [只比較原輸入中的同位置維度, 把嚴格小於寫成小於等於, 沒先確認禮物能放入鏈的第一盒, 多組 EOF 輸入未清空狀態]

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <vector>
  using namespace std;
  static bool fits_inside(const vector<int>& inner,const vector<int>& outer){
      for(size_t index=0;index<inner.size();++index)if(inner[index]>=outer[index])return false;
      return true;
  }
  int main(){
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int box_count=0,dimension_count=0;
      while(cin>>box_count>>dimension_count){
          vector<int> gift(static_cast<size_t>(dimension_count));
          for(int& length:gift)cin>>length;
          sort(gift.begin(),gift.end());
          vector<vector<int>> boxes(static_cast<size_t>(box_count),vector<int>(static_cast<size_t>(dimension_count)));
          for(vector<int>& box:boxes){
              for(int& length:box)cin>>length;
              sort(box.begin(),box.end());
          }
          sort(boxes.begin(),boxes.end());
          vector<int> dp(static_cast<size_t>(box_count),0);
          int answer=0;
          for(int outer=0;outer<box_count;++outer){
              if(fits_inside(gift,boxes[static_cast<size_t>(outer)]))dp[static_cast<size_t>(outer)]=1;
              for(int inner=0;inner<outer;++inner){
                  if(dp[static_cast<size_t>(inner)]==0)continue;
                  if(fits_inside(boxes[static_cast<size_t>(inner)],boxes[static_cast<size_t>(outer)])){
                      dp[static_cast<size_t>(outer)]=max(dp[static_cast<size_t>(outer)],dp[static_cast<size_t>(inner)]+1);
                  }
              }
              answer=max(answer,dp[static_cast<size_t>(outer)]);
          }
          if(answer==0)cout<<"Please look for another gift shop!\n";
          else cout<<answer<<'\n';
      }
      return 0;
  }
