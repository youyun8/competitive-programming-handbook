statement: 矩陣第 0 列依序為 233、2333、23333…，且 i,j>0 時 a_{i,j}=a_{i-1,j}+a_{i,j-1}。已知 a_{1,0}…a_{n,0}，求 a_{n,m} mod 10000007。
constraints:
  - 1 <= n <= 10
  - 1 <= m <= 10^9
  - 0 <= a_{i,0} < 2^31
  - 多組資料直到 EOF
input_format: 每組第一行 n、m；第二行 n 個第 0 欄元素。
output_format: 每組輸出 a_{n,m} mod 10000007。
samples:
  - input: |
      1 1
      1
      2 2
      0 0
      3 7
      23 47 16
    output: |
      234
      2799
      72937
    explanation: 第一組 a_{1,1}=a_{0,1}+a_{1,0}=233+1=234；其餘依相同欄轉移。
core_knowledge:
  - 逐欄線性轉移
  - 前綴和係數
  - 常數維度
judgment: n 很小而 m 很大；把整欄與產生 233… 所需的 23、常數 3 一起放入狀態，可快速跨欄。
hints:
  - 第 0 列滿足 x_j=10x_{j-1}+3，可用 [23,3] 表示。
  - 同一新欄由上往下計算，所以 a_{i,j}=10·23+3+Σ_{r=1}^i a_{r,j-1}。
  - 建立 n+2 維狀態 [23,a_1,…,a_n,3]，對欄轉移矩陣取 m 次方。
solution_outline: 構造每列含前綴 1 的 n+2 維矩陣，快速冪 m 次後取狀態第 n 個元素。
proof_or_invariant: 矩陣第 0 列生成下一個 233…；第 i 列恰為新第 0 列加舊 a_1 到 a_i，等同逐行遞推。故每次乘法精確前進一欄。
complexity:
  time: 每組 O(n^3 log m)
  space: O(n^2)
common_errors:
  - 把首狀態設為 233 而使次方錯一欄
  - 第 i 列漏加前面各行
  - 模數誤寫成 10^9+7
