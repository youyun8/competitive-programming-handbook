statement: |-
  給定一棵以 1 為根的樹。每次詢問刪除若干指定節點的整棵子樹，並指定節點 p，
  求 p 到所有未刪除節點距離的總和、最小值或最大值；沒有未刪除節點時輸出 -1。
  詢問強制在線：若上次答案不是 -1，令 last 為上次答案，否則令 last=0，
  真正的節點為 `(p' + last) mod n + 1`。
constraints:
  - 多組測試資料讀到 EOF
  - 樹邊長均為 1
  - 所有詢問的 k 總和需配合 O((n+Σk) log n) 解法
input_format: |-
  每組先輸入 n、q，再輸入 n-1 條邊。每個詢問先輸入 k、p'、t，
  其中 t=1/2/3 分別詢問距離和、最小距離、最大距離，後接 k 個被刪子樹根。
output_format: 每個詢問輸出一行答案；可行節點集合為空時輸出 -1。
samples:
  - input: |
      3 3
      1 2
      1 3
      0 0 1
      1 0 2 2
      1 2 3 1
    output: |
      2
      0
      -1
    explanation: |-
      第一問真正節點為 1，距離和為 2。第二問受 last=2 影響，真正節點為 3；
      刪除子樹 2 後最短距離為 0。第三問刪除根節點子樹，沒有可行點。
core_knowledge:
  - DFS 序把子樹轉成連續區間
  - 換根時的距離序列區間加
  - 標記永久化的持久化線段樹
judgment: |-
  對每個可能的 p 建立一個 DFS 序距離版本；將被刪子樹區間排序合併，
  查詢其補集的 sum/min/max。
hints:
  - 從父節點走到子節點時，子樹內所有距離減一，子樹外所有距離加一。
  - 先對全域加一，再對該子樹加負二，即可由父版本建立子版本。
  - 區間加標記不下推而永久保留；查詢時沿路累加祖先標記，可把空間降至 O(n log n)。
solution_outline: |-
  根為 1 時，DFS 序位置的值就是對應節點深度。持久化線段樹維護 sum、min、max
  與永久 lazy。依 DFS 先序由父版本建立每個節點的距離版本。詢問時把 k 個子樹
  轉成 DFS 區間，排序後略過被包含區間，對剩餘補集逐段查詢並合併摘要。
proof_or_invariant: |-
  對邊 parent→child，任意位於 child 子樹的點距離恰減一，其他點距離恰加一，
  因此兩次區間加產生的版本逐點等於真實距離。DFS 區間精確表示子樹；
  合併後區間的補集恰為所有可行點，對補集摘要做和、最小、最大合併即為答案。
common_errors:
  - 上次答案為 -1 時沒有把 last 重設為 0
  - 被刪區間互相包含時重複移動補集右端點
  - 持久化 lazy 下推時誤改歷史版本
complexity:
  time: O((n + Σk) log n)
  space: O(n log n)

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  struct Summary {
      long long sum = 0;
      int minimum = numeric_limits<int>::max();
      int maximum = numeric_limits<int>::min();
      int count = 0;

      void merge(const Summary& other) {
          if (other.count == 0) { return; }
          sum += other.sum;
          minimum = min(minimum, other.minimum);
          maximum = max(maximum, other.maximum);
          count += other.count;
      }
  };

  struct PersistentTree {
      struct Node {
          int left = 0;
          int right = 0;
          long long sum = 0;
          int minimum = 0;
          int maximum = 0;
          int lazy = 0;
      };

      vector<Node> nodes{Node{}};

      int clone_node(int node) {
          nodes.push_back(nodes[static_cast<size_t>(node)]);
          return static_cast<int>(nodes.size()) - 1;
      }

      void apply(int node, int l, int r, int delta) {
          Node& current = nodes[static_cast<size_t>(node)];
          current.sum += static_cast<long long>(r - l + 1) * delta;
          current.minimum += delta;
          current.maximum += delta;
          current.lazy += delta;
      }

      void pull(int node, int l, int r) {
          Node& current = nodes[static_cast<size_t>(node)];
          const Node& left = nodes[static_cast<size_t>(current.left)];
          const Node& right = nodes[static_cast<size_t>(current.right)];
          current.sum = left.sum + right.sum +
                        static_cast<long long>(r - l + 1) * current.lazy;
          current.minimum = min(left.minimum, right.minimum) + current.lazy;
          current.maximum = max(left.maximum, right.maximum) + current.lazy;
      }

      int build(int l, int r, const vector<int>& values) {
          const int node = static_cast<int>(nodes.size());
          nodes.push_back(Node{});
          if (l == r) {
              nodes[static_cast<size_t>(node)].sum = values[static_cast<size_t>(l)];
              nodes[static_cast<size_t>(node)].minimum = values[static_cast<size_t>(l)];
              nodes[static_cast<size_t>(node)].maximum = values[static_cast<size_t>(l)];
              return node;
          }
          const int mid = (l + r) / 2;
          nodes[static_cast<size_t>(node)].left = build(l, mid, values);
          nodes[static_cast<size_t>(node)].right = build(mid + 1, r, values);
          pull(node, l, r);
          return node;
      }

      int modify(int old_node, int l, int r, int ql, int qr, int delta) {
          if (qr < l || r < ql) { return old_node; }
          const int node = clone_node(old_node);
          if (ql <= l && r <= qr) {
              apply(node, l, r, delta);
              return node;
          }
          const int mid = (l + r) / 2;
          const int old_left = nodes[static_cast<size_t>(node)].left;
          const int old_right = nodes[static_cast<size_t>(node)].right;
          nodes[static_cast<size_t>(node)].left =
              modify(old_left, l, mid, ql, qr, delta);
          nodes[static_cast<size_t>(node)].right =
              modify(old_right, mid + 1, r, ql, qr, delta);
          pull(node, l, r);
          return node;
      }

      Summary query(int node, int l, int r, int ql, int qr, int inherited) const {
          if (qr < l || r < ql) { return Summary{}; }
          const Node& current = nodes[static_cast<size_t>(node)];
          if (ql <= l && r <= qr) {
              return {
                  current.sum + static_cast<long long>(r - l + 1) * inherited,
                  current.minimum + inherited,
                  current.maximum + inherited,
                  r - l + 1,
              };
          }
          const int next_inherited = inherited + current.lazy;
          const int mid = (l + r) / 2;
          Summary result =
              query(current.left, l, mid, ql, qr, next_inherited);
          result.merge(query(current.right, mid + 1, r, ql, qr, next_inherited));
          return result;
      }
  };

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      int n, query_count;
      while (cin >> n >> query_count) {
          vector<vector<int>> adjacency(static_cast<size_t>(n) + 1);
          for (int i = 1; i < n; ++i) {
              int u, v;
              cin >> u >> v;
              adjacency[static_cast<size_t>(u)].push_back(v);
              adjacency[static_cast<size_t>(v)].push_back(u);
          }

          vector<int> parent(static_cast<size_t>(n) + 1);
          vector<int> depth(static_cast<size_t>(n) + 1);
          vector<int> tin(static_cast<size_t>(n) + 1);
          vector<int> subtree_size(static_cast<size_t>(n) + 1, 1);
          vector<int> at_time(static_cast<size_t>(n) + 1);
          vector<int> order;
          order.reserve(static_cast<size_t>(n));
          vector<int> stack{1};
          int timer = 0;
          while (!stack.empty()) {
              const int node = stack.back();
              stack.pop_back();
              tin[static_cast<size_t>(node)] = ++timer;
              at_time[static_cast<size_t>(timer)] = node;
              order.push_back(node);
              const auto& edges = adjacency[static_cast<size_t>(node)];
              for (auto it = edges.rbegin(); it != edges.rend(); ++it) {
                  const int next = *it;
                  if (next == parent[static_cast<size_t>(node)]) { continue; }
                  parent[static_cast<size_t>(next)] = node;
                  depth[static_cast<size_t>(next)] =
                      depth[static_cast<size_t>(node)] + 1;
                  stack.push_back(next);
              }
          }
          for (size_t i = order.size(); i-- > 1;) {
              const int node = order[i];
              subtree_size[static_cast<size_t>(
                  parent[static_cast<size_t>(node)])] +=
                  subtree_size[static_cast<size_t>(node)];
          }
          vector<int> tout(static_cast<size_t>(n) + 1);
          vector<int> initial(static_cast<size_t>(n) + 1);
          for (int node = 1; node <= n; ++node) {
              tout[static_cast<size_t>(node)] =
                  tin[static_cast<size_t>(node)] +
                  subtree_size[static_cast<size_t>(node)] - 1;
              initial[static_cast<size_t>(tin[static_cast<size_t>(node)])] =
                  depth[static_cast<size_t>(node)];
          }

          PersistentTree tree;
          tree.nodes.reserve(static_cast<size_t>(n) * 24 + 8);
          vector<int> root(static_cast<size_t>(n) + 1);
          root[1] = tree.build(1, n, initial);
          for (size_t i = 1; i < order.size(); ++i) {
              const int node = order[i];
              int version = tree.modify(
                  root[static_cast<size_t>(parent[static_cast<size_t>(node)])],
                  1, n, 1, n, 1);
              version = tree.modify(
                  version, 1, n, tin[static_cast<size_t>(node)],
                  tout[static_cast<size_t>(node)], -2);
              root[static_cast<size_t>(node)] = version;
          }

          long long last_answer = 0;
          while (query_count-- > 0) {
              int k, encoded_point, type;
              cin >> k >> encoded_point >> type;
              const int point = static_cast<int>(
                  (static_cast<long long>(encoded_point) + last_answer) % n) + 1;
              vector<pair<int, int>> banned;
              banned.reserve(static_cast<size_t>(k));
              for (int i = 0; i < k; ++i) {
                  int node;
                  cin >> node;
                  banned.push_back({
                      tin[static_cast<size_t>(node)],
                      tout[static_cast<size_t>(node)],
                  });
              }
              sort(banned.begin(), banned.end());

              Summary answer;
              int covered_right = 0;
              for (const auto& [left, right] : banned) {
                  if (right <= covered_right) { continue; }
                  if (left > covered_right + 1) {
                      answer.merge(tree.query(
                          root[static_cast<size_t>(point)], 1, n,
                          covered_right + 1, left - 1, 0));
                  }
                  covered_right = max(covered_right, right);
              }
              if (covered_right < n) {
                  answer.merge(tree.query(
                      root[static_cast<size_t>(point)], 1, n,
                      covered_right + 1, n, 0));
              }

              if (answer.count == 0) {
                  cout << -1 << '\n';
                  last_answer = 0;
              } else if (type == 1) {
                  cout << answer.sum << '\n';
                  last_answer = answer.sum;
              } else if (type == 2) {
                  cout << answer.minimum << '\n';
                  last_answer = answer.minimum;
              } else {
                  cout << answer.maximum << '\n';
                  last_answer = answer.maximum;
              }
          }
      }
      return 0;
  }
