statement: n 位學生各希望在 t_i 日前得知全部 m 科成績，晚一天每人產生 C 不愉快度。科目原訂 b_i 日公布；可花 A 將一科提前一天並令另一科延後一天，或花 B 單獨提前一科一天。求總不愉快度最小值。
constraints: ['1 ≤ n,m,t_i,b_i ≤ 100000', '0 ≤ A,B ≤ 10^5', '0 ≤ C ≤ 10^5，特殊資料 C=10^16']
input_format: 第一行 A、B、C；第二行 n、m；第三行學生期限；第四行科目原公布日。
output_format: 輸出最小總不愉快度。
samples:
  - input: |
      100 100 2
      4 5
      5 1 2 3
      1 1 2 3 3
    output: |
      6
    explanation: 不調整科目時最後公布日為 3，只有期限 1、2 的學生等待，總不愉快度為 6，且已最優。
core_knowledge: ['枚舉最終最晚公布日', '提前需求與可配對延後量', '離散凸函數三分']
judgment: 固定最晚日 x，晚於 x 的科目必須提前；早於 x 的空間可與提前操作配對，單位成本取 min(A,B)。
hints:
  - '先固定所有成績最晚在第 x 天公布。'
  - 'need 為晚於 x 的總提前天數；spare 為早於 x 的可延後天數。'
  - '調整成本=min(A,B)×min(need,spare)+B×max(0,need-spare)，再加學生等待成本；對 x 整數三分。'
solution_outline: 對候選最晚日 x 線性計算 need、spare 與學生等待天數，使用飽和算術避免極端 C 溢位。成本為離散凸函數；三分縮至小區間後逐點取最小。
proof_or_invariant: 固定 x 時每個晚科目的 need 必須完成；若 A<B，至多 spare 單位可配對，否則直接 B 更優，公式即最小調整成本。學生只由 x 超過期限的差額決定。兩者皆為分段線性凸函數，其和凸，整數三分加末段枚舉得到全域最小。
common_errors: ['把 A 操作當成可憑空提前', '漏算最後公布日而逐科算學生等待', '未比較 A 與 B', 'C=10^16 時乘法溢位']

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false); cin.tie(nullptr);
      long long a,b,c; int n,m; cin>>a>>b>>c>>n>>m;
      vector<long long> deadline(static_cast<size_t>(n)), release(static_cast<size_t>(m));
      for(auto&x:deadline){cin>>x;}
      for(auto&x:release){cin>>x;}
      const long long inf=numeric_limits<long long>::max()/4;
      const auto add_product=[&](long long base,long long x,long long y){if(x!=0&&y>(inf-base)/x)return inf;return base+x*y;};
      const auto cost=[&](long long day){
          long long need=0,spare=0,result=0;
          for(const long long x:release)if(x>day)need+=x-day;else spare+=day-x;
          const long long paired=min(need,spare);
          result=add_product(result,min(a,b),paired);
          result=add_product(result,b,need-paired);
          for(const long long x:deadline)if(day>x)result=add_product(result,c,day-x);
          return result;
      };
      long long left=0,right=*max_element(release.begin(),release.end());
      while(right-left>6){long long m1=left+(right-left)/3,m2=right-(right-left)/3;if(cost(m1)<=cost(m2))right=m2;else left=m1;}
      long long answer=inf;
      for(long long day=left;day<=right;++day)answer=min(answer,cost(day));
      cout<<answer<<'\n';
  }
