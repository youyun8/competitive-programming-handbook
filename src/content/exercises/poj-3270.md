statement: n 頭牛的脾氣值互異，可交換任兩頭牛，成本為兩值之和。求將序列按值遞增排序的最小總成本。

input_format: 第一行 n，接著 n 行依序給脾氣值。
output_format: 輸出最小排序成本。
samples:
  - input: |-
      3
      2
      3
      1
    output: '7'
    explanation: 先交換 3、1 花 4，再交換 2、1 花 3，總成本 7。
core_knowledge: [目標置換的循環分解, 循環內最小值與全域最小值兩種交換策略]
judgment: 值互異，排序後每個元素的目標位置唯一。
hints:
  - 把「目前位置應送往哪個排序位置」寫成置換並分解循環。
  - 長度 k 的循環若反覆使用循環內最小值 m，成本為 sum+(k-2)m。
  - 也可借用全域最小值 g 進出循環，成本為 sum+m+(k+1)g；取較小者。
solution_outline: 排序值以建立原位置到目標位置的置換；走訪每個循環，統計長度、總和與最小值，累加兩公式的較小值。
proof_or_invariant: 一個循環至少需 k-1 次交換。若只用循環內元素，令最小值參與每次交換使成本最小，得到第一式。若引入外部元素，最佳外援必為全域最小值，且需兩次交換進出循環，得到第二式。任何策略不是不用外援就是使用外援；兩類下界皆由上述構造達成。
common_errors: [置換方向建立錯誤, 長度一循環仍加入成本, 總成本使用 32 位元]
complexity: { time: 'O(n log n)', space: 'O(n)' }

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <numeric>
  #include <vector>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n;
      cin >> n;
      vector<int> value(static_cast<size_t>(n));
      for (int &x : value) cin >> x;
      vector<int> order(static_cast<size_t>(n));
      iota(order.begin(), order.end(), 0);
      sort(order.begin(), order.end(), [&](int left, int right) {
          return value[static_cast<size_t>(left)] < value[static_cast<size_t>(right)];
      });
      vector<int> target(static_cast<size_t>(n));
      for (int position = 0; position < n; ++position)
          target[static_cast<size_t>(order[static_cast<size_t>(position)])] = position;
      const int global_minimum = *min_element(value.begin(), value.end());
      vector<bool> visited(static_cast<size_t>(n), false);
      long long answer = 0;
      for (int start = 0; start < n; ++start) {
          if (visited[static_cast<size_t>(start)]) continue;
          int current = start;
          int length = 0;
          int cycle_minimum = 100001;
          long long sum = 0;
          while (!visited[static_cast<size_t>(current)]) {
              visited[static_cast<size_t>(current)] = true;
              ++length;
              sum += value[static_cast<size_t>(current)];
              cycle_minimum = min(cycle_minimum, value[static_cast<size_t>(current)]);
              current = target[static_cast<size_t>(current)];
          }
          if (length > 1) {
              const long long internal = sum + static_cast<long long>(length - 2) * cycle_minimum;
              const long long external = sum + cycle_minimum +
                                         static_cast<long long>(length + 1) * global_minimum;
              answer += min(internal, external);
          }
      }
      cout << answer << '\n';
      return 0;
  }
