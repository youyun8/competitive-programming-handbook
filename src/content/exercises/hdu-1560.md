  - 以每條字串目前已匹配位置構成搜尋狀態
  - 剩餘長度最大值是 admissible 的 IDA* 下界
judgment: 子序列不要求字元連續，但相對次序不可改變；只需輸出最短長度，不必輸出構造。
hints:
  - 狀態對第 i 條字串記錄已匹配前綴長度 pos_i；追加字元 c 時，所有下一個待匹配字元為 c 的 pos_i 同時加一。
  - 至少還需 `max(len_i-pos_i)` 個字元；若目前深度加此值超過限制，該分支不可能成功。
  - 深度限制由最長輸入長度開始增加；每層只嘗試至少能推進一條字串的 A、C、G、T。
solution_outline: 對候選答案長度做迭代加深。DFS 以位置向量為狀態，枚舉四種下一字元並同步推進所有匹配字串；用最大剩餘長度剪枝。
proof_or_invariant: >-
  位置向量精確描述目前構造字串對各輸入的最長已匹配前綴。追加某字元時同步推進恰是子序列匹配規則，
  因而 DFS 枚舉限制長度內所有有用構造。每增加一個輸出字元，每條字串至多前進一格，所以最大剩餘長度是必要下界，
  剪枝不會刪除可行解。迭代限制由小到大，首個成功限制即最短長度。
complexity:
  time: O(4^L * n)，L 為答案長度；下界剪枝會刪除大量分支
  space: O(L+n)
common_errors:

  - 追加一個字元時只推進一條輸入字串
  - 下界使用剩餘長度總和，這會高估而錯誤剪枝

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int test_count;
      cin >> test_count;
      while (test_count--) {
          int n;
          cin >> n;
          vector<string> sequences(n);
          int lower_bound = 0;
          for (string& sequence : sequences) {
              cin >> sequence;
              lower_bound = max(lower_bound, static_cast<int>(sequence.size()));
          }
          vector<int> position(n, 0);
          const string alphabet = "ACGT";
          const auto search = [&](const auto& self, int depth, int limit) -> bool {
              int remaining = 0;
              bool complete = true;
              for (int i = 0; i < n; ++i) {
                  const int left = static_cast<int>(sequences[i].size()) - position[i];
                  remaining = max(remaining, left);
                  if (left > 0) complete = false;
              }
              if (complete) return true;
              if (depth + remaining > limit) return false;
              const vector<int> saved = position;
              for (char nucleotide : alphabet) {
                  bool advances = false;
                  for (int i = 0; i < n; ++i) {
                      if (position[i] < static_cast<int>(sequences[i].size())
                          && sequences[i][position[i]] == nucleotide) {
                          ++position[i];
                          advances = true;
                      }
                  }
                  if (advances && self(self, depth + 1, limit)) return true;
                  position = saved;
              }
              return false;
          };
          for (int limit = lower_bound;; ++limit) {
              fill(position.begin(), position.end(), 0);
              if (search(search, 0, limit)) {
                  cout << limit << '\n';
                  break;
              }
          }
      }
  }
