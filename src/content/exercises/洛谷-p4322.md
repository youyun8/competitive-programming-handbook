statement: >-
  n 名候選人各有招募費 s、戰鬥值 p 與推薦人 r；招募 i 必須招募 r（r=0 無限制）。恰招 k 人，最大化總戰鬥值除以總費用。
constraints:
  - 1 <= k <= n <= 2500
  - 0 < s_i,p_i <= 10000
  - 0 <= r_i < i
input_format: 第一行 k、n；接著 n 行 s_i、p_i、r_i。
output_format: 輸出最佳比值，保留三位小數。
samples:
  - input: |-
      1 2
      10 20 0
      5 20 1
    output: |-
      2.000
    explanation: 只能招一人時選候選人 1，比值為 20/10=2；候選人 2 需要同時招 1。
core_knowledge: ['01 分數規劃', '祖先依賴', 'DFS 序 DP']
judgment: 二分比值 x 後，每人權值變為 p_i-x*s_i；問題變成選恰 k 個祖先封閉節點，使權值和是否非負。
hints:
  - 答案在 [0,10000]，以 01 分數規劃二分。
  - 依賴樹做 DFS 前序，每個子樹在序列中是連續區間，記 end[u]。
  - 掃描序列時選 u 就前進一格並加權；不選 u 必跳到 end[u]，用 O(nk) DP 判定。
solution_outline: >-
  建虛擬根 0 的推薦樹並取得實節點前序與子樹結束位置。每次二分重算轉換權，做前序位置×已選人數 DP；末端恰選 k 的最大和非負則提高下界。
proof_or_invariant: >-
  Σp/Σs>=x 等價於 Σ(p-xs)>=0。祖先封閉集合掃到 u 時只有兩種：選 u 後才可考慮其後代，或不選 u 且其整個子樹都必須略過；前序區間跳轉恰好刻畫兩類。DP 枚舉所有合法集合，因此判定與比值條件等價。
common_errors: ['把虛擬根算入 k', '略過節點後仍允許選其後代', '二分輸出未保留足夠迭代精度']
