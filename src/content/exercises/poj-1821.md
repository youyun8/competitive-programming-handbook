statement: >-
  n 塊連續木板、k 名工人。工人 i 只能選一段包含位置 s_i、長度不超過 l_i 的連續木板，每塊收入 p_i；木板至多由一人粉刷，求最大收入。
constraints:
  - 1 <= n <= 16000
  - 1 <= k <= 100
  - s_i 互不相同
  - 1 <= p_i <= 10000
input_format: 第一行 n、k；接著 k 行 l_i、p_i、s_i。
output_format: 輸出最大總收入。
samples:
  - input: |-
      8 4
      3 2 2
      3 3 5
      3 1 7
      3 2 4
    output: |-
      17
    explanation: 依位置排序工人並選互不重疊區間，可取得最大收入 17。
core_knowledge: ['工人排序', '區間選擇 DP', '窗口最大值']
judgment: 按座位 s 排序後，工人的區間若使用，可視為目前最右的一段；起點前綴狀態形成連續窗口。
hints:
  - dp[i][j] 表示前 i 名工人處理前 j 塊木板的最大收入。
  - 工人 i 粉刷 k+1..j 時，k∈[max(0,j-l_i),s_i-1]，候選為 dp[i-1][k]-k*p_i+j*p_i。
  - 對合法 k 維護遞減 deque，並同時保留不使用工人與第 j 塊空白的轉移。
solution_outline: >-
  將工人按 s 排序；每層先複製不選狀態，再建立 s 前方的候選 deque，掃描可作右端的 j 更新，最後做前綴最大化。
proof_or_invariant: >-
  排序後任一不重疊方案可按工人座位順序安排。若第 i 人被選，其區間必含 s_i，且區間前的木板只能由前 i-1 人處理，得到轉移。deque 保留合法 k 中線性式最大者；其餘兩轉移涵蓋不選與留空。
common_errors: ['未按 s 排序', '候選 k 允許到 s_i 造成區間不含座位', '漏做 dp[i][j-1] 前綴最大']

cpp_solution: |
  #include <algorithm>
  #include <deque>
  #include <iostream>
  #include <vector>
  using namespace std;
  struct Worker{int length,pay,seat;};
  int main(){ios::sync_with_stdio(false);cin.tie(nullptr);int n,k;cin>>n>>k;vector<Worker>a(k);for(auto&x:a)cin>>x.length>>x.pay>>x.seat;sort(a.begin(),a.end(),[](auto x,auto y){return x.seat<y.seat;});vector<vector<long long>>dp(k+1,vector<long long>(n+1));for(int i=1;i<=k;i++){auto w=a[i-1];deque<int>q;for(int x=max(0,w.seat-w.length);x<w.seat;x++){while(!q.empty()&&dp[i-1][q.back()]-1LL*q.back()*w.pay<=dp[i-1][x]-1LL*x*w.pay)q.pop_back();q.push_back(x);}for(int j=1;j<=n;j++){dp[i][j]=max(dp[i-1][j],dp[i][j-1]);if(j>=w.seat&&j<w.seat+w.length){while(!q.empty()&&q.front()<j-w.length)q.pop_front();if(!q.empty())dp[i][j]=max(dp[i][j],dp[i-1][q.front()]+1LL*(j-q.front())*w.pay);}}}cout<<dp[k][n]<<'\n';}
