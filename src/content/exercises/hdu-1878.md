statement: 給定一張無向圖，判斷是否存在從某點出發、每條邊恰走一次並回到起點的歐拉迴路。
constraints: [頂點編號為 1 到 n, 圖可能有重邊, 輸入含多組資料, n=0 結束]

    output: "1\n0"
    explanation: 第一組是三角形，所有點度數為二且連通；第二組兩端為奇度，不能形成迴路。
core_knowledge: [無向歐拉迴路充要條件, 非零度頂點連通, 所有度數為偶數]
judgment: 孤立點不影響含邊部分的歐拉迴路；每條重邊都要分別計入度數。
hints:
  - 每讀一條無向邊，兩端度數各加一並合併其連通分量。
  - 檢查每個有邊頂點是否都屬於同一分量。
  - 連通條件成立後，還必須每個頂點度數皆為偶數。
solution_outline: 以 DSU 維護邊所連接的分量並統計度數；掃描所有非零度頂點，檢查同根與偶度。
proof_or_invariant: >-
  歐拉迴路每次進入頂點必須由另一條邊離開，因此每點度數為偶；單一巡迴也使所有含邊頂點
  連通。反之，無向圖的所有非零度頂點連通且全為偶度時，Hierholzer 可從任一含邊點反覆
  拼接閉合巡迴而使用全部邊，故兩條件亦充分。
common_errors: [要求包含所有孤立點的圖連通, 只檢查偶度而忽略多個含邊分量, 重邊被去重, 將兩奇點的歐拉路誤當成歐拉迴路]

  int main(){
      ios::sync_with_stdio(false);cin.tie(nullptr);int n=0;
      while(cin>>n&&n!=0){int m=0;cin>>m;Dsu dsu(n);vector<int> degree(static_cast<size_t>(n+1),0);
          for(int i=0;i<m;++i){int u=0,v=0;cin>>u>>v;dsu.unite(u,v);++degree[static_cast<size_t>(u)];++degree[static_cast<size_t>(v)];}
          bool ok=true;int root=-1;for(int v=1;v<=n;++v){if(degree[static_cast<size_t>(v)]%2!=0)ok=false;if(degree[static_cast<size_t>(v)]>0){if(root==-1)root=dsu.find(v);else if(root!=dsu.find(v))ok=false;}}cout<<(ok?1:0)<<'\n';
      }
  }
