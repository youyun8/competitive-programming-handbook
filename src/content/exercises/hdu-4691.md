statement: 每行是母字串 S 的半開區間子串。原格式每行直接寫子串；前綴壓縮格式寫它與上一行的 LCP 長度、空格及剩餘後綴。求兩種格式的總位元組數，空格與換行也各算一位元組。
constraints: ['|S| <= 100000', '1 <= N <= 100000', '0 <= A < B <= |S|', '多組資料直到 EOF']

output_format: 每組輸出原格式與壓縮格式的位元組數。
samples:
  - input: "frcode\n2\n0 6\n0 6\n"
    output: 14 12
    explanation: 兩行原文各 6 字元加換行共 14；壓縮為 `0 frcode` 與 `6 `，連換行共 12。另以直接逐字 LCP 對拍隨機區間序列。
core_knowledge: [任意後綴 LCP, height 區間最小值, 十進位位數]
judgment: 區間右端不含；第一行也以前綴長度 0 編碼；空格與換行皆計一 byte。
hints:
  - 兩個子串的 LCP 是其起點後綴 LCP，再截斷到兩個子串長度的較小值。
  - SA 中任意兩後綴的 LCP 等於兩者 rank 之間 height 的最小值，可用 sparse table O(1) 查詢。
  - 原行成本 len+1；壓縮行成本 digits(lcp)+1+(len−lcp)+1。
solution_outline: 建 S 的 SA 與 Kasai height，再建 RMQ sparse table。依輸入順序處理區間，與前一區間起點查後綴 LCP 並限制長度，套用兩種逐行成本公式累加。
proof_or_invariant: 前綴壓縮只省去與上一行相同的最大前綴；後綴 LCP 經兩個子串長度截斷後正是可省字元數。其餘字元及數字、空格、換行皆由公式逐項計入，逐行相加即總 byte。
common_errors: [把 B 當含端點, 忘記數字 0 也占一位, LCP 未截斷到較短子串]
