statement: 平面上有親水與疏水兩類粒子。放置一條無限長隔板後，一側滴水、另一側滴丙酮；位於水側的親水粒子、丙酮側的疏水粒子，以及恰在隔板上的任意粒子都會溶解。求適當選擇隔板位置與兩側溶劑後，最多可溶解多少粒子。

  - r 為 0 或 1，分別代表親水與疏水
  - N=0 結束輸入

output_format: 每組輸出一個整數，表示最多可溶解的粒子數。

core_knowledge:
  - 最優分隔線可平移到至少通過一個粒子而不減少答案
  - 相對樞紐而言，把異類點向量反向後，合法點會落在同一閉半平面
  - 同一閉半平面的方向在極角序列中形成長度不超過 pi 的連續窗口
judgment: 枚舉隔板通過的樞紐。對其他點取相對向量，若類別與樞紐不同就反向；此時選定隔板方向後，可被正確分到兩側的點恰對應某個閉半圓內的向量。極角排序加雙指標可在每個樞紐 O(N log N) 求最大值。
hints:
  - 任一不經粒子的最優直線都可保持方向平移，直到首次碰到粒子；此前已溶解集合不會減少。
  - 固定隔板通過 i，令同類 j 使用向量 p_j-p_i、異類 j 使用其反向；問題就變成選一個過原點閉半平面容納最多向量。
  - 將極角排序序列複製一份並加 2pi，以雙指標維護角差不超過 pi 的窗口；與樞紐重合的點永遠在線上，另外計數。
solution_outline: 逐點作樞紐，建立其他點的轉換向量並記錄 atan2 極角；零向量直接加入基數。排序非零向量，複製極角加 2pi，對每個左端點推進右端點至角差超過 pi，更新窗口大小加基數的最大值。
proof_or_invariant: 最優隔板可平移至某粒子 i 而不失去已正確分側的點，因此枚舉樞紐不漏解。固定 i 並把異類相對向量乘以 -1 後，「同類與 i 位於指定側、異類位於另一側」統一成所有轉換向量位於某個閉半平面；隔板上的點也因閉邊界而計入。過原點閉半平面在方向圓上恰是一段長度 pi 的閉區間，排序後雙指標枚舉所有此類區間，所以所得最大值正確。
complexity:
  time: O(N² log N)
  space: O(N)
common_errors:
  - 沒有反向異類點向量，實際算成單一類別的半平面最大點數
  - 用嚴格小於 pi 而漏掉位於隔板上的反向共線點
  - 忘記角度環狀跨越 -pi 與 pi，未複製序列
  - 重合點的零向量傳入 atan2 後被任意分組

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  struct Particle { int x; int y; int type; };

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n;
      while (cin >> n && n != 0) {
          vector<Particle> particles(static_cast<size_t>(n));
          for (Particle& particle : particles) {
              cin >> particle.x >> particle.y >> particle.type;
          }
          int answer = 1;
          const long double pi = acosl(-1.0L);
          for (int pivot = 0; pivot < n; ++pivot) {
              vector<long double> angles;
              int on_pivot = 1;
              for (int j = 0; j < n; ++j) {
                  if (j == pivot) { continue; }
                  int dx = particles[static_cast<size_t>(j)].x -
                           particles[static_cast<size_t>(pivot)].x;
                  int dy = particles[static_cast<size_t>(j)].y -
                           particles[static_cast<size_t>(pivot)].y;
                  if (dx == 0 && dy == 0) {
                      ++on_pivot;
                      continue;
                  }
                  if (particles[static_cast<size_t>(j)].type !=
                      particles[static_cast<size_t>(pivot)].type) {
                      dx = -dx;
                      dy = -dy;
                  }
                  angles.push_back(
                      atan2l(static_cast<long double>(dy),
                             static_cast<long double>(dx)));
              }
              sort(angles.begin(), angles.end());
              const size_t count = angles.size();
              vector<long double> extended = angles;
              extended.reserve(count * 2U);
              for (long double angle : angles) {
                  extended.push_back(angle + 2.0L * pi);
              }
              size_t right = 0;
              for (size_t left = 0; left < count; ++left) {
                  right = max(right, left);
                  while (right < left + count &&
                         extended[right] - extended[left] <= pi + 1e-18L) {
                      ++right;
                  }
                  const int in_half_plane =
                      static_cast<int>(right - left);
                  answer = max(answer, on_pivot + in_half_plane);
              }
              answer = max(answer, on_pivot);
          }
          cout << answer << '\n';
      }
      return 0;
  }
