statement: 小狗從 S 出發，每秒走到四鄰格；走過的格子隨即消失，不能停留或重訪。門 D 只在第 T 秒短暫開啟，判斷能否恰在 T 秒抵達。
constraints:
  - 1 < N,M < 7
  - 0 < T < 50
  - 多組資料，以 0 0 0 結束
input_format: 每組 N、M、T，後接 N 行迷宮；X 是牆，. 是空格。
output_format: 可行輸出 YES，否則 NO。
samples:
  - input: |
      4 4 5
      S.X.
      ..X.
      ..XD
      ....
      3 4 5
      S.X.
      ..X.
      ...D
      0 0 0
    output: |-
      NO
      YES
    explanation: 第一組無法在不重訪下恰好五步抵門；第二組存在五步路徑。
core_knowledge:
  - 簡單路徑回溯
  - 曼哈頓距離與棋盤奇偶性剪枝
judgment: 必須恰好第 T 秒，提早到門也不能等待；任何格不能重訪。
hints:
  - DFS 狀態為位置與已走秒數，移動前標記、返回後撤銷。
  - 若到門的曼哈頓距離大於剩餘秒數，必不可能。
  - 四方格每步翻轉黑白色；剩餘時間與曼哈頓距離奇偶不同也不可能。
solution_outline: 以不重訪 DFS 搜尋 T 層，使用距離、奇偶與可用格數剪枝。
proof_or_invariant: DFS 路徑始終是從 S 出發的不重複合法路徑，並枚舉每個可走鄰格。距離是必要下界，奇偶是四方移動必要條件，故剪枝不刪可行解；T 層到 D 充要。
complexity:
  time: O(4^T)
  space: O(NM)
common_errors:
  - 提早到 D 後原地等待
  - 漏做回溯撤銷
  - 只判距離而未利用奇偶剪枝
