statement: |-
  給定非負整數陣列 a，令 S(i,j) 為從 a_i 到 a_j 的區間和。計算所有 1≤i≤j≤n 的
  (floor(log2(S(i,j)))+1)×(i+j)
  之總和。此題特別約定 log2(0) 視為 0。

judgment: '逐一枚舉 O(n^2) 個區間不可行；即使每個左端二分 34 個邊界也多一個 log n。利用前綴和目標隨左端增加而不減，能讓每個權重的兩個右界線性掃過。'
hints:
  - '係數 floor(log2(sum))+1 在哪些連續整數範圍內保持不變？別忘了 sum=0 的特別約定。'
  - '固定係數 weight：weight=1 對應和 0..1；weight≥2 對應 2^(weight-1)..2^weight-1。用兩個右指標找出每個左端的合法右端區間。'
  - '若合法右端為 first..last，數量 count=last-first+1，則 Σ(i+j)=count×i+(first+last)×count/2；再乘 weight。'
solution_outline: 建立非遞減前綴和。枚舉 weight=1..34，決定對應區間和下、上界。對左端 i=1..n，維護 first_ge 指向第一個和至少為下界的右端，first_gt 指向第一個和大於上界的右端；因前綴和與目標都不減，兩指標只向右。合法右端為 [first_ge,first_gt)，用等差級數計算所有 i+j 並乘 weight。
proof_or_invariant: '每個非負區間和恰落在唯一權重帶：0、1 落在 weight=1；正整數 x≥2 唯一落在 [2^(w-1),2^w-1]。固定權重與 i 時，前綴和非遞減，所以滿足該帶的右端形成連續區間 [first_ge,first_gt)。i 增加後兩個搜尋目標都不減，舊指標左側仍不可能合格，故指標只右移仍可找出精確邊界。每個區間在唯一帶中被其唯一左端計算一次，等差公式又精確加總所有 i+j，因此總和正確。'

  - '每個左端重新從頭移動右指標，退化為平方時間'
  - '計算等差級數時先用 int 相乘而溢位'

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <vector>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int test_count = 0;
      cin >> test_count;
      while (test_count-- > 0) {
          int n = 0;
          cin >> n;
          vector<long long> prefix(static_cast<size_t>(n) + 1U, 0);
          for (int i = 1; i <= n; ++i) {
              long long value = 0;
              cin >> value;
              prefix[static_cast<size_t>(i)] =
                  prefix[static_cast<size_t>(i - 1)] + value;
          }

          long long answer = 0;
          for (int weight = 1; weight <= 34; ++weight) {
              const long long lower =
                  weight == 1 ? 0 : (1LL << (weight - 1));
              const long long upper = (1LL << weight) - 1;
              int first_ge = 1;
              int first_gt = 1;
              for (int left = 1; left <= n; ++left) {
                  first_ge = max(first_ge, left);
                  first_gt = max(first_gt, left);
                  const long long base = prefix[static_cast<size_t>(left - 1)];
                  while (first_ge <= n
                         && prefix[static_cast<size_t>(first_ge)] < base + lower) {
                      ++first_ge;
                  }
                  first_gt = max(first_gt, first_ge);
                  while (first_gt <= n
                         && prefix[static_cast<size_t>(first_gt)] <= base + upper) {
                      ++first_gt;
                  }
                  if (first_ge < first_gt) {
                      const long long count =
                          static_cast<long long>(first_gt - first_ge);
                      const long long index_sum =
                          static_cast<long long>(first_ge + first_gt - 1)
                          * count / 2;
                      const long long pair_sum =
                          static_cast<long long>(left) * count + index_sum;
                      answer += static_cast<long long>(weight) * pair_sum;
                  }
              }
          }
          cout << answer << '\n';
      }
      return 0;
  }
