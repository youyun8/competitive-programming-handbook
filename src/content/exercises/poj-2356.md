statement: >-
  給定 n 個正整數。請從原序列中選出一段連續且非空的數，使這段數的總和能被 n 整除，
  並輸出所選數量及每一個數值。若不存在才輸出 0；題目的條件保證可由鴿巢原理找到。
constraints:
  - 1 <= n <= 10000
  - 每個輸入數皆為正整數且不超過 15000，數值可以重複
  - 時間限制 1000 ms，記憶體限制 65536 kB
input_format: 第一行為整數 n，接下來 n 行各有一個正整數 a_i。
output_format: 若找到答案，先輸出所選數量，再逐行輸出該連續子段中的數；否則輸出 0。
samples:
  - input: |
      5
      1
      2
      3
      4
      1
    output: |
      2
      2
      3
    explanation: 第二、三個數的和為 5，恰可被 n=5 整除；題目允許輸出任一組合法答案。
core_knowledge:
  - 前綴和同餘代表兩前綴之差可被 n 整除
  - n 個非零餘數放進 n-1 個餘數類時必有重複
judgment: 特殊評測；任何非空、連續且總和為 n 倍數的輸入子段皆可。
hints:
  - 先依序考慮前綴和，不必任意挑選數的子集合。
  - 若某個前綴和除以 n 的餘數為 0，這個前綴本身就是答案。
  - 否則 n 個前綴餘數都落在 1 到 n-1；取兩個相同餘數的位置，相減便得到答案區間。
solution_outline: >-
  計算 prefix_i mod n。以 first[r] 記錄餘數 r 第一次出現的位置，並令 first[0]=0。
  掃描到位置 i 時，若目前餘數以前在位置 j 出現，輸出 a_(j+1)..a_i；
  否則記錄 i。鴿巢原理保證掃描結束前必定找到。
proof_or_invariant: >-
  掃描後 first[r] 始終是最早滿足 prefix_j≡r (mod n) 的 j。若 prefix_i 與
  prefix_j 同餘，則區間和 prefix_i-prefix_j 可被 n 整除，且 j<i，所以區間非空。
  若沒有餘數 0，n 個前綴餘數只能落入 n-1 個非零餘數類，必有一類重複；
  因此演算法一定輸出合法區間。
common_errors:
  - 誤把題目當成任意子集合；這個構造輸出的是連續子段
  - 忘記先設定 first[0]=0，因而漏掉從第一個數開始的答案
  - 輸出索引而非題目要求的原數值

cpp_solution: |
  #include <iostream>
  #include <vector>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n;
      if (!(cin >> n)) { return 0; }
      vector<int> values(static_cast<size_t>(n) + 1U);
      vector<int> first(static_cast<size_t>(n), -1);
      first[0] = 0;
      int remainder = 0;
      for (int i = 1; i <= n; ++i) {
          cin >> values[static_cast<size_t>(i)];
          remainder = (remainder + values[static_cast<size_t>(i)]) % n;
          const int left_prefix = first[static_cast<size_t>(remainder)];
          if (left_prefix != -1) {
              cout << i - left_prefix << '\n';
              for (int j = left_prefix + 1; j <= i; ++j) {
                  cout << values[static_cast<size_t>(j)] << '\n';
              }
              return 0;
          }
          first[static_cast<size_t>(remainder)] = i;
      }
      cout << 0 << '\n';
      return 0;
  }
