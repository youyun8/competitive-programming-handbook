statement: >-
  n 人按順序排隊，每人有不滿值 D；若第 k 個上台，其不滿度為 (k-1)D。可把隊首若干人暫放
  進只能後進先出的黑屋，讓後面的人先上台。求所有可行出場順序的最小總不滿度。
constraints:
  - 測試組數由第一行給定
  - 1 <= n <= 100
  - 0 <= D_i <= 100
input_format: 第一行 T；每組先給 n，接著 n 個整數 D_i，空白位置不限。
output_format: 每組依 `Case #x: answer` 輸出最小總不滿度。
samples:
  - input: |-
      2
      5
      1 2 3 4 5
      5
      5 4 3 2 2
    output: |-
      Case #1: 20
      Case #2: 24
    explanation: 區間 DP 枚舉每段首人在該段內第幾個上台，兩組最小成本分別為 20 與 24。
core_knowledge: [堆疊排列分解, 首人出場位置, 區間 DP]
judgment: 黑屋為單一堆疊，先進者後出；全局第 k 位造成的等待係數為 k-1。
hints:
  - 定義 dp[l][r] 為這段從局部第 1 位開始上台時的最小額外不滿度。
  - 假設 l 在段內第 k 位上台，則 l+1..l+k-1 先完成，剩餘區間延後 k 位。
  - 用前綴和一次計算剩餘人的總 D，枚舉 k 完成轉移。
solution_outline: 按區間長度枚舉 l 的局部出場名次 k，合併前段、後段成本及兩類等待位移成本。
proof_or_invariant: >-
  由堆疊先進後出性質，若段首 l 第 k 個上台，先於他的人必恰形成連續段 l+1..l+k-1，
  其內部與 l 之後的剩餘段各自仍是同型子問題。l 等待 k-1 人；後段每人因前面新增 k 人而
  多付 kD。轉移因此是必要成本；反之依兩子問題方案及此堆疊安排能構造可行順序，故充分。
  枚舉 k 並由短區間歸納得到最優值。
common_errors: [把 l 的等待人數寫成 k, 後段只延後 k-1 位, 忘記每組清空 DP]
complexity:
  time: O(n^3) 每組
  space: O(n^2)

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <limits>
  #include <vector>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false); cin.tie(nullptr);
      int tests = 0; cin >> tests;
      for (int tc = 1; tc <= tests; ++tc) {
          int n = 0; cin >> n;
          vector<long long> value(static_cast<size_t>(n + 1), 0);
          vector<long long> prefix(static_cast<size_t>(n + 1), 0);
          for (int i = 1; i <= n; ++i) {
              cin >> value[static_cast<size_t>(i)];
              prefix[static_cast<size_t>(i)] =
                  prefix[static_cast<size_t>(i - 1)] + value[static_cast<size_t>(i)];
          }
          vector<vector<long long>> dp(static_cast<size_t>(n + 2),
                                       vector<long long>(static_cast<size_t>(n + 2), 0));
          for (int length = 2; length <= n; ++length)
              for (int left = 1; left + length - 1 <= n; ++left) {
                  const int right = left + length - 1;
                  long long best = numeric_limits<long long>::max();
                  for (int rank = 1; rank <= length; ++rank) {
                      const int split = left + rank - 1;
                      const long long tail_sum =
                          prefix[static_cast<size_t>(right)] - prefix[static_cast<size_t>(split)];
                      best = min(best,
                          dp[static_cast<size_t>(left + 1)][static_cast<size_t>(split)] +
                          value[static_cast<size_t>(left)] * (rank - 1LL) +
                          dp[static_cast<size_t>(split + 1)][static_cast<size_t>(right)] +
                          tail_sum * rank);
                  }
                  dp[static_cast<size_t>(left)][static_cast<size_t>(right)] = best;
              }
          cout << "Case #" << tc << ": " << dp[1][static_cast<size_t>(n)] << '\n';
      }
  }
