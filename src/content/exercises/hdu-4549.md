statement: 定義 F_0=a、F_1=b，且 F_n=F_{n-1}·F_{n-2}。對每組 a、b、n，求 F_n mod 1000000007。
constraints:
  - 0 <= a,b,n <= 1000000000
  - 多組資料直到 EOF
input_format: 每行三個整數 a、b、n，讀至 EOF。
output_format: 每組輸出一行 F_n mod 1000000007。
samples:
  - input: |
      0 1 0
      6 10 2
    output: |
      0
      60
    explanation: 第一組直接是 F_0；第二組 F_2=F_1F_0=10·6=60。
core_knowledge:
  - 乘法遞推的指數化
  - 費波那契快速倍增
  - 指數模 p-1
judgment: 展開可得 n>0 時 F_n=a^{fib(n-1)}b^{fib(n)}；只需快速求兩個費波那契指數。
hints:
  - 先展開前幾項，分別記錄 a、b 的指數。
  - 兩組指數都遵循普通費波那契遞推；模質數冪的指數可對 p-1 取模。
  - n=0、1 要特判；n>=2 且底數模 p 為 0 時，正指數冪仍應是 0。
solution_outline: 特判前兩項；快速倍增求 fib(n)、fib(n-1) mod p-1，再做兩次模快速冪相乘。
proof_or_invariant: 對 n 歸納，a 與 b 的指數分別為 fib(n-1)、fib(n)。費馬小定理允許非零底數的指數模 p-1；零底數另外按正指數處理，故涵蓋全部輸入。
complexity:
  time: 每組 O(log n)
  space: O(log n)
common_errors:
  - 把加法費波那契值當成答案
  - 零底數正指數被錯算為 0^0=1
  - 漏掉 n=0、1
