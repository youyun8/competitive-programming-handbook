statement: 對每組正整數 a、b、n、m，計算 ceil((a+sqrt(b))^n) mod m。
constraints:
  - 0 < a,m < 2^15
  - (a-1)^2 < b < a^2
  - 0 < b,n < 2^31
  - 多組資料直到 EOF
input_format: 每行四個正整數 a、b、n、m，讀至 EOF。
output_format: 每組輸出 ceil((a+sqrt(b))^n) mod m。
samples:
  - input: |
      2 3 1 100
      2 3 2 100
    output: |
      4
      14
    explanation: ceil(2+sqrt3)=4；(2+sqrt3)^2=7+4sqrt3，值介於 13 與 14，故上取整為 14。
core_knowledge:
  - 共軛消去根式
  - 特徵根遞推
  - 模負數正規化
judgment: 直接使用浮點次方會溢位且失準；題目條件保證 0<(a-sqrt b)^n<1，可用共軛和轉成整數二階遞推。
hints:
  - 利用 (a-1)^2<b<a^2 推出 0<a-sqrt(b)<1，將其 n 次方加到原式不會跨過下一個整數。
  - 令 C_n=(a+sqrt b)^n+(a-sqrt b)^n，則 C_0=2、C_1=2a，且 C_n=2aC_{n-1}+(b-a²)C_{n-2}。
  - 以 2×2 矩陣快速冪求 C_n；係數 b-a² 為負，存入矩陣前先正規化到 [0,m)。
solution_outline: 把上取整值化為整數共軛和 C_n，建立其二階遞推矩陣，對 n-1 快速冪並乘初始 [C_1,C_0]。
proof_or_invariant: 共軛和展開後奇次根式項抵消而為整數；又 0<(a-sqrt b)^n<1，所以它恰等於原正根式冪的上取整。兩共軛根的和與積分別為 2a、a²-b，故 C_n 滿足所列遞推，矩陣計算正確。
complexity:
  time: 每組 O(log n)
  space: O(1)
common_errors:
  - 直接用 double 計算根式冪
  - 遞推中 b-a² 的符號寫反
  - C_0、C_1 或矩陣指數錯一位
