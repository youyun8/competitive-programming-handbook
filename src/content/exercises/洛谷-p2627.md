core_knowledge: ['補集 DP', '單調佇列', '滑動視窗最小值']
judgment: 限制是每 k+1 個位置至少略過一個；改求被略過效率最小總和後，轉移只需窗口最小值。
hints:
  - 設 prefix 為總效率；令 dp[i] 表示略過第 i 頭，且截至 i 滿足限制時的最小略過和。
  - 前一個略過位置 j 必須落在 [i-k-1,i-1]，所以 dp[i]=value[i]+min dp[j]；加入虛擬位置 0。
  - 答案允許最後一個略過位置在 [n-k,n]；用遞增 deque 維護每個窗口的 dp 最小值。
solution_outline: >-
  把選取最大化轉為總和減去最小略過和。依 i 遞增，用單調佇列保存合法前驅的 dp；先移除過期索引，取隊首轉移，再從隊尾刪除不小於新值者。最後取足以覆蓋尾段的候選最小值。
proof_or_invariant: >-
  任何長度 k+1 的區間至少一個位置被略過，等價於相鄰兩個略過位置距離不超過 k+1，且首尾空段長度不超過 k。dp 轉移恰枚舉上一個略過位置；deque 僅移除過期或被更新且更晚的候選，不改變窗口最小值。因此得到最小略過和，從總和扣除即最大選取和。
common_errors: ['最後直接使用 dp[n] 而強迫略過第 n 頭', '窗口左端差一造成允許 k+1 頭連選', '總效率與 dp 使用 int 溢位']

cpp_solution: |
  #include <algorithm>
  #include <deque>
  #include <iostream>
  #include <limits>
  #include <vector>
  using namespace std;
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int n, k;
      cin >> n >> k;
      vector<long long> value(static_cast<size_t>(n + 1));
      vector<long long> dp(static_cast<size_t>(n + 1));
      long long total = 0;
      for (int i = 1; i <= n; ++i) { cin >> value[i]; total += value[i]; }
      deque<int> candidates;
      candidates.push_back(0);
      for (int i = 1; i <= n; ++i) {
          while (!candidates.empty() && candidates.front() < i - k - 1)
              candidates.pop_front();
          dp[i] = dp[candidates.front()] + value[i];
          while (!candidates.empty() && dp[candidates.back()] >= dp[i])
              candidates.pop_back();
          candidates.push_back(i);
      }
      long long removed = numeric_limits<long long>::max();
      for (int i = max(0, n - k); i <= n; ++i) removed = min(removed, dp[i]);
      cout << total - removed << '\n';
  }
