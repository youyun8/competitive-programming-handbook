statement: >-
  每筆資料給一個安全上限與一個只含小寫英文字母的非空字串。以各字母在字串中的出現次數為權重，
  求最佳二進位霍夫曼編碼所需的位元數；若此最小值不超過安全上限，字串即為安全。
constraints:
  - 字串不含空白且只由小寫英文字母組成
  - 字串只有一種字母時，每次出現仍需一位元
  - 官方可存取題面未列出 m、測試筆數與字串長度的明確上限
input_format: 第一行為測試筆數 t；每筆依序給一個整數 m 與一個小寫字母字串（空白或換行皆可分隔）。
output_format: 每筆一行；最佳編碼長度不超過 m 時輸出 yes，否則輸出 no。
samples:
  - input: |
      2
      12
      helloworld
      66
      ithinkyoucandoit
    output: |
      no
      yes
    explanation: helloworld 的霍夫曼合併成本為 27，大於 12；第二筆的最小成本為 54，不超過 66。
core_knowledge:
  - 霍夫曼樹的帶權外部路徑長度
  - 最小堆貪心合併
judgment: 對每筆只比較最小位元數與 m，輸出必須是全小寫的 yes 或 no。
hints:
  - 編碼本身不用建出來；答案只取決於 26 個字母的頻率。
  - 最佳前綴碼可讓最小的兩個頻率成為最深的一對兄弟。
  - 用最小堆重複合併兩項並累加；若堆一開始只有一項，答案是字串長度。
solution_outline: 統計 26 個頻率，把非零者放入最小堆。多於一種字母時反覆合併最小兩項並累加其和；唯一字母則以字串長度為成本。最後與 m 比較。
proof_or_invariant: >-
  最小的兩個權重可在某棵最優前綴碼樹中置於最深的兄弟葉；將其縮合為權重和後，剩下的樹仍須是縮小問題的最優解。
  因而逐次合併最小兩項不劣於任何方案，所有合併和的總和恰等於葉權乘深度之和。
common_errors:
  - 唯一字母時輸出成本 0
  - 把安全條件寫成嚴格小於 m
  - 輸出 Yes/No 而非題面要求的小寫
complexity:
  time: 每筆 O(L + a log a)，a <= 26
  space: O(a)

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;

  static long long minimum_bits(const string& text) {
      array<int, 26> frequency{};
      for (char ch : text) { ++frequency[ch - 'a']; }
      priority_queue<long long, vector<long long>, greater<long long>> min_heap;
      for (int count : frequency) {
          if (count > 0) { min_heap.push(count); }
      }
      if (min_heap.size() == 1) { return static_cast<long long>(text.size()); }
      long long cost = 0;
      while (min_heap.size() > 1) {
          const long long first = min_heap.top();
          min_heap.pop();
          const long long second = min_heap.top();
          min_heap.pop();
          const long long merged = first + second;
          cost += merged;
          min_heap.push(merged);
      }
      return cost;
  }

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      int test_count;
      cin >> test_count;
      while (test_count--) {
          long long limit;
          string text;
          cin >> limit >> text;
          cout << (minimum_bits(text) <= limit ? "yes" : "no") << '\n';
      }
  }
