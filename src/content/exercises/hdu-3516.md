statement: >-
  給 n 個點，x 隨編號嚴增、y 嚴減；用只能向右或向上的有向線段把全部點連成一棵樹，求邊總長最小值。
constraints:
  - 1 <= n <= 1000
  - 0 <= x_i,y_i <= 10000
  - 輸入含多組資料直到 EOF
input_format: 每組第一行 n，接著 n 行 x_i、y_i。
output_format: 每組輸出最短總長。
samples:
  - input: |-
      5
      1 5
      2 4
      3 3
      4 2
      5 1
      1
      10000 0
    output: |-
      12
      0
    explanation: 五個反單調點的最佳連接長 12；單點無需邊。
core_knowledge: ['幾何連接', '區間 DP', '決策單調性']
judgment: 把相鄰索引區間分成 [l,k]、[k+1,r] 時，連接兩棵子樹的必要長度由四個邊界座標決定。
hints:
  - 令 dp[l][r] 為連接索引區間 [l,r] 的最短長度。
  - 轉移代價為 dp[l][k]+dp[k+1][r]+x[k+1]-x[l]+y[k]-y[r]。
  - 最佳 k 滿足 opt[l][r-1]<=opt[l][r]<=opt[l+1][r]，只枚舉此範圍。
solution_outline: >-
  單點初始化為零與 opt=i；按區間長度遞增，用決策單調界枚舉 k，記錄最小值與新 opt。
proof_or_invariant: >-
  x、y 的反單調順序使任一最優定向樹可沿某個相鄰分界拆成兩棵樹，跨分界連接的水平、垂直長度恰為公式；反向合併也合法。此代價滿足四邊形不等式，因此 Knuth 決策單調定理適用。
common_errors: ['k 枚舉到 r 造成空右區間', '漏掉水平或垂直連接長', 'n=1 時未輸出零']
complexity:
  time: 'O(n^2)'
  space: 'O(n^2)'

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <limits>
  #include <vector>
  using namespace std;
  int main(){ios::sync_with_stdio(false);cin.tie(nullptr);int n;while(cin>>n){vector<int>x(n+2),y(n+2);for(int i=1;i<=n;i++)cin>>x[i]>>y[i];vector<vector<long long>>dp(n+2,vector<long long>(n+2));vector<vector<int>>opt(n+2,vector<int>(n+2));for(int i=1;i<=n;i++)opt[i][i]=i;for(int len=2;len<=n;len++)for(int l=1,r=l+len-1;r<=n;l++,r++){dp[l][r]=numeric_limits<long long>::max()/4;int low=opt[l][r-1],high=min(r-1,opt[l+1][r]?opt[l+1][r]:r-1);for(int k=low;k<=high;k++){long long value=dp[l][k]+dp[k+1][r]+x[k+1]-x[l]+y[k]-y[r];if(value<dp[l][r])dp[l][r]=value,opt[l][r]=k;}}cout<<dp[1][n]<<'\n';}}
