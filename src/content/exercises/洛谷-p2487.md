statement: |-
  n 枚導彈依輸入順序飛來，第 i 枚有高度 h_i 與速度 v_i。一套系統攔截後續導彈時，高度與速度都不能高於前一枚。從所有攔截數量最大的合法子序列中等機率選一個方案，求最大攔截數及每枚導彈被選中的機率。
constraints:
  - '1 <= n <= 50000'
  - '1 <= h_i,v_i <= 1000000000'
  - '最優方案總數不超過 double 可表示範圍；機率誤差需不超過 1e-4。'
input_format: '第一行 n；接下來 n 行依序給 h_i,v_i。'
output_format: '第一行輸出最多攔截數；第二行輸出 n 個介於 0 與 1 的實數。'
samples:
  - input: |
      4
      3 30
      4 40
      6 60
      3 30
    output: |
      2
      0.33333 0.33333 0.33333 1.00000
    explanation: '三個長度二的最優方案都以第 4 枚結尾，前三枚各出現在其中一個。'
core_knowledge:
  - '正向 DP 查詢先前高度與速度皆不小於目前點的最佳狀態。'
  - '狀態合併取較長者；長度相同則方案數相加。'
  - '反向 DP 計算以每點開頭的最長鏈與方案數。'
judgment: '時間順序天然是第三維；依序處理後只需在線維護高度、速度二維支配查詢。'
hints:
  - '先寫 O(n^2) DP：轉移條件是 j<i、h_j>=h_i、v_j>=v_i。'
  - '離散化並反轉座標後，合法前驅形成二維前綴；資料結構節點同時保存最長值與達成方式數。'
  - '若 forward_len[i]+backward_len[i]-1 等於全域最長值，經過 i 的最優方案數就是兩側方案數乘積。'
solution_outline: |-
  離散化高度與速度。以離線建立的 Fenwick-of-Fenwick 支援單點加入與二維前綴最佳狀態，正向依序求以 i 結尾的長度及方案數；反向再求以 i 開頭的結果。所有正向長度等於全域最長值的方案數和是分母；可位於最優鏈上的 i 以兩側方案數乘積作分子。
proof_or_invariant: |-
  正向處理 i 時，二維前綴恰含所有 j<i 且 h_j>=h_i、v_j>=v_i 的狀態，合併規則正是最長鏈 DP，故 forward 正確；反向同理。任何包含 i 的最優鏈可唯一拆成「以 i 結尾」與「以 i 開頭」兩段，兩段獨立組合且僅重複 i，因此長度條件與方案數乘法皆成立。
common_errors:
  - '把不升條件誤寫成嚴格下降，遺漏相等高度或速度。'
  - '同長狀態只取其一，未累加方案數。'
  - '分母誤用某一終點的方案數，而非所有最長終點之和。'

cpp_solution: |
  #include <bits/stdc++.h>
  using namespace std;
  struct State { int length = 0; double ways = 0; };
  State merge_state(const State& a, const State& b) { if (a.length != b.length) return a.length > b.length ? a : b; return {a.length, a.ways + b.ways}; }
  class Fenwick2d {
      int outer_size; vector<vector<int>> coordinates; vector<vector<State>> tree;
  public:
      Fenwick2d(int size, const vector<pair<int,int>>& points) : outer_size(size), coordinates(static_cast<size_t>(size + 1)), tree(static_cast<size_t>(size + 1)) {
          for (auto [x,y] : points) for (int i=x;i<=outer_size;i+=i&-i) coordinates[i].push_back(y);
          for (int i=1;i<=outer_size;++i) { auto& c=coordinates[i]; sort(c.begin(),c.end()); c.erase(unique(c.begin(),c.end()),c.end()); tree[i].resize(c.size()+1); }
      }
      void update(int x,int y,State value) { for(int i=x;i<=outer_size;i+=i&-i){int p=static_cast<int>(lower_bound(coordinates[i].begin(),coordinates[i].end(),y)-coordinates[i].begin())+1;for(;p<static_cast<int>(tree[i].size());p+=p&-p)tree[i][p]=merge_state(tree[i][p],value);} }
      State query(int x,int y) const { State answer;for(int i=x;i>0;i-=i&-i){int p=static_cast<int>(upper_bound(coordinates[i].begin(),coordinates[i].end(),y)-coordinates[i].begin());for(;p>0;p-=p&-p)answer=merge_state(answer,tree[i][p]);}return answer; }
  };
