statement: >-
  保險箱密碼是任意 n 位十進位數字；輸入超過 n 位時只看最後 n 位。請構造長度
  10^n+n-1 的按鍵序列，使每個 n 位數字字串都恰好以連續子字串出現一次。
constraints: [1 <= n <= 6, 輸入包含多組 n, 以 0 結束, 時間限制 1000 ms, 記憶體限制 65536 kB]
input_format: 每行一個 n；讀到 0 結束。
output_format: 對每個 n 輸出一行符合要求的數字序列。
samples:
  - input: "1\n2\n0\n"
    output: "0123456789\n00102030405060708091121314151617181922324252627282933435363738394454647484955657585966768697787988990"
    explanation: n=1 時依序列出十個數字；n=2 的序列每個相鄰兩位視窗恰好涵蓋 00 到 99。
core_knowledge: [n-1 位後綴作頂點, n 位密碼作有向邊, De Bruijn 圖的歐拉迴路]
judgment: 前導零是密碼的一部分；答案必須恰有 10^n+n-1 位。
hints:
  - 把最近 n-1 位視為狀態，按下一位 d 就轉到新的 n-1 位後綴。
  - 每個 n 位密碼對應一條「舊後綴→新後綴」且標記 d 的邊。
  - De Bruijn 圖每點入出度皆為 10；從全零狀態做 Hierholzer，反轉回溯邊標後在前面補 n-1 個零。
solution_outline: >-
  令 vertex_count=10^(n-1)。頂點 u 的十條出邊以 digit=0..9 編號，終點為
  (u*10+digit)%vertex_count。以 next_digit[u] 記下一條未走出邊，遞迴 Hierholzer；
  回溯時收集 digit，反轉後以前綴 n-1 個零輸出。
proof_or_invariant: >-
  一條邊由「前 n-1 位、最後一位」唯一決定，故與每個 n 位密碼一一對應。每點有十條入邊
  與十條出邊，且從全零可達所有狀態，所以存在歐拉迴路。Hierholzer 恰走每邊一次；相鄰邊
  的後綴/前綴重疊 n-1 位，因此輸出滑窗恰列出全部密碼一次，長度也達理論下界。
common_errors: [以整數輸出而丟掉前導零, 頂點數誤用 10^n, 回溯標記未反轉, 只輸出邊標而少補 n-1 個起始零]
complexity: { time: O(10^n), space: O(10^n) }

cpp_solution: |
  #include <algorithm>
  #include <iostream>
  #include <string>
  #include <vector>
  using namespace std;
  static void build_tour(int vertex,int vertex_count,vector<int>& next_digit,string& reversed_digits){
      vector<int> vertices{vertex},incoming_digits;
      while(!vertices.empty()){
          int current=vertices.back();
          int& digit=next_digit[static_cast<size_t>(current)];
          if(digit<10){int used_digit=digit++;vertices.push_back((current*10+used_digit)%vertex_count);incoming_digits.push_back(used_digit);}
          else{vertices.pop_back();if(!incoming_digits.empty()){reversed_digits.push_back(static_cast<char>('0'+incoming_digits.back()));incoming_digits.pop_back();}}
      }
  }
  int main(){
      ios::sync_with_stdio(false);cin.tie(nullptr);int n=0;
      while(cin>>n&&n!=0){int vertex_count=1;for(int i=1;i<n;++i)vertex_count*=10;vector<int> next_digit(static_cast<size_t>(vertex_count),0);string reversed_digits;reversed_digits.reserve(static_cast<size_t>(vertex_count*10));build_tour(0,vertex_count,next_digit,reversed_digits);reverse(reversed_digits.begin(),reversed_digits.end());cout<<string(static_cast<size_t>(n-1),'0')<<reversed_digits<<'\n';}
  }
