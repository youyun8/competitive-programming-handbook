hints:
  - dist 先以原始有向邊初始化，重邊取最小。
  - 首次執行 0 k 時，對全部 i、j 做 dist[i][j]=min(dist[i][j],dist[i][k]+dist[k][j])。
  - 查詢先檢查端點標記，再檢查可達；重複標記也必須輸出錯誤。
solution_outline: 維護標記陣列與距離矩陣；每個新標記點觸發一輪 Floyd，查詢按規定優先序輸出。
proof_or_invariant: 已處理標記集合 S 後，dist 是只用 S 作中繼的最短距離。新增 k 時 Floyd 的單輪轉移完整涵蓋不經 k 與經 k 兩類路徑，因此不變量保持；查詢端點限制另行檢查。
complexity: { time: 'O(n^3+q)', space: 'O(n^2)' }

      }
